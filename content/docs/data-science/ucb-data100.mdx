## 课程简介

Data 100（Principles and Techniques of Data Science）是伯克利数据科学专业的核心课，
官方定位是连接入门课 Data 8 和高年级的计算机、统计课（数据库 CS186、机器学习 CS189、统计 Stat 154）的桥梁。

课程围绕“数据科学的生命周期”展开：提出问题、收集与清洗数据、探索性分析与可视化、统计推断与预测，最后基于结果做决策。
官方列的关键技术有：变换、查询、分析数据的语言；回归、分类、聚类这些机器学习方法；做出有信息量的可视化的原则；
测量误差与预测的统计概念；可扩展的数据处理技术。

和纯机器学习课比，它花了更多篇幅在数据本身上：怎么读进一份编码有问题的 CSV、怎么发现数据里的错误、
怎么判断一份抽样有没有偏差。这正是实际工作里最花时间的部分。
课程还专门有一讲“人文背景与伦理”的案例研究，用库克县房产估价（CCAO）的真实数据讨论模型的公平性。

课程网站 [ds100.org](https://ds100.org/) 从 2017 年春季起的每个学期都有存档，下面按 2026 年秋季写。

## 先修要求

官方写明先修要求会严格执行：

- **计算**：[CS61A](/docs/programming-intro/cs61a) 或 Data 88C。官方的理由是，有了循环、lambda、调试、复杂度这些基础，
  这门课就能专注在数据科学概念上，而不是 Python 细节。
- **数学**：线性代数（Math 54、EECS 16A 等），需要线性算子、投影、优化这些概念，**可以和 Data 100 同时修**。
  自学的话，[MIT 18.06](/docs/mathematics/mit-18-06) 前半部分就够用。
- **统计**：课程主页说 Data 8 覆盖了 Data 100 的很多内容，只是更入门。没学过也能上，但概率和抽样部分会吃力些。
- HW0 分“编程先修”和“数学先修”两份，正好用来自测。

## 课程结构

2026 年秋季每周两讲，共 28 讲：

| 部分 | 讲什么 |
|---|---|
| 探索性数据分析 | 课程概览与数据科学生命周期、EDA 五讲、正则表达式、可视化 |
| 抽样与建模 | 抽样、建模两讲、普通最小二乘两讲、梯度下降两讲 |
| 模型与伦理 | 人文背景与伦理案例（CCAO 房产估价）、特征工程、交叉验证与正则化 |
| 概率与推断 | 随机变量、估计量与偏差方差、参数推断与自助法（Bootstrap） |
| 分类与无监督 | 逻辑回归两讲、主成分分析与聚类两讲 |
| 收尾 | 客座讲座、总结 |

考试是三次一小时的小测（在校内机房的上机考试，期末前可以重考挽回部分分数）和一次期末。

## 官方作业

作业的 Notebook 放在公开的 GitHub 仓库 [DS-100/fa26-student](https://github.com/DS-100/fa26-student) 里，
里面有 `hw`（作业）、`disc`（讨论课）、`lec`（课堂示例）三个目录，谁都能下载。

- **Homework 0～7**（每周一份）：HW0 编程先修与数学先修自测；HW1、HW2 旧金山餐厅食品安全检查数据（Food Safety I、II）；
  HW3 纽约时报文章；HW4 可视化；HW5 抽样与建模；HW6 概率；HW7 待发布。
  **2026 年秋季起数据处理改用 Polars**（以前是 Pandas），HW1 第一部分就是用 Polars 读入、清洗、合并四张表。
- **Project A（Housing I、II）**：用库克县估价办公室（CCAO）的真实房产数据预测房价：先做数据清洗和探索，再搭建处理流水线、拟合线性模型并评估，其中还有专门讨论估价公平性的题目。（按 2026 春季版描述，秋季版尚未发布。）
- **Project B（Spam & Ham I、II）**：用逻辑回归做垃圾邮件分类，B2 要自己设计特征、用交叉验证调出一个尽量准的模型。
- **讨论课（Discussion 1～13）**：每周一份练习，官方说它们是为作业做准备的，要求每个学生都完成。

每份 Notebook 里都有 `grader.check("q1a")` 这样的公开测试，可以本地运行。
但官方说公开测试“主要是基本检查”（比如答案是不是个数字），真正判对错的是隐藏测试，只在 Gradescope 上跑。
有些题标着“Manual”，是要人工批改的文字题。

## 学习建议

- **先做 HW0。** 两份先修自测做不下来，就先回去补 Python 或线性代数。
- **公开测试通过不等于做对了。** 自学时没有隐藏测试，每道题做完自己再检查一遍：结果的形状对不对、数值合不合理、有没有漏掉缺失值。
- **注意作业里的 LLM 标记。** 课程政策允许在特定情况下用大模型；HW1 里官方建议第一部分“尽量少用或不用”，
  好让你把 Polars 的基本功练熟，只有标着 LLM-OK 的小题鼓励用。自学时照这个规矩来。
- **Project A 和 B 一定要做。** 它们把特征工程、正则化、交叉验证、逻辑回归全串起来了，是这门课最接近真实数据分析工作的部分。
- **用课程讲义复习。** [在线讲义](https://ds100.org/course-notes/) 按讲组织，比幻灯片完整，适合做作业前查。

## 同类课怎么选

- 想往机器学习走，下一步是 [CS189](/docs/ai-machine-learning/machine-learning/cs189) 或 [CS229](/docs/ai-machine-learning/machine-learning/cs229)，Data 100 的回归、梯度下降、正则化在那里会讲得更深。
- 想往数据库走，接 [CS186](/docs/systems/databases/cs186)，官方把它列为 Data 100 的后续课之一。
- 概率和推断想打得更扎实，看 [CS70](/docs/advanced-mathematics/cs70) 的后半部分。
