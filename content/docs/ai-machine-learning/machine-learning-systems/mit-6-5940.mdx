## 课程简介

6.5940（TinyML and Efficient Deep Learning Computing）由 Song Han 讲授，
主题是让深度学习跑得更省、更快。

课程分三部分。第一部分是让神经网络轻量化的基础技术：
剪枝、量化、知识蒸馏、神经网络架构搜索。
第二部分面向具体场景做优化，覆盖当下最热的方向：
大语言模型的推理加速、长上下文支持、后训练量化、
扩散模型加速、端侧微调。
第三部分是系统与硬件：TinyML 在微控制器上的部署、
分布式训练与并行策略。

五个实验都在真实模型上做，能直接看到模型体积和延迟的变化。
对想把模型真正跑到设备上的人，这门课非常对口。

## 先修要求

- 需要深度学习基础。
- 需要计算机体系结构的基本概念与 Python 能力。
