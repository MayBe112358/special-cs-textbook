## 课程简介

这门课讲的是机器学习编译——把训练好的模型高效地部署到各种环境里。
官方的问题陈述很清楚：模型和部署环境的组合爆炸给推理部署带来巨大挑战，
再加上减少软件依赖、支持新硬件、降低内存占用这些实际要求，
就产生了机器学习编译这个新方向。

课程按关键要素组织：如何表示机器学习程序（张量程序抽象）、
端到端的模型执行流程、自动程序优化（基于学习的搜索）、
与机器学习框架的集成、GPU 与专用硬件加速、
计算图优化，以及部署到不同环境的实践。

这是国内外少有的专门讲机器学习编译的课程，
由这个方向的核心研究者陈天奇讲授，有完整的中文版。

## 先修要求

- 需要机器学习或深度学习基础。
- 需要 Python 编程能力；了解编译或系统会更好。
