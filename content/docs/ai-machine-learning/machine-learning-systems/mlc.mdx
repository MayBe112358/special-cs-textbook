## 课程简介

这是 **陈天奇**（TVM、XGBoost 的作者，CMU 教授）在 2022 年夏天开的机器学习编译（Machine Learning Compilation，MLC）公开课，
中文和英文各一个版本，助教是冯思远、金弘义、赖睿航。

课程要解决的问题，官方说得很清楚：AI 应用越来越普遍，怎么把最新的模型部署到各种生产环境里成了难题。
模型和部署环境的组合爆炸，再加上减少软件依赖、覆盖更多模型、利用新硬件加速、减少内存占用这些实际要求，
就催生了“机器学习编译”这个新方向。它把机器学习编程抽象、基于学习的搜索、编译优化和运行时结合在一起。

课程按关键要素组织：**怎么表示机器学习程序**（张量程序抽象）、**怎么自动优化**、**怎么在端到端部署里优化依赖、内存和性能**。
用的工具是开源的机器学习编译框架 Apache TVM。这是少有的、系统讲机器学习编译的公开课，而且有完整的中文讲义。

## 先修要求

官方写的背景要求：

- 熟悉 Python 和 NumPy；
- 有一定的深度学习框架背景（PyTorch、TensorFlow、JAX 之一）；
- 有系统层面的编程经验（如 C/CUDA）更好，但不是必需。

## 课程结构

十讲，每周一讲：

| 讲次 | 主题 |
|---|---|
| 1 | 机器学习编译概述 |
| 2 | 张量程序抽象 |
| 3 | 张量程序抽象案例研究：TensorIR |
| 4 | 端到端模型整合 |
| 5 | 自动化程序优化 |
| 6 | 与机器学习框架的整合 |
| 7 | GPU 硬件加速（一） |
| 8 | GPU 硬件加速（二） |
| 9 | 计算图优化：算子融合和内存优化 |
| 10 | 课程总结和未来展望 |

每讲都有 B 站录像、幻灯片或 Notebook，以及中英文在线讲义。

## 官方作业

- **TensorIR 练习**（第 3 讲）：在讲义里，练习用 TensorIR 写张量函数、做变换。
- **作业 1：端到端模型执行**（第 4 讲）：从 PyTorch 里拿一个在 Fashion MNIST 上训练好的卷积网络，把它迁移成 TVM 的实现，
  再在端到端的层面做变换和优化。有中文版 Notebook。
- **每讲的 Notebook**：第 3～9 讲都有配套 Notebook，可以直接在 Colab 里跑，讲课时的代码就在里面。
- 第 8 讲另附一个 Tensor Core 教程。

没有自动评分，也没有截止日期，完全按自己的节奏做。
课程用的是官方打包的 TVM 版本（`mlc-ai-nightly`），安装命令写在讲义里。

## 学习建议

- **讲义配录像。** 在线讲义把每讲的内容和代码整理得很完整，可以先读讲义，看不懂的地方再看录像。
- **第 2～4 讲是地基。** 张量程序抽象、TensorIR、端到端模型这三讲把整门课的核心概念立起来了，TensorIR 练习和作业 1 一定要做。
- **GPU 那两讲配着 CUDA 一起学。** 讲的是怎么把张量程序映射到 GPU 的线程和共享内存上，事先了解一点 CUDA 会轻松很多。
- **想看最新的，接新课。** 2026 年 7 月陈天奇又发布了一门《面向机器学习系统的现代 GPU 编程》，讲 Blackwell GPU、TIRx、GEMM 和 FlashAttention 4，可以当作这门课的续篇。
