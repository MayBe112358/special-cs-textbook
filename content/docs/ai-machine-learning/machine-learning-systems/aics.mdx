## 课程简介

《智能计算系统》（AI Computing Systems，AICS）是中科院计算所智能处理器研究中心 **陈云霁** 团队推出的课，
2019 年 3 月在中国科学院大学首次开课。按官网的说法，截至 2024 年 9 月已在国科大、清华、北大、北航等上百所高校开课，
累计培养学生两万多名。

课程的思路叫“**应用驱动，全栈贯通**”：用一个典型的深度学习应用——**图像风格迁移**——当驱动范例，再以大模型为牵引，
把上层的算法、中间的编程框架和编程语言、底层的芯片串起来，讲清楚智能计算系统怎样获得持续增长的计算能力。
它特别强调技术栈各层之间的“结合部”：一个算法怎样拆成算子，算子在编程框架里怎样调度，芯片体系结构又怎样支持这些算子。

配套教材是《智能计算系统：从深度学习到大模型》（第 2 版，2024 年 7 月出版，官方说内容更新超过 70%）。

## 先修要求

- 官方大纲列的前序课程：线性代数、概率论与数理统计、计算机组成原理。
- 官方答疑里补充：如果还学过机器学习和人工智能基础，学习效果更好。
- 课程主要面向计算机、软件工程、人工智能、微电子、自动化等方向的高年级本科生和研究生。
- 实验用 Python（PyTorch）和 C/C++，第八章还要学智能编程语言 BANG。

## 课程结构

按第 2 版教材分九章，推荐 38 学时（各校会在 16～60 学时之间调整）：

| 章 | 主题 | 讲什么 |
|---|---|---|
| 1 | 概述 | 人工智能发展与三类研究方法；智能计算系统的发展；用风格迁移走一遍“算法 → 编程 → 芯片” |
| 2 | 深度学习基础 | 线性回归到神经网络；训练；提高精度的手段；交叉验证 |
| 3 | 深度学习应用 | 卷积网络、图像分类与目标检测；GAN 与扩散模型；RNN 与 LSTM；大模型核心技术；优化方法与量化；风格迁移 |
| 4 | 编程框架使用 | PyTorch 的编程模型与基本用法；用 PyTorch 做推理和训练 |
| 5 | 编程框架原理 | 框架设计；计算图的构建与执行；深度学习编译；分布式训练 |
| 6 | 面向深度学习的处理器原理 | 从通用处理器（CPU）到向量处理器（GPU）再到深度学习处理器（DLP）；大规模深度学习处理器 |
| 7 | 深度学习处理器架构 | 计算、存储、通信三方面的硬件模块设计 |
| 8 | 智能编程语言 | 抽象架构与编程模型；语言基础与接口；功能调试与性能调优 |
| 9 | 大模型计算系统 | 大模型算法分析；以 BLOOM 为例分析训练过程；大模型系统软件与基础硬件 |

## 官方作业

实验和理论章节一一对应，官方推荐课程**用实验成绩 100% 考核**，由自动评测平台打分：

| 实验 | 内容 |
|---|---|
| 神经网络设计 | 用三层神经网络做手写数字分类；在 DLP 平台上做同样的任务 |
| 深度学习设计 | 用 VGG19 做图像分类（CPU 与 DLP）；非实时风格迁移 |
| 编程框架 | VGG19 图像分类；实时风格迁移的推理与训练；自定义 PyTorch CPU 算子 |
| 智能编程语言 | 用 BANG 开发算子并集成进框架；性能优化 |
| 综合实验 | 在 DLP 平台上做 Tacotron2 语音合成、YOLOv5 目标检测训练、BERT 问答（SQuAD）训练 |
| 大模型实验 | 用 Stable Diffusion 生成图像；把 Llama 2 聊天机器人、Code Llama 代码生成部署到 DLP 平台 |
| 选修：处理器运算器设计 | 串行内积运算器、并行内积运算器、矩阵运算子单元 |

实验全部在**云平台**上做，只需要一台能上网的电脑。但官方答疑说的是“开课后”为学生提供实验环境，开课要由学校老师在官网提交申请，
官网没有给个人自学者申请 DLP 平台的入口。能在 CPU 上做的部分（前几个实验、PyTorch 自定义算子）可以照实验手册在自己电脑上做。

## 学习建议

- **跟着第 2 版教材学。** 官网公开了第 2 版各章的课件 PDF，官方 B 站账号“智能计算系统AICS”上有按章节发布的讲解视频。
- **盯住“结合部”。** 这门课最有价值的是讲清各层怎么衔接，读每一章时都问自己：这一层的东西，上一层怎么调用、下一层怎么支撑？
- **先把 CPU 上能做的实验做完。** 风格迁移从非实时到实时、从推理到训练，再到自定义 PyTorch 算子，这条线自己在电脑上就能走通。
- **想深入大模型，接研讨课。** 官网还有一门 2024 年 10 月到 2025 年 1 月开的“大模型研讨课”，十讲讲大模型的结构、预训练、后训练、推理等，课件和 B 站回放都公开。
