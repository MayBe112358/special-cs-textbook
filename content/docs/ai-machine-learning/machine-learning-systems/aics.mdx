## 课程简介

这门课由中科院计算所陈云霁团队开设，
关注的是智能计算系统——支撑人工智能应用的整套软硬件。

官方的定位很明确：每年全球要制造数以十亿计的智能计算系统，
从智能手机到智能服务器，需要大量的设计者和开发者，
而这方面的人才培养直接关系到产业的核心竞争力。

课程的特点是纵深打通：从深度学习算法讲起，
到编程框架的设计与实现，再到深度学习处理器的体系结构、
指令集与编译工具链，最后是整个系统的集成与优化。
一系列实验带你以完整视野理解人工智能的技术栈，
而不是停留在某一层。

配套有中文教材与实验平台，国内多所高校开设了对应课程。

## 先修要求

- 需要计算机体系结构基础。
- 需要深度学习基础；实验使用 Python 与 C++。
