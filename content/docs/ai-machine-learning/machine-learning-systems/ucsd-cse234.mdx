## 课程简介

CSE234 把自己定位成一门大语言模型系统的入门课，
内容分三部分（外加若干客座讲座）：

第一部分是基础：现代深度学习的计算表示、
自动微分、算子与计算图。
第二部分是系统与性能：GPU 架构与编程、算子优化、
内存管理、分布式训练的并行策略（数据并行、张量并行、流水线并行）。
第三部分面向大模型的具体问题：
推理服务的调度与批处理、KV 缓存管理、量化与稀疏化、
以及检索增强等应用系统。

作业用 Python 和 Triton 完成，涉及算子编写与性能调优。
课程材料组织得很清晰，适合作为机器学习系统方向的切入点。

## 先修要求

- 需要线性代数与深度学习基础。
- 需要操作系统、计算机网络与分布式系统的基本概念。
