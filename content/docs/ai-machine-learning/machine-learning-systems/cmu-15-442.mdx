## 课程简介

15-442/15-642 的目标是给出现代机器学习系统的整体图景。

随着大语言模型的爆发，如何高效训练和部署这些庞然大物
成了 AI 领域最核心的工程挑战之一。这门课面向的正是
不满足于调用 PyTorch API、想知道 vLLM、SGLang 这类推理框架
内部是怎么回事的人。

内容覆盖：机器学习框架的设计与自动微分、
GPU 编程与算子优化、模型并行与分布式训练、
内存优化技术、推理服务系统（批处理、KV 缓存、调度）、
模型压缩与量化，以及机器学习编译。

作业以动手实现为主，仓库公开在课程的 GitHub 组织里。

## 先修要求

- 需要系统编程基础（指南建议先修 CMU 15-213 或同等课程）。
- 需要深度学习入门；作业使用 Python、C++ 与 CUDA。
