## 课程简介

深度学习的普及很大程度上得益于 PyTorch、TensorFlow 这类框架，
但大多数使用者对框架内部知之甚少。10-414 就是为此开的：
它让你从零实现一个自己的深度学习框架。

课程分两条线。理论线讲：自动微分的原理（前向与反向模式）、
计算图的构建与优化、神经网络库的抽象设计、
硬件加速与算子实现、训练大模型的系统技术。
实践线是四个作业，逐步构建一个名为 needle 的框架——
先实现自动微分，再实现神经网络库与优化器，
然后实现 NDArray 后端（含 CUDA 版本），
最后用自己的框架训练 CNN 和 Transformer。

做完之后，PyTorch 对你就不再是黑盒了。

## 先修要求

- 需要系统编程基础（指南建议先修 CMU 15-213 或同等课程）。
- 需要深度学习入门与基本的数学基础；作业用 Python 与 C++/CUDA。
