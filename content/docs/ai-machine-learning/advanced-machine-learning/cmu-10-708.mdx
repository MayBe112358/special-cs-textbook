## 课程简介

10-708 是 CMU 的概率图模型课，由 Eric Xing 讲授，内容相当硬核。

课程围绕图模型的三个基本问题组织：表示（有向图与无向图模型、
贝叶斯网络、马尔可夫随机场、条件随机场）、
推断（精确推断、变量消元、信念传播、变分推断、蒙特卡洛方法）、
学习（参数估计、结构学习、EM 算法）。

之后课程把这套框架推向现代：图模型与深度学习的结合
（深度生成模型、变分自编码器）、图模型在强化学习中的应用、
非参数贝叶斯方法，以及大规模图模型的分布式实现。

课程网站上有完整的讲义、笔记与作业，组织得很清楚。

## 先修要求

- 需要机器学习、深度学习基础。
- 需要扎实的概率论与统计学，以及强化学习的基本概念。
