## 课程简介

STAT 8201 是一门博士研讨班，主题是深度生成模型——
图模型与神经网络的结合，也是现代机器学习最重要的方向之一。

课程形式是每周展示并讨论论文，覆盖变分自编码器、
生成对抗网络、归一化流、自回归模型等主要路线，
以及它们与概率图模型、变分推断之间的理论联系。

授课者是 John Cunningham。
研讨班的价值主要在论文列表和讨论问题本身，
适合已经有扎实基础、想系统读一遍这个方向经典工作的人。

课程材料公开在授课者的教学页面上。

## 先修要求

- 需要机器学习、深度学习与概率图模型基础。
- 需要能独立阅读研究论文。
