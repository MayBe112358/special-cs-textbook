## 课程简介

这门课的切入点很有意思。官方用了一个日常例子：
疫情后第一次出门吃饭，是去老地方还是试试新店？
这是一个不确定条件下的决策问题。

课程把这类问题统一形式化为“最小化期望代价”：
决策者从一个动作分布里采样、承担代价，
问题是找到让期望代价最小的那个分布。
这个看似具体的问题，其实贯穿整个机器学习与统计——
贝叶斯推断可以写成一个变分优化问题，
强化学习、生成模型、带不确定性校准的神经网络都能纳入这个框架。

课程强调推断与强化学习之间的相互关系，
以论文研读、代码 Notebook 和期末项目为主，
授课者是 Chris Maddison（AlphaGo 早期成员之一）。

## 先修要求

- 需要贝叶斯推断与强化学习基础。
- 需要较强的概率与优化背景，适合研究生水平。
