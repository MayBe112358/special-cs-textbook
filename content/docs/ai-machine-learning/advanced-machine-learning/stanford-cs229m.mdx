## 课程简介

STATS214 / CS229M Machine Learning Theory 是斯坦福统计系和计算机系合开的机器学习理论课。
这门课最早叫 CS229T，由 **Percy Liang** 讲；后来改名 CS229M，**马腾宇**（Tengyu Ma）讲了 2021 年冬季和秋季两次，
2022 年秋季由 Tselil Schramm 讲。这里以录像公开的**马腾宇 2021 年秋季版**为主。

课程问的是三个问题：**机器学习算法什么时候有效、为什么有效？怎么形式化“从数据里学习”这件事？怎么用数学思维设计更好的方法？**
它关心的是学习算法的统计性质，全程都是定理和证明。前半段是经典的统计学习理论（一致收敛、复杂度度量、泛化界），
后半段是这些年的深度学习理论（神经网络的泛化、非凸优化、神经正切核、隐式正则化）。

## 先修要求

2021 年秋季的官方要求：

- 微积分（Math 19/20/21）；
- 线性代数（Math 51 或 CS205）；
- 概率（CS109、STATS 116、MATH 151 或 EE178）；
- 机器学习（[CS229](/docs/ai-machine-learning/machine-learning/cs229) 或 STATS 315A）；
- 推荐但不要求：凸优化（EE364A）和/或 CS168。

## 课程结构

2021 年秋季共 20 讲，每讲都标了对应的讲义章节：

| 部分 | 讲什么 |
|---|---|
| 基础 | 监督学习的形式化与经验风险最小化；渐近分析；集中不等式（Hoeffding、次高斯） |
| 一致收敛 | 有限假设类；无限假设空间的离散化；Rademacher 复杂度；间隔理论与线性模型 |
| 神经网络的泛化 | 深度学习理论的挑战；神经网络的泛化界；覆盖数与 Dudley 定理；深度网络的泛化界；全层间隔（all-layer margin） |
| 优化 | 非凸优化（PCA、矩阵补全里“局部最优就是全局最优”）；神经正切核（NTK） |
| 隐式正则化 | 梯度下降的隐式正则化；初始化、分类问题和噪声带来的隐式正则化 |
| 无监督学习 | 高斯混合与矩方法；谱聚类 |

2021 年冬季版的后半段还讲了在线学习与在线凸优化（FTRL），课程主页上保留了那一版每讲的笔记链接。

评分（2021 年秋季）：三个作业共 50%（可以最多三人一组交一份）、论文评述或小项目 50%；写课堂笔记、改进已有笔记、在论坛答疑都有加分。

## 官方作业

- **三个作业**：以证明题为主。但官方说得很清楚：**作业只发在选课学生能看到的 Ed 论坛上，不放在课程网站上**，就是为了防止答案流到网上。所以校外拿不到作业题。
- **论文评述或小项目**：读同一个主题的两篇论文写评述——不只是总结，还要批判、举例、讨论意义、提出后续方向；
  也可以只读一篇，再在同一主题上做一个小项目，合起来写一份 8 页的报告。官方给了一份近年机器学习理论论文清单。

校外自学的话，可以把**论文评述当作业来做**：从讲义引用的论文里挑一个主题，读两篇，照官方的要求写一份评述。

## 学习建议

- **讲义是主角。** 马腾宇整理的课堂笔记汇编有 167 页，每一讲的推导都在里面，比录像更适合反复看。
- **录像配讲义。** YouTube 上有 2021 年秋季的 20 讲录像，课上是在 iPad 上手写推导，跟着一步一步推比看成品讲义更容易懂。
- **合上讲义自己推。** 讲义里几乎没有习题，最好的练习是看完一个定理，合上讲义把证明从头推一遍。
- **对照 Percy Liang 的讲义。** 更早的 CS229T 讲义有 217 页，经典统计学习理论部分讲得更细，可以当第二本参考书。

## 同类课怎么选

- **[Stanford CS229](/docs/ai-machine-learning/machine-learning/cs229)**：先修课，先把机器学习的算法和基本推导学扎实。
- **[CMU 10-708 概率图模型](/docs/ai-machine-learning/advanced-machine-learning/cmu-10-708)**：另一门高阶课，偏概率建模与推断，不是泛化理论。
- **[MIT 6.7960](/docs/ai-machine-learning/deep-learning/mit-6-7960)**：MIT 的深度学习研究生课，也讲逼近、泛化和缩放规律，但以直觉和实验为主，证明少得多。
