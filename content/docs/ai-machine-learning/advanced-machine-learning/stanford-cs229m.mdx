## 课程简介

STATS214 / CS229M 问的是三个问题：机器学习算法什么时候有效、为什么有效？
怎么形式化“从数据中学习”这件事？怎么用数学思维设计更好的方法？

课程分两部分。前半部分是经典统计学习理论：
一致收敛、复杂度度量（VC 维、Rademacher 复杂度）、
泛化界、margin 理论、核方法的理论分析。
后半部分转向近年的深度学习理论：
过参数化模型为什么不过拟合、隐式正则化、
神经正切核（NTK）、优化的非凸景观。

这门课非常硬核，全程都是定理和证明，
适合想做理论研究或者不满足于经验结论的人。
授课者先后是 Percy Liang 和 Tengyu Ma。

## 先修要求

- 需要机器学习与深度学习基础。
- 需要扎实的概率论、统计与线性代数，以及数学证明能力。
