## 课程简介

11-868 聚焦“从算法到工程”的大语言模型系统构建全过程，面向研究生开设。

课程内容大致分四块：GPU 编程与自动微分——
CUDA kernel 的调用与并行编程基础，以及深度学习框架的设计原理；
模型训练与分布式系统——高效训练算法、通信优化（ZeRO、FlashAttention）、
分布式训练框架（DDP、GPipe、Megatron-LM）；
模型压缩与加速——量化（GPTQ）、稀疏化（MoE）、编译技术；
以及推理服务系统的设计。

作业要求动手实现这些系统组件，
是少数把 GPU 编程与大模型系统结合起来讲的课程之一。

## 先修要求

- 强烈建议已修读深度学习（11-785）或高级 NLP（11-611 / 11-711）。
- 需要 Python 与一定的 CUDA/系统编程基础。
