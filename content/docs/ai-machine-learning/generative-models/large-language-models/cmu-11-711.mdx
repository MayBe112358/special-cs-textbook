## 课程简介

11-711（Advanced Natural Language Processing）是卡内基梅隆大学语言技术研究所（LTI）的 NLP 研究生课，面向**想做前沿研究**的学生。
课程讲的是基于神经网络的现代方法，重点放在生成模型、尤其是大语言模型的基础上：怎么建模、怎么训练、怎么推理。
课程以一个开放的研究项目收尾。

这门课这几年换过讲师：2024 年秋季由 Graham Neubig 讲，那一版的讲课录像全部公开在 YouTube 上；
2025 年春季起由 **Sean Welleck** 讲，网站搬到了 cmu-l3.github.io，每讲配有幻灯片，多数讲还有讲课用的代码，但网站上没有公开录像。

## 先修要求

官方没有硬性先修课，但期望你有：

- Python 编程经验；
- 概率论和线性代数的知识；
- 实际上**强烈推荐先有深度学习经验**。

## 课程结构

2026 年春季约 23 讲，按主题分块：

| 部分 | 讲什么 |
|---|---|
| 基础 | 导论；学到的表示（词向量、分词）；自回归语言模型 |
| 架构 | 循环神经网络；注意力与 Transformer（含 RMSNorm、RoPE、GQA 等现代改进） |
| 学习与推理 | 预训练；缩放定律与上下文学习；微调与蒸馏；解码算法 |
| 建模 | 多模态（两讲）；扩散模型与流 |
| 评测 | 评测技术；研究技能与实验设计 |
| 强化学习与智能体 | 强化学习基础与应用；基于语言模型的智能体 |
| 规模与效率 | 量化；并行与分布式训练；混合专家（MoE）；长序列；测试时扩展 |

另有客座讲座。每讲都有必读材料，课上的 5 次小测和 1 次考试都从必读材料和讲课内容里出题。

评分：A1 10%、A2 10%、A3 15%、A4（期末项目）25%、考试 20%、小测 15%、课堂参与 5%。

## 官方作业

四个作业，前两个个人完成，后两个 2～3 人一组：

| 作业 | 内容 |
|---|---|
| A1 自己动手写 LLaMa | 补全一个迷你版 Llama2 的核心部件：注意力、前馈网络、层归一化、旋转位置编码（RoPE）；然后用它做文本续写、零样本分类，再改模块让它学会做加法 |
| A2 端到端 NLP 系统 | 自己收集和标注数据，搭一套检索增强生成（RAG）系统，回答关于匹兹堡和 CMU 的问题（历史、文化、活动等）：文档与问题的向量化、检索器、阅读器 |
| A3 文献综述与复现 | A3.1 围绕一个题目做文献综述、写项目提案；A3.2 复现一篇论文里的强基线，拿到和原文一样的数字，并分析它还错在哪 |
| A4 期末项目 | 在 A3 的基础上改进，做一个研究项目 |

A1 和 A2 的说明和起始代码都在 GitHub 上公开，校外可以照着做；A3、A4 是开放的研究项目，适合有具体研究兴趣的人。

**AI 工具政策**（沿用斯坦福 CS336）：可以问大模型底层编程问题或概念问题，但不能直接让它解题；
官方强烈建议写作业时关掉 Cursor Tab、Copilot 这类 AI 自动补全，因为它会让你很难真正投入到内容里。

## 学习建议

- **看录像选 2024 年秋季版，做作业用 2026 年春季版。** Neubig 那一版录像完整；Welleck 的新版作业更贴近现在的大模型（A1 写 Llama2）。两版主线差不多，可以对着看。
- **A1 一定要自己写。** 亲手实现 RoPE、注意力、RMSNorm，再让模型真的生成文字，是弄懂现代大模型结构最直接的办法。
- **每讲的代码跑一遍。** 2026 年版多数讲在配套代码仓库里有一个目录，边看幻灯片边跑，比光看公式清楚。
- **A3 是研究训练。** 复现一篇论文的数字往往比想象中难，这恰恰是做研究最常见的第一步；想走研究路线的话值得认真做。
