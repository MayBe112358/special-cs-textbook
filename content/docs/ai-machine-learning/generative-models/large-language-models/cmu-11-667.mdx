## 课程简介

11-667 是 CMU 的大语言模型研究生课程，
全面介绍大模型的方法与应用，覆盖从基础架构到前沿技术。

课程分四块：基础知识——语言模型的网络架构、
训练、推理与评估方法；进阶主题——模型可解释性、
对齐方法、涌现能力，以及在语言任务和非文本任务中的应用；
扩展技术——大规模预训练、模型部署优化、
高效的训练与推理方法；最后是伦理与安全——
模型偏见、攻击方法与法律问题。

课程形式包括讲座、阅读、小测验、互动活动与作业。
六次作业涵盖预训练数据准备、Transformer 实现、
检索增强生成、模型比较与偏见缓解、训练效率提升等主题。

## 先修要求

- 需要机器学习基础（相当于 CMU 10-301/10-601）。
- 需要自然语言处理基础，熟练掌握 Python 与 PyTorch。
