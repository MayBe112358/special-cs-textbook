## 课程简介

11-667（Large Language Models: Methods and Applications）是卡内基梅隆大学语言技术研究所（LTI）的研究生课，
目标是把大语言模型的**现状讲全**：模型怎么搭、数据怎么准备、怎么训练、怎么评测、怎么微调和对齐、怎么用到各种任务上，
以及部署时要面对的效率、安全和伦理问题。2023 年起每年秋季开一次，2025 年秋季由 Jaromir Savelka 和 Yubin Kim 讲授。

课程前半段讲语言模型的基础：网络架构、预训练目标、推理、评测，然后是可解释性、对齐、涌现能力和各种应用；
后半段讲怎么把预训练做大、做得更省，以及部署中的各种顾虑，最后收在前沿进展上。
官方列的学习目标里有一条很实在：**能用 PyTorch 从零实现并训练一个神经语言模型**。

注意网址变了：原来的 cmu-llms.org 从 2026 年春季起换成了姊妹课 11-766《大语言模型应用》，
11-667 的各届网站改到了带年份的子域名（2023.cmu-llms.org、2024.cmu-llms.org、2025.cmu-llms.org）。

## 先修要求

官方写的先修：

- 机器学习基础，相当于 CMU 10-301/10-601 的内容。
- 自然语言处理的基本概念，相当于 CMU 11-411/11-611 的内容。
- 熟练的 Python。熟悉 PyTorch 这类深度学习框架更好，但不强制。

作业需要 GPU。CMU 的学生会领到 AWS 额度（Assignment 0 就是提交 AWS 账号），校外自学要自己准备算力，Colab 或按小时租的云 GPU 都行。

## 课程结构

2025 年秋季的讲次大致是：

| 部分 | 讲什么 |
|---|---|
| 基础 | 现代大模型的构件；Transformer 架构与预训练目标；预训练数据的整理与分词；Transformer 的架构改进 |
| 评测与适配 | 大模型的自动评测；上下文学习、任务微调与参数高效微调；上下文学习与对齐中的反常现象 |
| 应用 | 工具使用；检索增强生成（客座）；推理（客座）；人机交互中的智能体评测（客座）；推荐系统（客座） |
| 规模化 | 缩放定律；优化与并行训练；稀疏模型高效预训练；合成数据训练；长上下文模型 |
| 理解与风险 | 可解释性方法；偏见与伦理问题；攻击大模型系统与基准泄露 |
| 对齐与部署 | 基于人类反馈的强化学习（RLHF）；高效推理方法；聊天机器人与大模型智能体 |

评分：四个作业共 39%（外加 Assignment 0 占 1%）、小项目 20%、期中考试 20%、期末考试 20%，课堂参与最多加 3 分。

## 官方作业

2025 年秋季的作业页上每个作业都有题目、起始代码和报告模板可以下载（放在 CMU 的 Box 网盘上）：

| 作业 | 内容 |
|---|---|
| Assignment 0 | 课程准备：注册 AWS 账号领算力额度（校外可以跳过） |
| Assignment 1 | 预训练数据：分析现有的预训练数据集；复现一条数据处理流水线，把网页抓取的原始数据清洗、去重、转成便于训练的格式 |
| Assignment 2 | 学分词；从零实现一个 Transformer 并做训练实验；用 HuggingFace 加载开源模型，用困惑度评测 |
| Assignment 3 | 训练一个会调用计算器的简单工具使用模型；训练一个检索器，搭一套检索增强生成（RAG）系统 |
| Assignment 4 | 提升训练和推理效率：优化显存占用，用多 GPU 做分布式训练 |
| Mini-project | 1～3 人一组，自选任务，用课上学的方法做一个小项目，最后在课上展示 |

作业交到 Gradescope，每份都要交代码和一份报告。校外交不了，但题目和起始代码都能下，可以自己做完再对照报告模板检查。

## 学习建议

- **Assignment 2 是核心。** 从零写一个 Transformer 并训练起来，是这门课最有分量的动手练习；前面没写过的话，一定要自己写一遍。
- **先把算力准备好。** 后两个作业要训练模型、做多 GPU 实验，开始之前先确认手头的 GPU 够用。
- **每讲的阅读要读。** 课程要求课前读完指定材料，很多讲的内容直接来自近几年的论文，读了再听事半功倍。
- **用小项目把知识串起来。** 小项目题目自选，可以挑一个你真正关心的应用，把检索、微调、评测都用上。
