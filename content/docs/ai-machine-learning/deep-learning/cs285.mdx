## 课程简介

CS285（研究生）/ CS185（本科）Deep Reinforcement Learning, Decision Making, and Control 是伯克利的深度强化学习课，
由 Sergey Levine 讲授，最近一次是 **2026 年春季**。讲课录像放在 YouTube 上（官方特别说明：课程不作为网课提供，视频仅供个人了解）。

强化学习研究的是：智能体怎么通过和环境交互、根据奖励信号学会做决策。这门课从最简单的**模仿学习**（照着专家的动作学）讲起，
然后是强化学习的三大类方法——**策略梯度**、**基于价值的方法（Q 学习）**、**基于模型的方法**，以及把它们结合起来的演员-评论家方法；
后半段讲概率推断视角（变分推断、控制即推断）、**离线强化学习**（只用已有数据、不再和环境交互）、探索、强化学习理论、多任务学习。

2026 年的一个新变化是加了**大模型强化学习**（LLM RL）一讲和一个对应的作业，这正是现在大模型后训练（比如 RLHF 和推理模型训练）的核心技术。

课程以公式密集著称，每个方法都会从目标函数推导到算法。

## 先修要求

- 官方写的是：**CS189 或同等课程**是先修；课程会假设你对强化学习、数值优化和机器学习有一定了解。
- 官方还推荐用 CS188 的 edX 版和 Sutton 与 Barto 的《强化学习》教材的部分章节补基础。
  强化学习完全没接触过的话，先学 [CS188](/docs/ai-machine-learning/artificial-intelligence/cs188) 的马尔可夫决策过程和强化学习部分。
- 作业用 PyTorch。仓库默认配置了在 Modal 云平台上运行，需要 GPU 的作业可以租用云端显卡。

## 课程结构

2026 年春季共 25 讲：

| 部分 | 讲什么 |
|---|---|
| 入门 | 导论；行为克隆（两讲）；强化学习基础 |
| 无模型方法 | 策略梯度；演员-评论家；基于价值的强化学习；Q 学习的实践；高级策略梯度（两讲） |
| 推断视角 | 变分推断；强化学习中的变分推断；控制即推断 |
| 大模型 | 大模型强化学习（LLM RL） |
| 基于模型 | 基于模型的强化学习（两讲） |
| 离线与探索 | 离线强化学习（两讲）；探索；强化学习理论 |
| 收尾 | 期中复习（两讲）；高级探索；多任务强化学习；挑战与开放问题 |

评分：五个编程作业共 50%（每个 10%），期末项目 20%，考试 20%，小测 10%。

## 官方作业

**作业说明 PDF 在课程主页，代码框架在公开的 GitHub 仓库 [berkeleydeeprlcourse/homework_spring2026](https://github.com/berkeleydeeprlcourse/homework_spring2026)**：

| 作业 | 内容 |
|---|---|
| HW1 模仿学习 | 在 Push-T 任务上训练“动作块”策略：先做一个简单的均方误差策略，再做一个类似扩散策略（diffusion policy）的流匹配策略 |
| HW2 策略梯度 | 实现策略梯度算法 |
| HW3 Q 学习与演员-评论家 | 离散动作空间用深度 Q 网络（DQN），连续动作空间用软演员-评论家（SAC） |
| HW4 大模型强化学习 | 用强化学习训练语言模型；默认在云端 GPU 平台 Modal 上跑（需要 H100 这类大显卡） |
| HW5 离线强化学习 | 实现离线强化学习算法 |

**期末项目**：可以自选题目，也可以做两个默认项目之一——“离线到在线强化学习”或“大模型强化学习”，说明文档都在课程主页和仓库里。

不在伯克利选课的人，官方提供了一个 Reddit 论坛（r/berkeleydeeprlcourse）用来讨论。

## 学习建议

- **每个算法都从目标函数推一遍。** 这门课的讲法是先写出要优化的目标，再推导出梯度或更新规则。自己推一遍，才知道每个算法的假设在哪。
- **HW2 的策略梯度要调通。** 策略梯度对超参数和实现细节很敏感，第一次调通会让你理解为什么后面要引入基线、优势函数和演员-评论家。
- **强化学习训练慢、方差大，多跑几个随机种子。** 一次跑不好不一定是代码错了，看几次的平均表现再下结论。
- **看往年录像补充。** 课程主页链接了 2023 年秋季的完整录像，和 2026 年的内容大部分重合。
