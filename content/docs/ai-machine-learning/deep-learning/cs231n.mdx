## 课程简介

CS231n 是计算机视觉方向流传最广的公开课，
最初由李飞飞团队开设，现在的标题是 Deep Learning for Computer Vision。

课程从图像分类问题入手，先讲最近邻与线性分类器，
再引出损失函数与优化，然后是反向传播与神经网络、
卷积神经网络的结构与训练技巧（初始化、批归一化、数据增强、迁移学习）、
经典网络架构，之后是检测与分割、循环网络与注意力、
生成模型（GAN、扩散模型），以及自监督学习。

它最被称道的是作业：三次作业要求你用 NumPy 从零实现
反向传播、全连接网络、卷积层与批归一化，
之后才允许用框架。亲手实现过一遍梯度计算，
对后面读任何论文都有帮助。

## 先修要求

- 需要 Python 与 NumPy 能力。
- 需要线性代数、微积分与基础的机器学习概念。
