## 课程简介

这是吴恩达在 Coursera 上的深度学习专项，由五门课组成，
是深度学习领域流传最广的入门课。

第一门讲神经网络与深度学习的基础——前向与反向传播、
浅层与深层网络。第二门讲怎么把网络训练好：
初始化、正则化、Dropout、梯度检验、优化算法、超参数调优、批归一化。
第三门讲机器学习项目的工程决策——怎么划分数据、
怎么定位误差来源、什么时候该用迁移学习。
第四门是卷积神经网络与计算机视觉。第五门是序列模型：
RNN、LSTM、注意力机制与 Transformer。

第三门课在同类课程里比较少见：它讲的不是模型，
而是做深度学习项目时的判断力，非常实用。

## 先修要求

- 需要 Python 编程能力与基础的线性代数。
- 建议先完成一门机器学习入门课程。
