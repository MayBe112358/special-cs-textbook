## 课程简介

CS224w 讲的是当数据本身是一张图时——社交网络、分子结构、
知识图谱、推荐系统——机器学习该怎么做。

课程从传统的图特征工程与节点相似度讲起，
然后是图表示学习（node2vec、DeepWalk），
接着进入图神经网络：消息传递框架、GCN、GraphSAGE、GAT，
以及它们的表达能力与局限。后半程讨论知识图谱嵌入、
子图与模体、社区发现、图生成模型，
以及在推荐系统和科学计算中的应用。

这门课的一个特点是理论与应用并重：
既会讨论 GNN 的表达能力（和 WL 检验的关系），
也会给出在真实大规模图上的工程做法。作业分编程和书面两类。

## 先修要求

- 需要 Python 编程能力。
- 需要线性代数、概率与基础的机器学习概念。
