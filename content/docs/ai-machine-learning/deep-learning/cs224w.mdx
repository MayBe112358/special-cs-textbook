## 课程简介

CS224W（Machine Learning with Graphs）是斯坦福的图机器学习课，由 Jure Leskovec 讲授，2026 年秋季正在开课。

图（网络）无处不在：社交网络、知识图谱、分子结构、推荐系统里的用户和商品、交通路网……
这门课讲怎么在图上做机器学习：先学怎么把节点和图表示成向量（节点嵌入），再学图神经网络（GNN）怎么通过“消息传递”聚合邻居信息，
以及 GNN 的表达能力有多强、怎么设计更强的图编码器。后半段讲各种应用和前沿：异构图、知识图谱、推荐系统、关系型数据库上的深度学习、
图基础模型、图生成模型。

每一讲在课程主页上都附了几篇**原始论文**作为选读，比如 DeepWalk、node2vec、GraphSAGE、GIN（《How Powerful Are Graph Neural Networks?》）、LightGCN、GraphRNN。

## 先修要求

课程主页写的先修：

- 计算机基础：能写一个有一定规模的程序（推荐 CS107 或 CS145）。
- 基础概率论（CS109 或 Stat116 足够，但不是必须）。
- 基础线性代数（Math 51 等任一门都绰绰有余）。

开学头几周有复习课讲这些背景。虽然主页没把深度学习列为先修，但作业直接用 PyTorch 写 GNN，
学过 [吴恩达机器学习](/docs/ai-machine-learning/machine-learning/coursera-machine-learning) 或 [CS231n](/docs/ai-machine-learning/deep-learning/cs231n) 这类课会轻松很多。

## 课程结构

2026 年秋季 19 讲：

| 部分 | 讲什么 |
|---|---|
| 表示学习 | 导论；节点嵌入（DeepWalk、node2vec） |
| 图神经网络 | GNN 基础；GNN 的一般视角与设计空间；GNN 的增强与训练；GNN 理论（表达能力）；设计更强的图编码器；图 Transformer |
| 复杂图 | 异构图；知识图谱 |
| 应用 | 推荐系统中的 GNN；关系型深度学习（在关系数据库上直接学习）及其进阶结构 |
| 前沿 | GNN 进阶话题；知识图谱的基础模型；图 AI 前沿（两讲）；图的深度生成模型；总结 |

期中之后有一次线下考试，学期里还有一个课程项目。

## 官方作业

以 2025 年秋季（最近一个完整学期）为准：

- **Colab 0～5**：Google Colab 编程作业，从图的基本操作开始，一步步用 PyTorch 和 PyTorch Geometric 实现节点嵌入、GNN、异构图、知识图谱等。
  Colab 链接直接公开在课程日程里，打开就能在浏览器里跑。
- **Homework 1～3**：书面作业，偏理论推导，题目 PDF 和 LaTeX 模板都能在课程主页下载。
- **课程项目**：用图机器学习解决一个实际问题，要交项目提案。项目说明和评分标准在课程网站的 Projects 页。

## 学习建议

- **先做 Colab。** 这门课的 Colab 写得非常细，边读边填空，做完 Colab 0～2 基本就会用 PyG 搭 GNN 了。
- **每讲读一篇选读论文。** 课程主页每讲都挑好了论文，GIN 那篇（GNN 的表达能力和图同构测试的关系）尤其值得读。
- **把消息传递写一遍。** 不用 PyG，自己用 PyTorch 实现一个两层 GCN，理解邻接矩阵归一化和聚合在做什么。
- **看往届课程网站找灵感。** 课程主页说往届的幻灯片和项目报告都在存档网站上，是很好的“图机器学习能做什么”的例子。
