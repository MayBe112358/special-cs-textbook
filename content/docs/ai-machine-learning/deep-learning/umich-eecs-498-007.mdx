## 课程简介

这门课由 Justin Johnson 讲授——他是 CS231n 早期的助教之一，
所以课程结构和 CS231n 很像，但内容更新、覆盖面更全。

课程从图像分类、线性分类器与优化讲起，
接着是神经网络与反向传播、卷积网络、训练技巧、
经典网络架构，然后是目标检测与分割、循环网络与注意力、
Transformer、三维视觉、视频理解、生成模型（GAN、
自回归模型、扩散模型），最后是可视化与模型理解。

对自学者友好的一点是：课程不假设你有任何深度学习框架的使用经验，
前几次作业会从零教你怎么用 PyTorch，
再逐步让你自己搭建和训练讲座里出现的模型。
六个 Assignment 加一个 Mini-Project，难度由浅入深。

## 先修要求

- 需要 Python 基础。
- 需要微积分与线性代数，熟悉矩阵求导即可。
