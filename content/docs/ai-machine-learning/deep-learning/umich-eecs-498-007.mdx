## 课程简介

EECS 498-007 / 598-005 Deep Learning for Computer Vision 是密歇根大学的视觉深度学习课，由 **Justin Johnson** 讲授。
他读博时是斯坦福 [CS231n](/docs/ai-machine-learning/deep-learning/cs231n) 的讲师之一，所以这门课的结构和 CS231n 很像，
部分讲次的阅读材料直接用 CS231n 的讲义笔记。

课程 2019 年秋季第一次开，2020 年秋季、2022 年冬季（课号改为 498.008 / 598.008）又各开了一次。
**2019 年秋季的 22 讲录像公开在 YouTube 上**，这也是这门课在校外流传最广的原因；后两次的录像只对密歇根的学生开放。

它的特点是**作业不用现成的层**：前几个作业用 PyTorch 的张量运算自己写 kNN、线性分类器、全连接网络、卷积网络和反向传播，
到第四个作业才开始用 autograd，然后一路做到图像描述、目标检测和生成模型。课程不假设你用过深度学习框架，第一个作业就是 PyTorch 入门。

注意：**课程网站 web.eecs.umich.edu/~justincj 已经下线**（2026-09 核对为 404），下面的课程页、作业说明都链到互联网档案馆的存档。

## 先修要求

课程大纲列的是“有助于学好这门课的能力”：

- 编程：熟练使用 Python，数据结构与算法达到密歇根 EECS 281 的水平；熟悉 NumPy 有帮助但不强制。
- 概率：学过概率分布、随机变量、期望等（EECS 401 或 MATH 425 的水平）。
- 向量微积分：要能对向量值函数求梯度。
- 机器学习：学过 EECS 445 这样的机器学习课有帮助，但不强制，课上会复习需要的概念。

## 课程结构

公开录像对应的 2019 年秋季共 22 讲，外加两次客座讲座（视觉与语言、对抗攻击）：

| 部分 | 讲什么 |
|---|---|
| 基础 | 课程导论；图像分类（kNN、超参数、交叉验证）；线性分类器（Softmax、SVM）；优化（SGD、动量、Adam） |
| 神经网络 | 全连接网络与万能逼近；反向传播与计算图；卷积网络；CNN 架构（AlexNet、VGG、ResNet 等）；硬件与软件（GPU、PyTorch、TensorFlow） |
| 训练 | 训练神经网络（一）（二）：激活函数、初始化、数据增强、正则化、学习率、迁移学习 |
| 序列与注意力 | 循环网络（RNN、LSTM、图像描述）；注意力与 Transformer |
| 视觉任务 | 可视化与理解（特征可视化、对抗样本、风格迁移）；目标检测；图像分割；3D 视觉；视频 |
| 生成与决策 | 生成模型（一）（二）：自回归模型、VAE、GAN；强化学习 |
| 总结 | 课程回顾与计算机视觉的未来 |

2022 年冬季版扩成 25 讲，新增了 CNN 架构（二）、Vision Transformer、自监督学习几讲，去掉了强化学习。

评分（2020 年秋季）：六个作业共 70%（第一个 10%，其余各 12%），期中考试 30%。

## 官方作业

2020 年秋季的六个作业（全部在 Google Colab 上做，代码写在 `.py` 文件里，Notebook 负责引导和测试）：

| 作业 | 内容 |
|---|---|
| A1 | PyTorch 101（张量基础）；kNN 分类器 |
| A2 | 多类 SVM、Softmax 分类器；两层神经网络；数值梯度检验 |
| A3 | 模块化的全连接网络与卷积网络；各种优化器；批归一化；Dropout |
| A4 | 用 autograd 和 `nn.Module` 实现 ResNet；RNN/LSTM 加注意力做图像描述；网络可视化；风格迁移 |
| A5 | 目标检测：类似 YOLO 的单阶段检测器、类似 Faster R-CNN 的两阶段检测器（PASCAL VOC 2007） |
| A6 | 生成模型：在 MNIST 上实现 VAE 和 GAN |

2022 年冬季版的作业顺序有调整：A4 是检测，A5 是图像描述加一个做简单算术的 Transformer，A6 是生成模型加可视化与风格迁移；
另外新增了一个 **Mini-Project**，从图像分类、单图超分辨率、NeRF 新视角合成里选一个（也可以自己提），交一份像论文一样有文字、有代码、有结果的 Notebook。

作业原本用 autograder.io 自动评分，校外用不了；存档里能下到部分作业的起始代码压缩包，但**不是每一个都存下来了**。

## 学习建议

- **跟着 2019 年的录像学。** 这是唯一公开的一版，内容和作业基本对得上；2022 年的新讲次（ViT、自监督学习）可以去 [CS231n](/docs/ai-machine-learning/deep-learning/cs231n) 补。
- **A2、A3 一定要自己写。** 手写每层的前向和反向传播、再用数值梯度检验，是这门课最有价值的训练。写完 A3 再用 autograd，就知道框架替你做了什么。
- **别急着上 autograd。** 前三个作业故意不让用，就是为了让你把反向传播彻底弄懂。
- **做作业前先找存档。** 作业说明和起始代码都在互联网档案馆里，先确认你要做的那一个下得到。
