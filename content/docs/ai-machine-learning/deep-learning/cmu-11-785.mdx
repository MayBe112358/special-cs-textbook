## 课程简介

11-785 是 CMU 的深度学习核心课，风格扎实、节奏快，
几乎没有可以略过的内容。

课程从神经网络基础出发：感知机、多层网络、通用逼近定理、
反向传播的严格推导，然后是优化与正则化、
卷积网络、循环网络与序列建模、
注意力机制与 Transformer，最后是生成模型与表示学习。

它的作业强度是出了名的：不只是把模板跑通，
而是要求你理解模型行为、训练细节和实验设计。
每次作业通常分两部分——一部分从零实现组件，
一部分在真实数据集上训练并冲榜（Kaggle 形式）。

如果你想建立的是长期可迁移的深度学习能力，
而不只是会调几个现成 API，这门课的投入产出比很高。

## 先修要求

- 需要线性代数、概率论与 Python 编程能力。
- 需要机器学习基础。
