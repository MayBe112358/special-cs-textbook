## 课程简介

11-785（Introduction to Deep Learning）是卡内基梅隆大学语言技术研究所的深度学习课，每个春季和秋季都开，
课号还有 11-485（本科，不做项目）和 11-685。课程网站每学期都更新，最新是 **2026 年秋季**。

这门课以**强度大、作业硬**出名。它的讲法很“从底层往上”：前八讲都在讲神经网络为什么能工作、怎么训练——
万能近似定理、经验风险最小化、梯度下降、反向传播的微积分、收敛问题与损失曲面、动量、各种优化器、损失函数的选择、批归一化、Dropout，
然后才进入各种网络结构。

作业的设计也很特别：每个作业分两半。
**Part 1** 要你从零实现一个深度学习模块（不用 PyTorch 的现成层），
**Part 2** 是一场班内的 Kaggle 比赛，用 PyTorch 在真实数据上把效果做到尽量好，成绩按排行榜分档。

## 先修要求

- 线性代数、概率论、微积分（反向传播那几讲会做大量矩阵求导）。
- 扎实的 Python 编程；Part 2 要熟练使用 PyTorch，课程安排了配套的习题课和训练营（Recitations & Bootcamps）带你上手。
- 学过机器学习基础会轻松很多，比如 [吴恩达机器学习专项课程](/docs/ai-machine-learning/machine-learning/coursera-machine-learning)。

## 课程结构

2026 年秋季共 28 讲：

| 部分 | 讲什么 |
|---|---|
| 基础 | 导论；神经网络是万能近似器 |
| 训练（六讲） | 学习问题与经验风险最小化；梯度下降；反向传播的微积分；收敛问题、损失曲面与动量；批大小、SGD、二阶方法；优化器与正则、损失函数、批归一化、Dropout |
| 卷积网络 | CNN（四讲） |
| 循环网络与序列 | RNN（两讲）；序列到序列模型与 CTC；CTC 的空白符与束搜索；语言模型与机器翻译 |
| 注意力与大模型 | 注意力模型与 Transformer；Transformer 与新架构；大语言模型 |
| 生成模型 | 表示学习与自编码器；变分自编码器；标准化流与扩散模型；生成对抗网络 |
| 其他 | 图神经网络；Hopfield 网络；玻尔兹曼机；四个作业的复盘与部署 |

评分：作业 50%、每周小测 24%（14 次取最好的 12 次）、课程项目 25%（11-485 不做项目）、出勤 1%。

## 官方作业

四个作业，按 2026 年春季的安排：

| 作业 | Part 1：从零实现 | Part 2：Kaggle 比赛 |
|---|---|---|
| HW1 | 实现并训练多层感知机 | 用 MLP 做音素状态标注 |
| HW2 | 实现并训练卷积网络 | 用 CNN 做人脸验证 |
| HW3 | 实现 RNN、GRU、CTC 与 CTC 解码 | 自动语音识别 |
| HW4 | 实现注意力，训练一个只有解码器的 Transformer | 用编码器-解码器 Transformer 做语音识别 |

每个作业还有加分题（比如自己实现自动微分）。Part 2 的分档线按排行榜定，大致分高（90%）、中（70%）、低（50%）、很低（30%）几档。

- **每周小测**：一般周五发，48 小时内完成。
- **课程项目**：11-785 学生必做，要交中期报告、项目视频和期末报告。

**校外自学要注意**：作业材料通过 CMU 的 Canvas 和 Autolab 发布，**校外拿不到**。
公开的是讲课录像（每讲都链接到 YouTube）、幻灯片和习题课材料。

## 学习建议

- **前八讲一定要看完再往后。** 这门课最有价值的是“训练”那六讲，把神经网络为什么难训练、每种技巧解决什么问题讲得非常透。
- **自己实现一遍 Part 1 的内容。** 虽然拿不到官方作业，但“从零写 MLP、CNN、RNN、注意力”这件事本身可以照着讲义做。
  可以参考 [Karpathy 从零到英雄](/docs/ai-machine-learning/artificial-intelligence/neural-networks-zero-to-hero) 的做法，用 NumPy 或最朴素的 PyTorch 张量写。
- **找一个 Kaggle 比赛当 Part 2。** 选一个语音、图像或文本的公开比赛，把讲课里的训练技巧一个个用上去，看分数怎么变。
- **习题课别跳。** 官方的 Recitations 和 Bootcamps 专门讲 PyTorch 实操、调试和作业技巧。
