## 课程简介

这是纽约大学数据科学中心的研究生课 DS-GA 1008 Deep Learning，2021 年春季由 **Yann LeCun**（图灵奖得主、卷积网络的提出者）和 **Alfredo Canziani** 共同讲授：
LeCun 上理论课，Canziani 上配套的实践课（practicum）。讲课录像、幻灯片、Notebook 都公开在[课程网站](https://atcold.github.io/NYU-DLSP21/)上。

和别的深度学习课最大的不同是它的**视角**：2021 年版把“**隐变量能量模型**”（latent-variable energy-based model，LV-EBM）当作基础模块，
后面的自编码器、GAN、自监督学习、控制都放在这个框架里讲。Canziani 在仓库说明里写得很直白：学生已经学过 EBM，
再照去年的方式讲后半学期就“不诚实”了，所以他把后半学期的幻灯片全部重做。

讲解兼顾理论和直觉，整体偏研究导向，适合已经学过一门入门课、想提升“问题意识”和“建模品味”的人。

## 先修要求

- 官方先修：NYU 的 DS-GA 1001 数据科学导论，**或一门研究生水平的机器学习课**。
- 数学：线性代数、多元微积分、概率论要熟，课上大量用向量和矩阵的记号推导。
- 编程：Python 和 PyTorch 基础。实践课的 Notebook 用 PyTorch，从张量讲起。

## 课程结构

2021 年版按主题组织，前半学期三个主题，每个主题两周、后面跟一次作业：

| 主题 | 讲什么 |
|---|---|
| 1. 导论 | 历史与资源；梯度下降与反向传播；神经网络的推理与训练（螺旋分类） |
| 2. 参数共享 | 循环网络与卷积网络；卷积网络实践；自然信号的性质与卷积；RNN 与 LSTM |
| 3. 能量模型基础 | 能量模型（一）（二）；隐变量 EBM 的推理与训练 |
| 4. 能量模型进阶 | 无监督学习与自编码器；从隐变量 EBM 到目标传播再到自编码器；用 PyTorch 写自编码器与 GAN；联合嵌入方法（对比式与正则化式） |
| 5. 联想记忆 | 注意力与 Transformer |
| 6. 图 | 图 Transformer 网络（语音识别）；图卷积网络 |
| 7. 控制 | 规划与控制；倒车入库问题（Truck Backer-Upper）；不确定性下的预测与规划 |
| 8. 优化 | 优化（一）（二） |
| 其他 | 视觉中的自监督学习；低资源机器翻译（Marc'Aurelio Ranzato 的客座讲座）；拉格朗日视角的反向传播 |

官方估计每周约 2.5～3 小时视频，加上记笔记和跑 Notebook，每周 5 小时左右。

## 官方作业

- **三次作业**，都放在网站上的 Google Drive 文件夹里，对应前半学期的三个主题：
  - **Homework 1**：反向传播。
  - **Homework 2**：RNN 与 CNN。
  - **Homework 3**：结构化预测。
- **Jupyter Notebook**：螺旋分类、回归、卷积网络、序列分类、自编码器、VAE、倒车入库控制、Transformer 等，
  分散在 [2021 仓库](https://github.com/Atcold/NYU-DLSP21)和 [2020 仓库](https://github.com/Atcold/NYU-DLSP20)里，网站上每讲旁边都标了对应的 Notebook。

没有自动评分，也没有公开的参考答案。官方 FAQ 明说这门课**不提供证书**，内容也不是按能给校外学生评分来设计的。

## 学习建议

- **以视频为准，网站为辅。** 官方 FAQ 特意提醒：网站上的文字是学生记的课堂笔记，视频里有更多例子、学生提问和论文出处。点网页上的段落标题可以直接跳到视频对应的位置。
- **Notebook 自己跑一遍。** 2020 仓库的说明里有用 Miniconda 建环境的步骤（`conda env create -f environment.yml`）。
- **先学一门常规深度学习课再来。** 这门课的能量模型框架和别的课讲法差别很大，已经熟悉 CNN、RNN、反向传播之后再看，更能体会它换了什么视角。
- **想要更全的文字材料，看 2020 年版。** 2020 年版讲义更完整，还被译成十几种语言，包括[中文](https://atcold.github.io/NYU-DLSP20/zh/)。
- **有问题在 YouTube 评论区问。** FAQ 说 Canziani 会在视频下面回答，记得带上时间戳；也可以去课程的 Discord。
