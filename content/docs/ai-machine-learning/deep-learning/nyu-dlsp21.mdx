## 课程简介

这门课最具辨识度的地方是授课者：Yann LeCun 亲自讲授，
对多数人来说，这是极少见的、能完整听到顶级学者从一线研究者视角
讲解深度学习的公开资源。

课程按周组织，内容包括：监督学习与反向传播的几何直觉、
参数化模型与能量模型、卷积网络及其在信号处理上的动机、
循环网络与注意力、自监督学习、生成模型与隐变量模型、
图神经网络，以及基于能量的方法这一 LeCun 本人主张的框架。

讲解兼顾理论与直觉，整体偏研究导向，
适合已经完成入门课、想提升“问题意识”和“建模品味”的人。
把它作为主线课程之外的高质量补充会很有价值。
课程网站提供文字版讲义，且有多语言翻译。

## 先修要求

- 需要线性代数与概率论。
- 需要 Python 编程能力与基础的深度学习概念。
