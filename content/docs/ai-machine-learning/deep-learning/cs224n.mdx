## 课程简介

CS224N（Natural Language Processing with Deep Learning）是斯坦福的自然语言处理课，**2026 年冬季**由 Diyi Yang 和 Yejin Choi 讲授。

课程主页的介绍：自然语言处理是人工智能的关键部分，应用无处不在——网页搜索、广告、邮件、客服、机器翻译、虚拟助手、医疗报告、政治……
2010 年代深度学习方法在很多 NLP 任务上取得了很高的性能；2020 年代，大语言模型（比如 ChatGPT）的规模化又带来了惊人的进步。
这门课全面介绍 NLP 深度学习的前沿研究，通过讲课、作业和期末项目，让学生掌握为 NLP 问题设计、实现、理解自己的神经网络模型的能力，
并接触大语言模型的前沿研究。

2026 年的内容非常新：讲完词向量、反向传播、RNN 和 Transformer 这些基础后，
一半的课在讲大模型——预训练（规模化、系统、数据）、后训练（RLHF、SFT、DPO）、高效适配（提示与参数高效微调）、
智能体与工具调用和 RAG、评测、推理，还有一系列客座讲座（分词与多语言、可解释性、多模态，以及 John Schulman 讲 LoRA）。

## 先修要求

课程主页写的先修：

- **熟练的 Python**：所有作业都用 Python（NumPy 和 PyTorch）。第一周有 Python 复习课；主页说有其他语言丰富经验的人一般也没问题。
- **微积分与线性代数**（如 MATH 51）：要能熟练求多元导数，熟悉矩阵和向量的记号与运算。
- **基础概率统计**（如 CS109）：概率、高斯分布、均值、标准差等。
- **机器学习基础**（如 CS221、CS229、CS230 或 CS124）：会写代价函数、求导、用梯度下降优化。

## 课程结构

2026 年冬季，每周两讲，另有周五的辅导课：

| 周 | 讲什么 |
|---|---|
| 1 | NLP 的历史；词向量；Python 复习 |
| 2 | 反向传播与神经网络基础；语言模型与 RNN；PyTorch 教程 |
| 3 | Transformer；期末项目介绍与实用建议 |
| 4 | 预训练（规模化、系统、数据）；后训练（RLHF、SFT、DPO） |
| 5 | 高效适配（提示与 PEFT）；智能体、工具调用与 RAG；Hugging Face 教程 |
| 6 | 评测与基准；推理（一） |
| 7 | 推理（二）；客座讲座：分词与多语言 |
| 8 | 客座讲座：可解释性；NLP 的社会影响与风险 |
| 9 | 客座讲座：多模态；客座讲座：Tinker 与 LoRA |
| 10 | 2026 年 NLP 的开放问题；期末项目海报展示 |

评分：作业 48%（四份），期末项目 49%（提案 8%、中期 6%、海报 3%、报告 32%）。

## 官方作业

**四份作业的代码包和说明 PDF 都能在课程主页直接下载**（`assignments_w26/` 目录下）：

| 作业 | 占比 | 内容 |
|---|---|---|
| A1 | 6% | 词向量入门（Notebook） |
| A2 | 14% | 神经网络基础、张量求导、依存句法分析 |
| A3 | 14% | 自注意力与 Transformer |
| A4 | 14% | 大语言模型的基准测试与评估 |

**期末项目（49%）** 有两种选择：

- **默认项目**：自己实现 GPT-2 架构的关键部分，再用它解决三个下游任务。说明文档《Build GPT-2》是公开的。
  （2024 年春季的默认项目基于 BERT，现在换成了 GPT-2。）
- **自选项目**：任何和人类语言与深度学习相关的课题，会分配一位导师。

可以一个人做，也可以最多三人一组，官方强烈建议组队。项目要交提案、中期报告和期末报告，说明文档都在主页上。

校外旁听的人作业不会被批改（主页说因为选课人数太多，只能批改正式选课学生的作业），但所有材料都可以自己做。

## 学习建议

- **A2 的张量求导一定要手推。** 这是很多人第一次在矩阵层面推反向传播，推一遍之后，后面的 Transformer 和大模型就不再神秘。
- **做默认期末项目。** 自己写 GPT-2 的注意力、前馈层、位置编码，再在下游任务上微调，是这门课最接近“真正理解大模型”的一步。
- **配合往年录像。** 主页链接了 2024 年的 YouTube 播放列表，基础部分（词向量、RNN、Transformer）讲得和今年大同小异；大模型的新内容看今年的幻灯片。
- **读讲义里的笔记。** 前几讲除了幻灯片还有讲义笔记（notes），推导比幻灯片完整。
