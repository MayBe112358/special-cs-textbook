## 课程简介

CS224n 是 Stanford 的自然语言处理课，由 Chris Manning 领衔。
它几乎是这个方向最被推荐的一门公开课，并且每年跟着领域一起更新。

课程从词向量开始（word2vec、GloVe），
接着是神经网络基础与反向传播、依存句法分析、
循环网络与 LSTM、机器翻译与序列到序列模型、注意力机制，
然后是 Transformer、预训练语言模型、大模型的提示与微调，
以及问答、代码生成等应用，最后讨论模型分析与伦理问题。

五次编程作业难度循序渐进：词向量、word2vec 实现、
依存分析、神经机器翻译、Transformer 微调。
最终的大作业是在 SQuAD 这类基准上做一个完整项目。

## 先修要求

- 需要 Python 编程能力。
- 需要线性代数、概率与基础的深度学习概念。
