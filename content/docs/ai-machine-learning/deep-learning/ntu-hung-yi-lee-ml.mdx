## 课程简介

李宏毅老师的这门课挂着“机器学习”的名字，但内容之广令人吃惊，
实际上是一门覆盖现代深度学习全景的中文课程。

作业列表最能说明覆盖范围：回归、分类、卷积网络、自注意力、
Transformer、生成对抗网络、BERT、异常检测、可解释 AI、
对抗攻击、领域自适应、强化学习、终身学习、元学习，
近年版本还加入了大语言模型相关的内容。

讲课风格轻松幽默，幻灯片里常出现宝可梦之类的动漫元素，
但内容并不因此变浅。对中文母语的学习者来说，
这是理解深度学习概念最省力的路径之一。

课程每年更新，不同年份的作业和主题会有调整。

## 先修要求

- 需要熟练掌握 Python。
- 需要基础的线性代数与概率概念。
