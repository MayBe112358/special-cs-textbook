## 课程简介

这是吴恩达在 Coursera 上的机器学习专项课程，由三门课组成，
是很多人进入这个领域的第一站。

第一门讲监督学习：线性回归、逻辑回归、梯度下降、正则化。
第二门讲进阶的监督学习方法：神经网络、决策树与集成方法，
以及模型评估和调优的实践建议。第三门讲无监督学习、
推荐系统与强化学习入门。

这套课的长处是讲解方式：吴恩达有一种把复杂概念讲成算术题的能力，
对新手极其友好。作业用 Python 和 NumPy 在 Jupyter Notebook 里完成，
有自动评分。

它的定位是入门，数学推导点到为止。想深入理论的话，
CS229 是同一位老师面向研究生的版本。

## 先修要求

- 需要基础的 Python 编程能力。
- 需要高中数学；线性代数基础会更顺。
