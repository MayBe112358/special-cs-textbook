## 课程简介

CS189/289A 是伯克利的机器学习导论，官方描述是把数学严谨性与实践经验结合起来，
覆盖完整的机器学习流程——从问题建模、处理数据，到设计和优化模型。

内容包括：概率与优化基础、聚类与隐变量模型、降维、
回归与分类（线性模型、支持向量机、决策树与集成方法）、
神经网络，以及现代深度学习架构。

和 CS229 相比，这门课对自学者更友好的一点是：
它把所有作业代码和 Gradescope 的自动评分脚本都开源了，
意味着你能在本地得到和选课学生一样的反馈。
课程讲义也写得相当理论化，可以当参考书用。

## 先修要求

- 指南列出的学前准备是 CS188 与 CS70。
- 需要线性代数、概率与多元微积分，以及 Python 能力。
