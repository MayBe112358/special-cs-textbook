## 课程简介

CS189/289A（Introduction to Machine Learning）是伯克利的机器学习导论，本科生选 CS189，研究生选 CS289A（多一个研究项目）。
2026 年秋季由 Narges Norouzi 和 Joseph Gonzalez 讲授。

课程大纲的介绍：机器学习是现代人工智能的核心，正在改变视觉、语言、机器人、推荐系统等领域解决问题的方式。
这门课介绍机器学习的**理论基础、算法和应用**，把数学上的严谨和实践经验结合起来，
覆盖从问题建模、处理数据，到设计模型、优化模型的完整流程。

这门课近两年改版很大，**深度学习占了一半以上**：大纲写明会讲神经网络基础、PyTorch 实现、反向传播、批归一化、初始化与正则化，
然后是 CNN、RNN、Transformer，以及大语言模型、自编码器、GAN 等生成模型。
2026 年秋季的日程最后还有“后训练”（微调、LoRA、参数高效微调、蒸馏）和扩散模型。

教材也换了：2026 年秋季的必读教材是 Christopher Bishop 和 Hugh Bishop 的《Deep Learning: Foundations and Concepts》（Springer，2024）。

## 先修要求

大纲写的是“需要扎实的数学和编程准备”，必修先修有三门：

- 多元微积分：MATH 53
- 线性代数：MATH 54 或同等课程（可以看 [MIT 18.06](/docs/mathematics/mit-18-06)）
- 概率与离散数学：[CS70](/docs/advanced-mathematics/cs70) 或同等课程

第三周的讨论课专门做一次线性代数和概率的复习。

## 课程结构

2026 年秋季共 27 讲：

| 部分 | 讲什么 |
|---|---|
| 基础 | 导论与机器学习问题建模；KNN、机器学习术语、K-means；降维 |
| 概率模型 | 概率与密度估计；密度估计与高斯混合模型 |
| 经典模型 | 线性回归；偏差-方差权衡与正则化；逻辑回归（两讲）；梯度下降（两讲） |
| 神经网络 | 非线性、结构、激活函数、输出层与损失；反向传播；批归一化、初始化与正则化；另外两讲 |
| 深度结构 | 卷积神经网络；Transformer；大语言模型（两讲）；注意力方法 |
| 强化学习 | 马尔可夫决策过程与强化学习（两讲） |
| 前沿 | 客座讲座；后训练：微调、LoRA、PEFT、蒸馏；扩散模型；总结 |

评分（CS189）：作业 35%、期中 25%、期末 30%、课堂出勤 10%。CS289A 的作业和考试比例略低，另有一个研究生期末项目。

## 官方作业

- **Homework 1～5**：每份跨三周，分两部分：先是热身部分，然后是更深入的主体部分。
  作业里既有数学推导，也有编程任务；编程部分在 Pensive 平台上提交，**有公开测试和隐藏测试**，
  官方说公开测试“主要是基本检查”（比如答案是不是一个数字），真正判对错的是隐藏测试。
- **讨论课**：每周一份练习，主题跟着讲课走（机器学习问题建模、数学复习与 KNN/K-means、密度估计与高斯混合模型……）。
- **课堂示例**：讲课用的 Notebook 放在公开的 GitHub 仓库 [BerkeleyML/fa26-student](https://github.com/BerkeleyML/fa26-student) 的 `lecture` 目录里。

作业题目通过课程平台发布，校外能拿到的主要是讲课材料和讨论课题目；课程主页顶部还有一个课程资料的 Google Drive 链接。

## 学习建议

- **先把三门先修补齐。** 这门课的推导默认你熟悉矩阵求导、特征分解和条件概率。数学不熟的话，先看 [MIT 18.06](/docs/mathematics/mit-18-06) 和 [CS70](/docs/advanced-mathematics/cs70) 的概率部分。
- **配着 Bishop 的教材读。** 讲课节奏快，教材的推导完整、图也画得好。
- **梯度下降和反向传播自己推一遍。** 这两讲是后面所有深度学习内容的基础，推导一次比看十遍幻灯片管用。
- **动手写 PyTorch。** 讲课的 Notebook 都公开，跟着跑一遍，再改几个超参数看看效果怎么变。

- **[Stanford CS229](/docs/ai-machine-learning/machine-learning/cs229)**：斯坦福的研究生机器学习课，偏经典机器学习理论（学习理论、核方法、EM），数学推导更重。
  CS189 现在更偏深度学习和大模型。
- **[吴恩达机器学习专项课程](/docs/ai-machine-learning/machine-learning/coursera-machine-learning)**：零基础入门，数学淡化。

- 学完想专攻深度学习，接 [CS231n](/docs/ai-machine-learning/deep-learning/cs231n)（视觉）或 [CS224n](/docs/ai-machine-learning/deep-learning/cs224n)（语言）。
