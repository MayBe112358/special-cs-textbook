## 课程简介

CS229（Machine Learning）是斯坦福最有名的机器学习课，每个季度都开，不同学期由不同老师讲；
2018 年秋季吴恩达（Andrew Ng）讲授的版本有完整的公开录像。

课程主页的介绍：这门课广泛介绍机器学习和统计模式识别。主题包括：监督学习（生成式学习、参数与非参数学习、神经网络）；
无监督学习（聚类、降维）；学习理论（偏差-方差权衡、实践建议）；强化学习与自适应控制。
还会讨论机器学习最近的应用，比如机器人控制、数据挖掘、自主导航、生物信息、语音识别、文本和网页数据处理。

这门课的核心材料是 **Tengyu Ma 和吴恩达写的官方讲义**（[main_notes.pdf](https://cs229.stanford.edu/main_notes.pdf)），
2026 年的版本有 278 页，分六部分：监督学习、深度学习、泛化与正则化、无监督学习、生成模型与基础模型、强化学习与控制。
推导写得非常完整，很多人不上课也专门读这份讲义。

## 先修要求

课程主页写的先修：

- 计算机基础：能用 Python/NumPy 写一个“有一定规模”的程序，相当于斯坦福 CS106A 或 CS106B。
- 概率论：相当于 CS109 或 MATH151。
- 多元微积分和线性代数：相当于 MATH51 或 CS205L。

官方还提供 Problem Set 0（不计分）用来自测。数学是这门课的门槛：讲义里大量用到矩阵求导、多元高斯分布、拉格朗日对偶。
线性代数不熟的话先看 [MIT 18.06](/docs/mathematics/mit-18-06)，概率不熟先看 [CS70](/docs/advanced-mathematics/cs70) 的后半部分。

## 课程结构

课程主页上 2026 年冬季学期的日程：

| 部分 | 讲什么 |
|---|---|
| 监督学习 | 监督学习设定与 LMS；加权最小二乘、逻辑回归、牛顿法；数据集划分、指数族与广义线性模型；偏差-方差权衡与正则化 |
| 生成式学习与核方法 | 高斯判别分析、朴素贝叶斯与拉普拉斯平滑；核方法与支持向量机 |
| 无监督学习 | K-means、高斯混合模型、EM 算法；主成分分析 |
| 实践 | 评估指标；决策树；Boosting；机器学习实践建议 |
| 深度学习 | 神经网络（两讲，含反向传播）；卷积网络；Transformer |
| 强化学习 | 基本概念、值迭代与策略迭代；基于模型的强化学习与值函数近似 |
| 大模型与社会 | 大语言模型（学习任务、语言建模、嵌入；RAG、微调、提示优化、安全）；公平性、算法偏见、可解释性与隐私（两讲） |

另有助教讲的复习课：线性代数、概率、Python/NumPy。

## 官方作业

- **Problem Set 0～4**：PS0 是不计分的自测；PS1～PS4 以数学推导为主，配编程实现。
- **期末项目**：自选题目，要交开题提案、中期报告、期末报告，学期末有海报展示。
- **期中考试**。

**课程主页明确写了：课程文档只对斯坦福成员开放**，需要斯坦福邮箱登录才能看，所以当前学期的作业和解答校外拿不到。
校外自学主要靠公开的讲义和 2018 年的录像，练习可以用讲义里的推导自己重做一遍。

## 学习建议

- **以讲义为主线。** 讲义按章节推进，每章的推导都写得很细。读的时候自己在纸上把每一步推出来，比看录像更有效。
- **录像配讲义看。** 2018 年的录像是八年前的版本，经典部分（监督学习、核方法、EM、强化学习）和讲义大体对得上；讲义里基础模型、大语言模型这些新章节，录像里没有。
- **先补数学再开始。** 矩阵求导和多元高斯分布是这门课反复用到的两件工具。讲义第 1 章就有矩阵求导的小节，读不懂就先停下来补。
- **做一个期末项目。** 在校生的期末项目是整门课分量最重的部分。自学时找一个自己感兴趣的数据集，把学到的方法完整走一遍。

## 同类课怎么选

- **[吴恩达机器学习专项课程](/docs/ai-machine-learning/machine-learning/coursera-machine-learning)**：同一位老师的入门版，数学淡化、代码驱动。先学它再学 CS229 会顺很多。
- **[UC Berkeley CS189](/docs/ai-machine-learning/machine-learning/cs189)**：伯克利的对应课，现在更偏深度学习和大模型；CS229 的经典机器学习理论（广义线性模型、核方法、EM、学习理论）讲得更完整。
- 想深入理论，看 [Stanford CS229M](/docs/ai-machine-learning/advanced-machine-learning/stanford-cs229m)（机器学习理论）。
