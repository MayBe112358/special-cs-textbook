## 课程简介

CS229 是吴恩达在 Stanford 开的研究生机器学习课，
和 Coursera 那门入门课是同一位老师、完全不同的深度。

课程从监督学习开始：线性回归的概率解释、逻辑回归、
广义线性模型、生成式学习算法、支持向量机与核方法；
接着是学习理论——偏差方差权衡、VC 维、正则化与模型选择；
然后是无监督学习：k-means、高斯混合与 EM 算法、
主成分分析、独立成分分析；最后是强化学习与控制。

这门课最有价值的资产是它的课程讲义：写得非常专业，
推导完整，被广泛当作工具书查阅。想不满足于调包、
真正理解算法背后的数学，这份讲义值得反复读。

## 先修要求

- 需要扎实的线性代数、概率论与多元微积分。
- 需要 Python 编程能力。
