## 课程简介

GAMES202 接在 GAMES101 之后，专讲实时渲染。
它的核心问题是：实时渲染要求每秒三十帧以上，
在这么苛刻的时间预算下，怎么打破速度与质量之间的权衡？

课程以专题形式组织，覆盖学术界与工业界的前沿做法：
实时软阴影的渲染、环境光照、基于预计算或无预计算的全局光照、
基于物理的着色模型、实时光线追踪、抗锯齿与超分辨率。

和 GAMES101 的全景式介绍不同，这门课每一讲都深入一个具体技术，
会讲清楚它的数学推导、工程取舍以及在真实引擎里的用法。
适合已经理解渲染基本原理、想知道游戏画面是怎么做出来的人。

课程配五个编程作业，同样用 C++ 完成。

## 先修要求

- 需要先完成 GAMES101 或同等的图形学入门课程。
- 需要线性代数、高等数学与 C++ 能力。
