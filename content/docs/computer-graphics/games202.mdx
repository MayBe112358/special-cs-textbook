## 课程简介

GAMES202 是闫令琪在 2021 年春季讲的在线课程，[GAMES101](/docs/computer-graphics/games101) 的续课，中文授课、英文课件，录像在 B 站。

课程主页的介绍：全面介绍现代实时渲染中的关键问题与解决方法。实时渲染要求每秒 30 帧以上，
所以课程关注的是**在苛刻的时间限制下，怎么打破速度与质量之间的权衡**，同时做到实时和照片级真实感。

课程以专题形式组织，覆盖学术界和工业界的前沿内容：实时软阴影、环境光照、基于预计算或不预计算的全局光照、
基于物理的着色模型、实时光线追踪、抗锯齿与超采样，以及常见的加速方法。

和 GAMES101 一样，它**不讲游戏引擎怎么用**，也不特别强调具体的着色器写法，
而是讲实时渲染背后的科学和知识。官方的目标是：学完之后，你有足够深的功底去开发一个自己的实时渲染引擎。

## 先修要求

- 必须：GAMES101 或其他图形学入门课；微积分。
- 非必须：着色器编程基础（GLSL 或 HLSL），课程开始时会快速回顾，并有一个练手的作业 0。
- 推荐教材（非必须）：Akenine-Möller 等人的《Real-Time Rendering》第四版。

## 课程结构

15 讲左右，每讲一小时：

| 专题 | 讲什么 |
|---|---|
| 概述与回顾 | 实时渲染概述；渲染管线、着色语言、渲染方程、微积分基础回顾 |
| 实时阴影 | Shadow Map、PCSS；VSSM、Moment Shadow Map、SDF 阴影 |
| 实时环境光照 | 预滤波与 Split Sum；预计算辐射传输（PRT） |
| 实时全局光照 | 三维空间方法：RSM、LPV、VXGI；屏幕空间方法：SSAO、SSDO、SSR |
| 实时高质量着色 | 微表面模型、GGX、多次弹射近似；Disney 原则化 BRDF、LTC、非真实感渲染 |
| 实时光线追踪 | 反投影、运动向量、时间累积；联合双边滤波、SVGF 等降噪方法 |
| 工业界常用技术 | 抗锯齿与超采样、级联/分块/延迟着色、粒子、引擎等 |

每讲都附有推荐阅读的原始论文，比如 PCSS 那讲推荐 NVIDIA 的《Percentage-Closer Soft Shadows》，PRT 那讲推荐 Ramamoorthi 的综述。

## 官方作业

官方安排 5 次小作业和 1 次大作业，全部编程、提供框架、自愿完成、没有考试。
作业在[课程 BBS 的作业汇总帖](http://games-cn.org/forums/topic/games202zuoyehuizong/)下载，作业 0～3 的说明 PDF 也在课程主页上：

| 作业 | 做什么 |
|---|---|
| 作业 0 | 在 WebGL 框架里跑通并实现 Blinn-Phong 着色，熟悉作业环境 |
| 作业 1 | 实时阴影：两趟 Shadow Map，再实现 PCF 和 PCSS 软阴影 |
| 作业 2 | 预计算辐射传输（PRT）：预计算部分用 C++，实时部分用 WebGL |
| 作业 3 | 屏幕空间光线追踪（SSR）：在屏幕空间里求间接光照 |
| 作业 4 | Kulla-Conty 能量补偿：修正微表面模型（GGX）在粗糙表面上的能量损失 |
| 作业 5 | 实时光线追踪降噪：时间累积与滤波 |

大部分作业用 WebGL 和 JavaScript，在浏览器里就能看到结果，环境比 GAMES101 的 C++ 框架更容易搭。

## 学习建议

- **一定先学完 GAMES101。** 这门课默认你已经懂渲染方程、蒙特卡洛积分、BRDF，不会重讲。
- **每个专题读一篇原始论文。** 课程主页给的阅读材料大多是经典论文，读过之后你会发现课上讲的是论文里最关键的那一两个想法。
- **作业 1 和作业 3 最值得做。** 软阴影和屏幕空间反射是现代游戏里最常见的两项技术，自己实现一次，就会明白它们为什么有那些典型瑕疵。
- **注意“近似”背后的假设。** 实时渲染几乎每个方法都是某种近似，学的时候问自己：它假设了什么？什么情况下会出错？这是这门课最想培养的思维方式。
