## 课程简介

这是中国科学技术大学数学科学学院刘利刚教授开的本科课《计算机图形学》（课程编号 00106501），每年春夏学期开课，
课程主页和作业仓库每年都更新，**最新的是 2026 年春季**。

课程主页写的目标有两条：

- **C++ 编程**：面向对象编程思想、图像编程基础、图形学编程基础。
- **计算机图形学**：几何处理、真实感渲染、物理仿真、角色动画、GPU 编程。

和偏渲染的图形学课相比，这门课的特点是**覆盖面宽、几何处理讲得多**：从图像处理、图像变形、泊松图像编辑讲起，
到曲线曲面拟合、曲面参数化、离散微分几何，再到渲染、仿真和动画。
近两年还加入了深度学习相关的内容：扩散模型与文生图、渲染中的 AI 方法、神经渲染（NeRF、3DGS）、基于 AI 的仿真。

另一个特点是**非常重视编程训练**。作业仓库的说明里写，通过每周一个的系统性编程作业，你能学到：
图形学主要内容的算法实现、OpenGL 渲染管线和 GPU 着色器编程、图像处理算法、C++ 面向对象和基础设计模式、
快速看懂和使用网上的代码与库，以及“从问题到抽象、到数学建模、再到算法实现”的方法。

## 先修要求

- 微积分、线性代数、数据结构。
- C++ 编程。开课前会先布置一套 **C++ 课前热身练习**，官方要求“务必一个一个独立练习，再与参考代码进行对比学习”。
- 作业环境：Visual Studio 2022、CMake 3.27 以上、Git。刘老师还专门写了一篇[《如何自学计算机图形学 & C++ 面向对象编程》](http://staff.ustc.edu.cn/~lgliu/Resources/CG/How_to_Learn_CG&Coding.htm)，开始前值得读。

## 课程结构

2026 年春季共 22 讲：

| 部分 | 讲什么 |
|---|---|
| 编程与图像 | 课程介绍；面向对象编程、数学建模、数据拟合；图像处理；二维光栅化、图像矢量化；泊松图像编辑 |
| 深度学习 | 深度学习、扩散模型、文生图（两讲） |
| 几何 | 参数曲线与隐式曲线拟合、采样和网格；曲面参数化、离散微分几何、数字几何处理 |
| 渲染 | 局部着色模型、阴影图、延迟渲染；OpenGL、GPU 并行计算、GLSL 着色器编程；渲染方程、光线跟踪、路径追踪；渲染中的 AI 方法；材质、纹理、实时光路追踪 |
| 仿真 | 质点-弹簧系统、弹性体仿真；蒙特卡洛仿真、流体与 NS 方程；SPH 流体、刚体、碰撞检测；断裂与破坏、基于 AI 的仿真 |
| 动画与视觉 | 角色动画、四元数与三维旋转；坐标系与变换、多视点几何；体渲染、CT、NeRF、3DGS、神经渲染 |
| 收尾 | 游戏工业里的实时渲染与渲染引擎、课程总结 |

考核：平时作业 60%、期末大作业 20%、闭卷期末考试 20%。

## 学习建议

- **先做 C++ 热身，别跳。** 这门课的作业框架是一个不小的 C++ 工程，面向对象和 CMake 不熟，后面每个作业都会卡在工程问题上。
- **每周一个作业，保持节奏。** 作业设计成每周一个，一个接一个地覆盖图像、几何、渲染、仿真。拖久了很难追上。
- **几何部分是这门课的特色。** 泊松融合、曲面参数化（Tutte、ARAP）在别的图形学入门课里很少作为作业出现，值得认真做。
- **注意旧材料的框架问题。** 2020 年课程主页上的作业链接指向旧仓库 Ubpa/USTC_CG，官方说明那个框架已经不再维护、可能无法编译，
  自学请直接用最新年份的仓库。

## 同类课怎么选

- **[GAMES101](/docs/computer-graphics/games101)**：更专注渲染，讲得更细。刘老师在 2020 年的课程主页上也推荐把 GAMES101 结合着一起学。
- **GAMES102《几何建模与处理》**：刘老师在 GAMES 平台开的几何课，是这门课几何部分的深入版。
- **[GAMES103](/docs/computer-graphics/games103)**：物理仿真部分的深入版。
- **[CMU 15-462](/docs/computer-graphics/cmu-15-462)**：英文课，作业同样是一个完整的 C++ 图形软件。
