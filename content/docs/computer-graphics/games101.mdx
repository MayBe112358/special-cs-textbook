## 课程简介

GAMES101 是 GAMES（计算机图形学与混合现实研讨会）组织的在线课程，由加州大学圣塔芭芭拉分校的闫令琪讲授，
2020 年春季首次直播，**中文授课、英文课件**，录像放在 B 站，免费面向所有人。

课程主页的介绍：全面系统地讲现代计算机图形学的**四大组成部分**——光栅化成像、几何表示、光的传播理论、动画与模拟。
每部分都从基础原理讲到实际应用，再介绍前沿研究。目标是让你对图形学有一个“完整的、自上而下的全局把握”，
学完后明白“图形学不等于 OpenGL，不等于光线追踪，而是一套生成整个虚拟世界的方法”。

它和很多图形学教程有个重要区别：**不讲 OpenGL，甚至不会提这个概念**。
课程讲的是图形学背后的原理，而不是某个 API 怎么用；官方说学完之后你一定有能力自己用 OpenGL 写实时渲染程序。
另外，它也不讲计算机视觉、图像视频处理、深度学习，不教游戏引擎和建模软件的使用。

## 先修要求

- 课程主页写的必须项：高等数学（微积分、线性代数）、算法、数据结构。
- 非必须：信号处理、数值分析、大学物理（光学）。
- 作业用 C++，框架已经写好，你只需要补全关键函数。会基本的 C++ 语法、能用 CMake 编译就够了。

## 课程结构

共 22 讲，每讲一小时左右，每周两讲：

| 部分 | 讲什么 |
|---|---|
| 概述与数学 | 计算机图形学概述、向量与线性代数 |
| 变换 | 二维与三维变换；模型、视图、投影变换 |
| 光栅化 | 三角形的离散化；深度测试与抗锯齿 |
| 着色 | 光照与基本着色模型；着色频率、图形管线、纹理映射；插值与高级纹理映射 |
| 几何 | 基本表示方法；曲线与曲面；网格处理与阴影图 |
| 光线追踪 | 基本原理；加速结构；辐射度量学、渲染方程与全局光照；蒙特卡洛积分与路径追踪 |
| 外观与相机 | 材质与外观；高级光线传播与复杂外观建模；相机与透镜；光场、颜色与感知 |
| 动画与模拟 | 基本概念、质点弹簧系统、运动学；求解常微分方程、刚体与流体 |

推荐教材是 Marschner 和 Shirley 的《Fundamentals of Computer Graphics》（虎书），不是必须的；课程主页每讲都标了对应章节（以英文第四版为准）。

## 官方作业

官方安排 8 次小作业和 1 次大作业，全部是编程，提供代码框架，**自愿完成**，没有考试。
作业都能在 [GAMES 论坛的往期作业汇总帖](https://games-cn.org/forums/topic/allhw/) 下载：

| 作业 | 做什么 |
|---|---|
| 作业 0 | 配好开发环境，熟悉线性代数库 Eigen |
| 作业 1 | 写模型矩阵（绕轴旋转）和透视投影矩阵，在屏幕上画出一个三角形 |
| 作业 2 | 三角形光栅化与深度缓冲（Z-buffer），可选做超采样抗锯齿 |
| 作业 3 | 着色：法向量、Blinn-Phong 光照、纹理映射、凹凸贴图与位移贴图 |
| 作业 4 | 贝塞尔曲线（de Casteljau 算法） |
| 作业 5 | 光线与三角形求交（Möller-Trumbore 算法），实现一个 Whitted 风格的光线追踪 |
| 作业 6 | 用包围盒层次结构（BVH）加速光线追踪，可选做 SAH |
| 作业 7 | 路径追踪（俄罗斯轮盘赌），可选做微表面材质；官方提醒这次难度不低、渲染时间长，要尽早开始 |
| 作业 8 | 质点弹簧系统：用显式欧拉和 Verlet 积分模拟绳子的摆动 |

2020 年那一期结束后，作业提交和批改关闭；课程主页说之后每年会重新开放提交通道、提交后可以拿证书。
即使不提交，下载下来在本地编译运行、看渲染结果，也完全可以自学。

## 学习建议

- **跟着 B 站录像学，每讲看完就去读虎书对应章节。** 闫老师讲得非常清楚，但推导细节在书里。
- **每次作业都做。** 这门课的精华一半在作业：写完作业 1～3，你就亲手搭了一条软件光栅化管线；写完 5～7，你就有了一个路径追踪器。
- **作业 7 预留足够的时间。** 路径追踪渲染一张图可能要几分钟到几十分钟，先用低采样数调通，再提高采样数出最终图。
- **不要把作业代码公开到网上。** 课程主页的合作政策明确说，如果别人抄了你公开在 GitHub 上的代码，你也要负责。
