## 课程简介

这是卡内基梅隆大学的计算机图形学课，以前的课号是 15-462/662，现在本科生课号是 **15-362**。
2026 年秋季由 Oscar Dadfar 讲授；Keenan Crane、Kayvon Fatahalian、Jim McCann 等人都讲过这门课，课件一代代沿用改进。

官方说明：这是一门全面的图形学入门，关注基本概念和技术，以及它们在**渲染、动画、几何、成像**几个方向之间的交叉关系。
列出的主题非常多：采样与走样、插值、光栅化、几何变换、可见性、合成、滤波与卷积、曲线与曲面、几何数据结构、细分与网格化、
空间层次结构、光线追踪、辐射度量学、反射、蒙特卡洛渲染、重要性采样、相机模型、微分方程与时间积分、基于物理的动画、
优化、逆向运动学、傅里叶方法等。

这门课的最大特色是作业：全部在一个叫 **Scotty3D** 的 3D 建模、渲染和动画软件里完成。
软件的框架是开源的，你要亲手补上它的核心部分——软件光栅化管线、半边网格编辑、路径追踪渲染器、骨骼动画与粒子模拟。
做完以后，你手里就是一个自己写的“迷你 Blender”。

## 先修要求

- 官方写的是：向量微积分和线性代数是课程的重要组成部分；有 C/C++ 编程经验会非常有帮助，因为编程作业的实现量很大。
- 线性代数不熟的话，先看 [MIT 18.06](/docs/mathematics/mit-18-06) 的矩阵变换和特征值部分。

## 课程结构

2026 年秋季每周两讲，按日程表：

| 部分 | 讲什么 |
|---|---|
| 光栅化 | 图形管线导论、数学与代码复习、坐标空间与变换、透视投影与光栅化、透明与纹理 |
| 几何 | 几何导论、数字几何处理、空间数据结构 |
| 渲染 | 颜色、辐射度量学、渲染方程、方差缩减、双向反射分布函数（BRDF） |
| 动画 | 动画原理、样条与运动学、物理模拟 |
| 专题 | 图形 API 与硬件架构、神经几何、非真实感渲染、游戏图形、学生投票选题、研究与业界 |

期中在第七周，学期末是期末项目展示。

## 官方作业

- **编程作业（占 55%）**：五个，每个分两步（x.0 和 x.5，前一步是检查点）：
  - **A0 环境配置**：把 Scotty3D 编译跑起来。
  - **A1 光栅化器**：在软件里实现一条简化的光栅化管线，也就是 GPU 把三维三角形变成屏幕像素的那套流程。
  - **A2 网格编辑**：用半边数据结构实现网格的交互式编辑（翻转边、倒角、细分等局部和全局操作）。
  - **A3 路径追踪**：先实现高效的光线与场景求交（包括加速结构），再实现基于路径追踪的真实感渲染器。
  - **A4 动画**：骨骼动画、线性混合蒙皮、粒子模拟。
  - **A5 期末项目**：在 Scotty3D 里实现一个自己选的功能，脚手架很少，要自己设计实现。
- **小作业（mini homework，占 7.5%）**：大约每周一份，几道题，巩固最核心的概念。
- **考试**：期中 15%、期末 20%。

Scotty3D 的全部代码和作业说明都在 [GitHub 仓库](https://github.com/CMU-Graphics/Scotty3D) 里（`assignments` 目录下的 A0.md～A5.md），
**校外可以直接克隆下来做**，只是没有自动评分，要靠自己渲染出的结果和说明里的参考图来判断对不对。

## 学习建议

- **先把 A0 做完。** 编译一个大型 C++ 图形项目本身就可能卡一两天，先把环境搞定再开始学。
- **每个作业先读完整份说明。** 作业说明写得很细，还配了参考图和常见错误，是这门课最好的教材之一。
- **A2 的半边结构多画图。** 半边网格编辑的 bug 几乎都来自指针关系没理清。每写一个操作，先在纸上画出操作前后的每条半边指向哪里。
- **A3 从简单场景开始。** 先确认一个球的求交和直接光照对了，再加加速结构和多次反弹。路径追踪的 bug 在复杂场景里很难看出来。
- **课程允许用 AI，但不推荐。** 在校生用了必须在作业说明里注明用了什么模型、做了什么。这门课的价值就在亲手实现，建议尽量自己写。
