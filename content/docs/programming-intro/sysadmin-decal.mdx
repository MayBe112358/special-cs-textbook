## 课程简介

Sysadmin DeCal 是伯克利开放计算设施（OCF，一个学生运营的计算机组织）开的 Linux 系统管理课。
DeCal 是伯克利的一种“学生教学生”的课程形式，由学生志愿者讲授，学分只有 2 个，只分通过和不通过。

它讲的是怎么搭好、管好一台“生产级”的 Linux 服务器。官方列的目标是：用 Linux 用得顺手；
弄明白操作系统的各个部分怎么配合（init、进程、守护进程、文件系统）；懂 Linux 上的基础网络；
对系统安全有个清楚的感觉；知道系统管理员在公司里实际都干些什么。

它放在“编程入门”这一支，是因为很多自学者会在这里第一次认真用 Linux：命令行、包管理、服务、日志、
网络配置……这些东西大学课程通常默认你会，但很少有课专门教。每周一讲一实验，
实验都是在真实的系统上动手：配置、修东西、搭服务，而不是做选择题。

## 先修要求

- 官方说唯一真正的先修，是愿意学陌生的新技术，这本身就是系统管理员最重要的能力。很多学生有计算机背景，但不是必须。
- 需要一台 Linux 环境。校外自学的话，官方建议在自己电脑上装一个虚拟机，或者去 DigitalOcean 这类云服务商租一台。

## 课程结构

2026 年秋季这一期，每周二一讲（1 小时）加一次实验课（1 小时）：

| 周 | 讲课与实验 |
|---|---|
| 1 | UNIX 的历史、Linux 入门、自由和开源软件 |
| 2 | Shell 核心用法与 shell 脚本 |
| 3 | 软件包与打包（`apt`、`dpkg`） |
| 4 | 进程与服务（`systemd`） |
| 5 | 网络入门：MAC、IP、路由这些概念 |
| 6 | Web 服务器：DNS、Web 服务、负载均衡 |
| 7 | 安全基础：对称与非对称加密 |
| 8 | 版本控制与备份 |
| 9 | 容器（Docker） |
| 10 | Nix：用声明式的方式管理软件和系统 |
| 11 | Kubernetes |

官方说会尽量每周放出讲课录像，幻灯片挂在课程主页的日程表里。

## 官方作业

每讲对应一个实验，都在 [Labs](https://decal.ocf.berkeley.edu/labs/1/) 页面，校内学生要完成 10 个才能拿学分：

- [Lab 1：Unix, the Shell, OSS](https://decal.ocf.berkeley.edu/labs/1/)：在 shell 里到处“探险”，熟悉文件系统和常用命令，再回答几个关于开源的问题。
- [Lab 2：Core Shell & Shell Scripting](https://decal.ocf.berkeley.edu/labs/2/)：管道、重定向，写 shell 脚本。
- [Lab 3：Packages and Packaging](https://decal.ocf.berkeley.edu/labs/3/)：用 `apt`、`dpkg` 装软件，自己打一个包。
- [Lab 4：Processes and Services](https://decal.ocf.berkeley.edu/labs/4/)：用 `systemd` 管理服务，看进程怎么被启动和监管。
- [Lab 5：Introduction to Networking](https://decal.ocf.berkeley.edu/labs/5/)：MAC、IP 这些概念落到 Linux 的实际命令上。
- [Lab 6：Web Servers](https://decal.ocf.berkeley.edu/labs/6/)：看机器上跑着哪些网络服务，配 DNS、Web 服务器，用 HAProxy 做负载均衡。
- [Lab 7：Security Fundamentals](https://decal.ocf.berkeley.edu/labs/7/)：对称和非对称加密的实际操作。
- [Lab 8：Version Control and Backups](https://decal.ocf.berkeley.edu/labs/8/)：Git 基础和备份策略。
- [Lab 9：Containers (Docker)](https://decal.ocf.berkeley.edu/labs/9/)：用 Docker 打包、运行服务。
- [Lab 10：Nix](https://decal.ocf.berkeley.edu/labs/10/)：Nix 表达式语法，用声明式配置描述一个系统。
- [Lab 11：Kubernetes](https://decal.ocf.berkeley.edu/labs/11/)：Kubernetes 的基本概念，把服务部署到集群上。

## 学习建议

- **官方欢迎旁听。** 课程 FAQ 里写着：不是学生、没选上的人，也可以自己看讲课、做实验。
- **备一台“能随便折腾”的 Linux。** 实验要改系统配置、装服务、开端口，别在你日常用的电脑上直接做。本地虚拟机最省钱，云服务器最接近真实环境。
- **动手比看懂重要。** 这门课的价值全在实验里：只看讲义很快就忘，亲手配过一遍 `systemd` 服务、HAProxy、Docker，才真的会。
- **往期材料也在。** 课程网站有 Archives 页，保留了过去好几个学期的版本，某一期讲得不清楚可以对照着看。
- **和 Missing Semester 搭配。** MIT 的 [Missing Semester](/docs/essential-tools/missing-semester) 讲命令行工具、编辑器、Git、调试，和这门课的前几周互补；这门课往后走得更远，一直到部署和运维。

## 同类课怎么选

- **[MIT Missing Semester](/docs/essential-tools/missing-semester)**：面向程序员的工具课，讲 shell、Vim、Git、调试、元编程。偏“开发者怎么用好工具”。
- **Sysadmin DeCal**：偏“系统管理员怎么管好一台服务器”：包管理、服务、网络、安全、容器、集群。
- 想往运维、后端、基础设施方向走，这门课是一个很实际的起点；学完再去学计算机网络、操作系统，会有很多“原来是这样”的时刻。
