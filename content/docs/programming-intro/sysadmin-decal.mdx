## 课程简介

这是伯克利开放计算设施（OCF）开的学生自办课程（DeCal），
主题是怎么搭建和管理一台真正对外提供服务的 Linux 服务器。

课程按实验推进，顺序很实在：Unix 与 shell、shell 脚本、软件包与打包、
进程与服务、网络基础、Web 服务器、安全基础、版本控制与备份、
容器（Docker）、Nix，最后是 Kubernetes。

它补的是一块大多数计算机课程不碰的空白：程序写完之后，怎么让它在一台机器上
稳定地跑着、能被访问、出事能恢复。对想自己部署点什么的人，这门课非常对口。

## 先修要求

- 会用命令行执行基本命令。
- 有一台可以随便折腾的 Linux 机器或虚拟机。
