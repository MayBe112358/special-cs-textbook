## 课程简介

CS220 是 KAIST 的程序设计原理课，用 Rust 作为教学语言。
它关心的不是某种语法，而是语言设计里的通用概念：类型系统、所有权、
表达式求值、模式匹配、trait 与泛型、错误处理，以及这些概念如何影响你写出来的程序。

课程全部材料放在 GitHub 上：讲义、幻灯片、代码框架和自动测试。
作业以填空式的练习为主，每道题都有配套的单元测试，本地 `cargo test` 就能判断对错，
这对自学者非常友好。

它也是同一团队的 CS420（编译器设计）和 CS431（并发编程）的前置课，
三门课共用一套 Rust 工程约定。
