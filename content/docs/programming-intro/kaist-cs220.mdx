## 课程简介

CS220（Programming Principles）是韩国 KAIST 的程序设计原理课，由 Jeehoon Kang 讲授，整门课的材料放在一个公开的 GitHub 仓库里。
它的目标用官方的话说，是教你“能有效地把想法告诉计算机”需要的那些编程概念，Rust 只是讲这些概念的载体。

课程分五个部分：先用 Rust 把入门课学过的东西复习一遍；然后讲类型和正确性，包括“让类型替你做自动检查”；
接着是引用和所有权，这是 Rust 最有特色的地方；再是把函数当成值、迭代器和组合子；最后是可变性、并发和并行。
选 Rust 的理由官方也写了：它的所有权类型系统让大规模系统软件好写得多。

这门课有个很少见的特点：它明确允许用 ChatGPT 这类大模型辅助写作业，而且作业难度就是按“学生会用 ChatGPT 3.5 或同等工具”来定的。
与其禁止，不如把题目出得让工具也帮不了你偷懒。

## 先修要求

- 官方强烈建议先修过两门课：一门编程入门（KAIST 的 CS101），一门讲命题和证明的数学课（MAS101）。
- 不需要事先会 Rust，第一部分就是用 Rust 把基础重新过一遍。
- 需要会用 Git 和命令行，作业全靠它们下载、评分、提交。

## 课程结构

按 2024 年秋季的课表，十六周：

| 周 | 部分 | 讲什么 |
|---|---|---|
| 1 | 介绍 | 课程目标、为什么用 Rust |
| 2–4 | 第 1 部分 | 用 Rust 复习入门课的内容：变量、控制流、结构体、枚举 |
| 5–7 | 第 2 部分 | 类型、正确性、把类型当成自动的验证工具 |
| 8 | | 期中考试 |
| 9–10 | 第 3 部分 | 引用、所有权 |
| 11–12 | 第 4 部分 | 函数作为值、组合子、迭代器 |
| 13–15 | 第 5 部分 | 可变性、并发、并行 |
| 16 | | 期末考试 |

讲课幻灯片是一份公开的 Google Slides，课本就是官方的《The Rust Programming Language》。

## 官方作业

作业都在仓库的 [`src/assignments`](https://github.com/kaist-cp/cs220/tree/main/src/assignments) 目录里，每份是一组 Rust 模块，你把 `todo!()` 填上，然后跑 `./scripts/grade.sh 作业号` 看得分：

- **作业 1**：搭好 Rust 开发环境，做几道小题。
- **作业 2、3**：用 Rust 重练常见的编程概念。作业 2 有向量和矩阵运算；作业 3 有自定义运算符，还要写一个简单的 shell 命令解析器。
- **作业 4**：设计一个计算器，要自己读文档学会用 `pest` 这个解析器库，写语法、解析、求值。
- **作业 6、7**：泛型、trait、生命周期。作业 6 是半环（semiring）和符号求导（让程序对表达式求导数）；作业 7 有生成器、自己实现一套 itertools 风格的迭代器工具。
- **作业 8**：一等函数，里面有 Church 编码（只用函数来表示数字）。
- **作业 9、10**：迭代器。作业 9 是大整数运算和矩阵乘法；作业 10 的 Labyrinth 其实是一道概率题，改编自有名的“100 个囚犯”问题，要实现一个会以一定概率失败的随机算法。
- **作业 11**：智能指针，实现链表、图、一个模拟的存储系统。
- **作业 12**：并发，几道用线程和 channel 分发、汇合数据的题。
- **作业 13**：数据并行。

## 学习建议

- **别 fork 仓库。** 官方要求直接 clone，然后推到你自己的私有仓库，免得别人看到你的答案。
- **评分脚本就是答案检查器。** 每份作业都有 `*_grade.rs` 测试和 `grade.sh` 脚本，本地跑就能知道得了多少分；`cargo doc --open` 可以在浏览器里看每份作业的说明文档。
- **边做作业边读 Rust Book。** 作业 2 的说明里就直接写了对应 Rust Book 的第 3、5 章，照这个对应关系读最省力。
- **AI 可以用，但别让它替你想。** 这门课允许用大模型，可你真正要学的是类型、所有权这些概念，让 AI 写完你看不懂，这门课就白学了。
- **作业 4 值得多花时间。** 自己读第三方库的文档、自己设计语法，是“学会学习”的一次练习。

## 同类课怎么选

- **[Stanford CS110L](/docs/programming-intro/cs110l)**：也用 Rust，但重点是系统编程里的安全问题，项目是调试器和负载均衡器，更偏系统。
- **[KAIST CS431](/docs/programming-intro/kaist-cs431)**：同一个研究组开的并发编程课，也用 Rust，难度高得多。学完 CS220 的第 5 部分可以接着上。
- **[Cornell CS3110](/docs/programming-intro/cs3110)**：用 OCaml 讲函数式编程，类型、代数数据类型、正确性这些思想和 CS220 的第 2 部分相通。
