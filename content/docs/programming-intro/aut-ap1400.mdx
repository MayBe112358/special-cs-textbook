## 课程简介

AP1400-2 是德黑兰理工大学（AUT）的高级编程课，
课程本身以 C++ 作业为主线，全部作业框架公开在 GitHub 上。

它和入门课的差别在于工程化：每个作业都是一个带 CMake 构建、
Google Test 单元测试的完整项目，你要做的是在给定的骨架里把功能补完，
并让全部测试通过。题目涉及矩阵运算、智能指针、模板、
运算符重载、异常处理这些实际写 C++ 会碰到的东西。

对自学者来说，它最有用的地方是提供了一批有测试、可自测的 C++ 练习，
填补了很多 C++ 教程只讲语法不给练习的空缺。

## 先修要求

- 需要 C++ 基础，建议先完成 CS106B/X 或同等课程。
- 需要会用 CMake 构建项目。
