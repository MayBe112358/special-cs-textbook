## 课程简介

这是赫尔辛基大学的一门 Haskell 函数式编程在线课。全部讲义和练习公开，没有开课时间，想什么时候学都行。
它分两部分，每部分对应学校的 5 个 ECTS 学分，一共十六讲。

第一部分从零讲 Haskell：表达式和类型、递归、列表、`Maybe` 和 `Either`、高阶函数、fold、类型类、
代数数据类型，最后一讲浅尝输入输出，外加一个画图的小结课项目。
第二部分进入 Haskell 真正“不一样”的地方：惰性求值和纯函数、等式推理、无限列表、IO 到底是什么、
Functor、Foldable、Monad（从 Maybe、日志、状态三个例子一步步推出来）、Applicative，
中间还有一讲用 Haskell 写一个 HTTP 服务器、连 SQLite 数据库。

它的讲法很友好，每讲的标题都是个小玩笑（比如第 12 讲叫 “fmap fmap fmap”），
Monad 那一讲不是直接甩定义，而是先让你写三段长得很像的代码，再告诉你它们其实是同一个东西。
这是很多人第一次真正看懂 Monad 的地方。

## 先修要求

- 官方说不假设任何先修知识，但先会一门编程语言会让课程容易很多。
- 做练习需要会用命令行、会用 Git 克隆仓库，环境用 Haskell 的 `stack` 工具搭。

## 官方作业

每一讲末尾都有一组练习，一共三十来个练习文件，放在课程的 GitHub 仓库 [moocfi/haskell-mooc](https://github.com/moocfi/haskell-mooc) 的 `exercises` 目录里（`Set1.hs`、`Set2a.hs`……）。
每个练习文件都配一个测试文件，写完在本地跑测试就知道对不对，然后可以到网站上提交，拿到官方的完成记录。

- [第一部分](https://haskell.mooc.fi/part1)：Set1 到 Set8，从简单的函数定义一路练到类型类和建模，第 8 讲的结课项目是用 Haskell 画图。
- [第二部分](https://haskell.mooc.fi/part2)：Set9 到 Set16，惰性、IO、Functor、Monad、Applicative 都有专门的题组，第 14 讲的练习要写一个小型 Web 服务。

计分办法很直白：每讲至少完成一半才能拿学分；全部练习完成 50% 得 3 分、80% 得 4 分、99% 得 5 分（芬兰的五分制）。

## 学习建议

- **环境第一次要装很久。** 在 `exercises` 目录里跑 `stack build`，会下载指定版本的 GHC 和一堆库，好几个 GB。第一讲的 1.13 节列了常见的报错和解决办法，碰到问题先去那里找。
- **测试是最好的老师。** 每道题都有对应的测试，先写个半成品跑一下，看测试说什么，再改。
- **Monad 那一讲别跳。** 第 13 讲是整门课的高潮，它会带着你自己“发现”Monad，而不是背定义。前面第 12 讲的 Functor 要先弄懂。
- **想拿学分可以登录。** 网站可以免费注册账号、提交练习、查看“My status”；只是自学的话，本地测试全过就够了。
- **有社群可以问。** 课程有一个 Telegram 群，能和其他学员、助教讨论。

## 同类课怎么选

- **[Cornell CS3110](/docs/programming-intro/cs3110)**：用 OCaml 学函数式编程，有一本极好的教材，范围更广（还讲正确性、数据结构、解释器），但练习没有自动评分。
- **[KAIST CS220](/docs/programming-intro/kaist-cs220)**：用 Rust 讲程序设计原理，类型系统的思想相通，更贴近工程。
- **[UC Berkeley CS61A](/docs/programming-intro/cs61a)**：函数式思想的入门版，用 Python，面向完全的初学者。

想要“即时反馈、按自己节奏、把函数式编程学纯粹”，这门课是最好的选择；想要一本讲得更全面的书，选 CS3110。
