## 课程简介

这是杜克大学在 Coursera 上开的 C 语言入门专项，由四门小课组成，
面向完全没有编程经验的人。

它的特点是把“怎么想”和“怎么写”分开教：课程花了相当篇幅讲解题步骤——
先把问题讲清楚、手工做一遍、总结成算法、再翻译成代码、最后测试——
而不是一上来就贴语法。对第一次学编程的人，这套方法比语言本身更有价值。

内容覆盖 C 的基本语法、数组与指针、结构体与动态内存、文件读写，
最后有一个综合项目。如果你的目标是 CS50x 之后再补一轮 C 的基础，
或者想要一条比 CS50x 更慢更稳的路径，这门课合适。
