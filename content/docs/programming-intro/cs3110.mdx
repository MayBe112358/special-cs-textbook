## 课程简介

CS3110（Data Structures and Functional Programming）是 Cornell 的函数式编程课，用 OCaml 讲。
它的公开部分是一本很好的在线书，名字就说明了态度：《OCaml Programming: Correct + Efficient + Beautiful》，
写得正确、跑得高效、读着漂亮。这本书是 Cornell 几代老师和学生花了几十年一起攒出来的，开源、免费，书里嵌着两百多个 YouTube 讲解视频。

它想教的其实不只是 OCaml。学完你会习惯另一种写程序的方式：尽量不改变量，而是用函数把数据变成新的数据；
用类型把“不可能出现的情况”排除在编译期；用模块和接口把大程序拆开。
书的后半本讲程序的正确性（规格说明、测试、证明）、函数式的数据结构（红黑树、持久化数组），
最后一章写解释器：解析、代换模型、环境模型、类型检查、类型推断，和 [CS61A](/docs/programming-intro/cs61a) 的解释器单元遥相呼应。

## 先修要求

- 会一门命令式语言，写过几百行规模的程序。Cornell 校内要求先修一门 Java 面向对象课，但书里说学过类似语言的人跟上没有困难。
- 不需要事先会 OCaml，也不需要函数式编程的经验。
- 最后几章会用到一点离散数学（归纳法证明），不会也能先跳过。

## 课程结构

以教材的章节为准，一共十章：

| 章 | 主题 | 讲什么 |
|---|---|---|
| 1–2 | OCaml 入门 | 为什么学 OCaml、交互环境、表达式、函数、调试 |
| 3 | 数据与类型 | 列表、变体、记录、模式匹配、Option、代数数据类型、用 OUnit 写单元测试 |
| 4 | 高阶函数 | map、filter、fold、管道、柯里化 |
| 5 | 模块化 | 模块、封装、函数式数据结构、模块类型、functor |
| 6 | 可变性 | 引用、可变字段、数组和循环 |
| 7 | 并发 | Promise、异步 I/O、回调，最后讲到 monad |
| 8 | 正确性 | 规格说明、文档、黑盒与白盒测试、QCheck 随机测试、证明程序正确 |
| 9 | 数据结构 | 哈希表、摊还分析、红黑树、惰性序列、记忆化、持久化数组、2-3 树 |
| 10 | 解释器 | 计算器、解析、代换模型、环境模型、类型检查、类型推断 |

## 官方作业

Cornell 当学期的编程作业和考试放在校内的 Canvas 上，外面看不到。公开可做的，是教材每章（第 2 章起）末尾的练习：

- [第 2 章练习](https://cs3110.github.io/textbook/chapters/basics/exercises.html)：表达式、函数、递归的小题，熟悉工具链。
- [第 3 章练习](https://cs3110.github.io/textbook/chapters/data/exercises.html)：列表、模式匹配、自定义类型，题量最大的一章，是后面所有内容的底子。
- [第 4 章练习](https://cs3110.github.io/textbook/chapters/hop/exercises.html)：用 map、filter、fold 改写各种循环。
- [第 5 章练习](https://cs3110.github.io/textbook/chapters/modules/exercises.html)：写模块和接口，用 functor 做参数化的数据结构。
- [第 8 章练习](https://cs3110.github.io/textbook/chapters/correctness/exercises.html)：写规格、设计测试、做简单的正确性证明。
- [第 9 章练习](https://cs3110.github.io/textbook/chapters/ds/exercises.html)：实现哈希表、红黑树等数据结构。
- [第 10 章练习](https://cs3110.github.io/textbook/chapters/interp/exercises.html)：扩展书里的解释器：解析、化简、类型推断。

每道题都标了难度：一颗星一两分钟，两颗星几分钟，三颗星五到二十分钟，四颗星以上是给想深挖的人的难题。

## 学习建议

- **书和视频一起用。** 视频通常先引入概念，书再展开；两者顺序偶尔不同，视频就嵌在书里离主题最近的地方。视频是 2020 年前后录的，OCaml 的版本和工具链有些已经变了，想法不变，看到界面不一样别慌。
- **先把环境装好。** 书开头有一章“Installing OCaml”，照着装 opam、OCaml 和编辑器插件，别跳过。
- **有官方参考答案。** 大部分练习的答案是公开的，书的“About This Book”一节有入口。官方请大家不要把自己的答案贴到公开仓库，以免被搜到。
- **第 3、4 章多花时间。** 模式匹配和 fold 是函数式编程的两根柱子，这两章的题做透了，后面会顺很多。
- **PDF 版可以离线读**，但不带视频和交互内容。

## 同类课怎么选

- **[Helsinki Haskell MOOC](/docs/programming-intro/haskell-mooc)**：用 Haskell 学函数式编程，练习全部自动评分，更“纯”也更抽象。想要即时反馈，选它。
- **[KAIST CS220](/docs/programming-intro/kaist-cs220)**：用 Rust 讲程序设计原理，同样重视类型和代数数据类型，但不是纯函数式。
- **[UC Berkeley CS61A](/docs/programming-intro/cs61a)**：也讲函数式思想和解释器，但主体用 Python，面向初学者。

CS3110 的优势是“全”：它同时是一门函数式编程课、一门数据结构课和一门讲正确性的软件工程课，书也写得最好。
