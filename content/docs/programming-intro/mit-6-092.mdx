## 课程简介

6.092 是 MIT 在一月独立活动月开的短课，目标很实际：
让已经会一门语言的人快速上手 Java。

内容是 Java 的核心部分：类型与变量、操作符、条件与循环、数组、
方法、类与对象、继承与接口、基本的输入输出，最后是一个简单的图形界面练习。
课程只有十来讲，不求覆盖 Java 生态，只求把语言本身讲清楚。

OCW 上材料完整：讲义、示例代码和作业都公开。
适合作为读 CS61B（Java 版数据结构）之前的语言补课，两三天就能过完。

## 先修要求

- 需要已经会一门编程语言。
- 不需要预先了解 Java。
