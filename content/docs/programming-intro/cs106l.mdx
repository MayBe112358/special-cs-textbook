## 课程简介

CS106L 是一门一学分的小课，专讲现代 C++ 语言本身。
官方的定位很明确：它不教编程基础，而是补上 CS106B 里为了教数据结构而绕开的那部分语言细节。

内容按语言特性组织：类型与结构体、初始化与引用、流、容器、迭代器与指针、
类与面向对象、模板与模板元编程、函数对象与 lambda、移动语义与右值引用。
课程会讲到较新的标准，官方页面写的是覆盖到 C++26 的一些现代写法。

每周一份很短的作业，官方明确说不以难度取胜，只是让你把上周讲的特性实际写一遍。
对想把 C++ 写得像样一点的人，这门课性价比很高。

## 先修要求

- 需要已经学过或正在学 CS106B/X，或同等的编程基础（函数、对象、类）。
- 不需要预先熟悉 C++ 的高级特性，这正是课程要讲的内容。
