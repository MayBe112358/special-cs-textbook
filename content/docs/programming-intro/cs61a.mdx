## 课程简介

CS61A 是 UC Berkeley 的程序设计导论。它用 Python 授课，但重点从来不是 Python 的语法，
而是控制程序复杂度的几种手段——官方的说法是：这门课关心的是编程的思想，而不是某种语言。

课程按四条线推进。先是函数抽象：高阶函数、递归、以及把函数当成值来传递。
接着是数据抽象：可变与不可变数据、面向对象、继承与多态，以及怎么用数据类型隐藏实现细节。
第三条线是解释器——你会用 Python 写一个 Scheme 解释器，
亲手实现求值、环境、尾递归。最后是声明式编程：SQL 与逻辑式语言，
展示另一种"说清要什么、而不是怎么做"的编程范式。

那个解释器项目是全课的重心，也是这本教材关心的那类项目的原型：
一旦你亲手写过一遍求值循环，"程序也是数据"就不再是一句口号。
课程材料每学期更新，讲义、作业、项目和自动评分工具全部公开。

## 先修要求

- 数学：官方将 Math 1A 或同等课程列为可同时修读的要求，日常会用到基础代数。
- 编程：没有正式的编程先修要求；官方同时提醒，完全没有编程经验的学生通常需要投入更多时间。
