## 课程简介

CS61A 是 UC Berkeley 计算机系的第一门课，课名取自那本经典教材《计算机程序的构造和解释》（SICP）。
官方说得很直白：这门课教的是编程，不是某一种语言。它关心的是怎么控制程序的复杂度，
办法是抽象：让你按问题本身的样子去思考，而不是按计算机底层的操作去思考。

主体用 Python 讲，按几条线往前走：先是函数，包括高阶函数、环境模型、递归；
然后是数据，包括序列、容器、对象和面向对象设计；再往后是解释器和函数式编程，
你会亲手实现一门小语言的求值过程；另外还有声明式编程（SQL）。

**2026 秋季这一版改动很大，值得单独说一下。** 课程组为 AI 时代重新设计了课程：

- 最后加了一个两周的单元，讲软件应用的设计。学生要用 AI 编程代理，做一个包含浏览器前端、客户端—服务器结构、多种语言的完整 Web 应用。
- 解释器和函数式编程那个单元，不再用教了二十多年的 Scheme，改用 [Gleam](https://gleam.run/)。这是一门静态类型的函数式语言，顺带讲了代数数据类型和模式匹配。
- 为了腾出时间，删掉了一部分和 CS61B 重复的内容，以及宏那两讲。

课程组也说得很清楚：大部分内容没变，“不借助 AI、自己读懂和写出程序”仍然是这门课的核心目标。
所以平时的作业要求手写代码，交作业时还要讲清楚自己的代码是怎么回事，每周还有一次不许用 AI 的小测。

## 先修要求

- **数学**：官方把 Math 1A（微积分）列为可以同时修的课。做作业从来用不到微积分，但基础代数天天在用。
- **编程**：没有硬性要求。不过官方也坦白说，大多数学生来之前都写过不少程序，典型背景是学过一门 CS10 那样的入门课，或者 AP 计算机考过 3 分以上。零基础也能学下来，但要花明显更多的时间。官方的原话是：如果开学头三周就跟得很吃力，强烈建议先去上一门更基础的课。

## 课程结构

以下按 2026 秋季官网（截至 2026 年 9 月下旬）已经发布的内容整理。后半学期还没公布的部分，按课程公告里的描述写，会随学期推进变化。

| 阶段 | 讲什么 | 状态 |
|---|---|---|
| 函数 | 函数、控制流、高阶函数、环境模型、函数式抽象 | 已发布（第 1–6 讲），期中考试 1 覆盖到这里 |
| 递归 | 递归、树形递归 | 已发布（第 9–10 讲） |
| 数据 | 序列、容器、对象与面向对象 | 陆续发布中（第 11–13 讲已出） |
| 解释器与函数式编程 | 用 Gleam 讲解释器、静态类型、代数数据类型与模式匹配 | 尚未发布 |
| 声明式编程 | SQL | 尚未发布 |
| 软件应用 | 浏览器、DOM、单页应用（Gleam 的 Lustre 框架），用 AI 编程代理完成最终项目 | 尚未发布 |

每周的节奏是：三次讲课（每讲都配一组视频，官方要求先看视频再去听课）、一次讨论课、一次 lab、一份作业；
大部分周的 lab 开头有一个十分钟的小测，题目是作业里某道题的变形。

## 官方作业

所有作业都在课程主页上按周发布，下面是截至 2026 年 9 月下旬已经发布的。每份的题目页、起始代码和测试都能公开打开。

**项目**（比较大的综合作业，可以两人结对）

- [Project 1：Hog](https://cs61a.org/fa26/projects/hog/)。一个掷骰子的双人游戏。第一阶段实现游戏规则，第二阶段写“策略函数”，也就是用函数来描述一种打法。练的是高阶函数：函数作为参数传进去，又作为结果返回出来。
- [Project 2：Cats](https://cs61a.org/fa26/projects/cats/)（Computer Aided Typing Software）。一个打字速度测试程序，分打字、自动纠错、多人对战三个阶段，还有一个讲效率的附加挑战。自动纠错那部分要用递归去比较两个单词差多少。
- 解释器单元的项目、最后的 AI 辅助应用开发项目，要到学期后半才发布。

**作业**（每周一份，周五发、下周四截止）

- [Homework 1：Functions](https://cs61a.org/fa26/hw/hw01/)
- [Homework 2：Higher-Order Functions](https://cs61a.org/fa26/hw/hw02/)
- [Homework 3：Recursion](https://cs61a.org/fa26/hw/hw03/)

**Lab**（每周一次，比作业短，偏向把刚讲的东西练熟）

- [Lab 0：Getting Started](https://cs61a.org/fa26/labs/lab00/)：装好 Python 和 VS Code，学会下载、运行、提交作业。自学也建议从这里开始。
- [Lab 1：Functions & Control](https://cs61a.org/fa26/labs/lab01/)
- [Lab 2：Higher-Order Functions](https://cs61a.org/fa26/labs/lab02/)
- [Lab 3：Lists](https://cs61a.org/fa26/labs/lab03/)

讨论课的题目也在主页上（Discussion 1 起），适合做完 lab 之后再练一轮。

## 学习建议

- **跟着当前学期走。** 以前自学 CS61A 的人常用往年的存档，但截至 2026 年 9 月，伯克利服务器上的往年存档（inst.eecs.berkeley.edu 下的 fa25、sp25 等）都要伯克利账号登录，外面打不开了。当前学期 cs61a.org/fa26 的材料是公开的，只是后面的内容要等它按周发布。
- **本地测试够用了。** 每个作业的起始代码里自带一套测试（Hog 的压缩包里就有一个打包好的测试工具），不需要伯克利账号，在自己电脑上就能跑。
- **哪些环节可以跳过。** 交作业用的 Gradescope、记录你怎么写代码的 Provenance 插件、作业后的 AI 口头检查（Preceptor），还有小测和考试，都是给在校学生的。自学时做完题、跑通测试就行。不过它们背后的意思值得学：别让 AI 替你写，写完要能讲清楚自己的代码。
- **视频是公开的。** 每一讲的视频列表放在 YouTube 上，课程页的每一讲底下都有链接。官方建议先看视频，再去看讲课的例子。
- **教材免费。** 配套教材 [Composing Programs](https://www.composingprograms.com/) 是 SICP 的 Python 改编版，全文在线。
- **零基础的话先热身。** 官方推荐的替代课是 CS10（用积木式语言 Snap! 起步）和 Data C88C（大约覆盖 CS61A 三分之二的内容）。放在本站的课程树里，可以先学 Harvard CS50x 或 CS50P 再回来。

## 同类课怎么选

编程入门这一支里有好几门课，侧重点不同：

- **[Harvard CS50x](/docs/programming-intro/cs50x)**：从 C 讲起，再到 Python、SQL 和 Web，面更广，对零基础更友好。想先对计算机科学有个整体印象，选它。
- **[Harvard CS50P](/docs/programming-intro/cs50p)**：只讲 Python 本身，从语法到测试、正则、面向对象，最平缓。
- **[MIT 6.100L](/docs/programming-intro/mit-6-100l)**：同样用 Python，更偏计算思维和用程序解决问题。
- **CS61A**：三者里抽象程度最高，重点是函数、数据抽象和解释器，而且要实现一门语言。它是这本教材的“正文”对应得最多的一门课：命令引擎、终端、AI 助手的主循环，都能在它身上找到原型。

大致的路子是：零基础先走 CS50x 或 CS50P，有一点编程经验就直接上 CS61A。学完 CS61A，下一门通常是 [CS61B](/docs/data-structures-algorithms/cs61b)（数据结构）。
