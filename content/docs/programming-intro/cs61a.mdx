## 课程简介

CS61A 是 UC Berkeley 的程序设计导论。课程从函数和抽象出发，逐步讨论递归、数据、对象、程序解释器
以及声明式编程。重点不只是学会 Python 语法，而是学习如何组织和理解程序。

## 先修要求

- 数学：官方将 Math 1A 或同等课程列为可同时修读的要求，日常会用到基础代数。
- 编程：没有正式的编程先修要求；官方同时提醒，完全没有编程经验的学生通常需要投入更多时间。
