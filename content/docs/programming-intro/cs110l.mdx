## 课程简介

CS110L 问的问题是：系统编程里那些反复出现的崩溃和漏洞——
悬垂指针、重复释放、缓冲区溢出、数据竞争——能不能在语言层面被挡住？
Rust 是这门课用来回答问题的工具，但它讲的不是 Rust 语法手册。

课程从内存安全讲起，接着是错误处理、Rust 的面向对象、trait 与泛型、
智能指针与内部可变性，然后进入多进程与多线程、共享状态并发和消息传递并发。
作业里你会写一个调试器和一个多线程的 Web 服务器。

它适合已经写过 C 或 C++、体会过手工管理内存的痛苦的人。
如果你没有那段经历，所有权和借用规则看起来会像是凭空的限制。

## 先修要求

- 需要一定的编程背景，最好写过 C 或 C++。
- 对操作系统里进程、线程、内存的概念有初步认识会更顺。
