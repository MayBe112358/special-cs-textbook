## 课程简介

CS431 讲并发程序为什么难写对。课程从并发的基本概念出发，
讲锁的实现与代价、内存模型与顺序保证、无锁数据结构，
以及并发环境下最棘手的一类问题——内存回收：一个节点被摘下来之后，
什么时候才能安全地释放它？

作业要求你自己实现这些东西：各种锁、并发哈希表、无锁链表、
以及基于 epoch 的内存回收机制。每个作业都有测试，包括专门用来暴露竞态的压力测试。

这门课难度明显高于同系列的 CS220，官方也把它排在后面。
如果你写过多线程程序并且被难以复现的 bug 折磨过，会特别有共鸣。

## 先修要求

- 需要 Rust 编程基础，建议先完成 CS220。
- 对并发有初步了解（线程、竞态、锁）。
