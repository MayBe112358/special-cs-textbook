## 课程简介

CS50P 是 CS50 系列里专讲 Python 的一门，比 CS50x 更窄也更实用。
它假设你零基础，按周依次讲函数与变量、条件、循环、异常、库、单元测试、文件读写、
正则表达式、面向对象，最后收在一个自选项目上。

值得单独指出的是它把单元测试排进了入门课。大多数入门课教到“程序能跑”为止，
这门课要求你写 `pytest` 测试来证明它跑得对——这是一个从一开始就该养成的习惯。

如果你的目标是尽快能用 Python 做事，这门课比 CS50x 更直接；
如果你想要的是对计算机整体的认识，CS50x 覆盖面更广。两门课没有先后关系。

## 先修要求

- 没有先修要求。
- 如果完全没接触过编程，这门课和 CS50x 都可以作为起点。
