## 课程简介

CS106B 是 Stanford 编程系列的第二门课，用 C++ 讲抽象与数据结构。
课程顺序很有代表性：先用课程提供的容器（Vector、Grid、Stack、Queue、Set、Map）
把注意力放在解决问题上，再讲大 O 分析，然后是递归——递归回溯、枚举、
递归式问题求解整整占了六讲——之后才进入面向对象、指针与动态内存管理，
最后是链表、树、哈夫曼编码、哈希与图算法。

这个顺序的用意是：先让你习惯用抽象思考，再揭开抽象底下的实现。
等你自己写链表和二叉树时，已经知道它们是用来干什么的了。

CS106X 是同一内容的加速加深版本，面向已有编程经验的学生。两门课的材料都公开。

## 先修要求

- 需要有编程基础，官方按 CS106A 或同等水平设定；CS50、CS61A 也够用。
- 不需要预先会 C++，课程前两讲会带你从已有语言过渡过来。
