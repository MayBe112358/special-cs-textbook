## 课程简介

CS50x 是哈佛的计算机科学与编程导论，也是全世界选修人数最多的公开课之一。
它面向的是完全没有基础的人，但它并不因此降低内容的硬度——课程从 Scratch 开始，
第一周就切到 C 语言，然后依次是数组、算法、内存与指针、数据结构，
之后转向 Python、SQL，再到 HTML/CSS/JavaScript 和 Flask，最后是一个自选的结课项目。

先讲 C 再讲 Python 是这门课的一个关键选择。你会先在一个什么都要自己管的语言里
体会内存、指针和手工实现数据结构的代价，再换到高级语言，
于是“方便”这件事对你来说就有了参照系，而不是理所当然。

课程的另一个特点是制作水准：讲座、讲义、题目和评分系统都打磨得非常完整，
作业有自动评分工具 `check50` 和风格检查 `style50`，在家自学也能得到接近课堂的反馈。

## 先修要求

- 没有任何先修要求，课程从零讲起。
- 唯一需要的是时间：官方估计每周 10 到 20 小时。

## 官方资源

- [课程主页](https://cs50.harvard.edu/x/)：按周组织的讲座、讲义与题目。
- [课程大纲](https://cs50.harvard.edu/x/syllabus/)：课程范围、评分与学术诚信规定。
- [OpenCourseWare 存档](https://cs50.harvard.edu/x/2025/)：往年完整材料，内容基本稳定。

## 官方作业

- [Problem Sets](https://cs50.harvard.edu/x/psets/)：每周一组题目，从 Scratch 到 Flask 依次推进。
- [结课项目](https://cs50.harvard.edu/x/project/)：自选题目，把整学期学到的东西做成一个完整作品。

作业自带 `check50` 自动评分与 `style50` 风格检查，本地即可自测。
