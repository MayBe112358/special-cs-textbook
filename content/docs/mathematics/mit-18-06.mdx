## 课程简介

18.06 是 MIT 的线性代数课，由 Gilbert Strang 讲授。这门课的录像在网上流传了二十多年，很多人第一次真正看懂线性代数就是在这里。
Strang 的讲法不是从抽象定义出发，而是从“解方程组”这件具体的事出发：
先用消元法解 $Ax = b$，然后一步步问：什么时候有解？有几个解？解都长什么样？
顺着这些问题，引出列空间、零空间和“四个基本子空间”这个贯穿全课的主线。

这里链接的是 OCW 的 **Scholar 版**，专门为自学者重新组织过：每一小节是一段 Strang 的讲课视频、一份讲课摘要、
推荐阅读（对应他自己写的教材的章节）、一段习题课视频，以及一组带解答的题目。
课程页上还收了 Strang 2023 年在 MIT 的最后一堂 18.06 课。

对学计算机的人来说，线性代数可能是最常用的一门数学：机器学习里的数据就是矩阵，最小二乘是线性回归，
特征值和奇异值分解（SVD）是主成分分析、推荐系统、图像压缩的核心；图形学里的变换、搜索引擎的 PageRank 也都是它。

## 先修要求

- MIT 校内的正式先修是 18.02 多变量微积分，但官方说学线性代数本身并不需要微积分。
- 真正需要的是熟悉向量、矩阵和三维坐标。这些在 [18.02](/docs/mathematics/mit-18-01-18-02) 的前几讲里有，高中数学学得扎实也够用。

## 课程结构

分三个单元，每个单元后面一场考试：

| 单元 | 讲什么 |
|---|---|
| I. $Ax = b$ 与四个子空间 | 线性方程的几何意义、消元、矩阵乘法与逆、$A = LU$ 分解、转置与置换、向量空间、列空间与零空间、解 $Ax = 0$ 和 $Ax = b$、线性无关、基与维数、四个基本子空间、图与网络的关联矩阵 |
| II. 最小二乘、行列式与特征值 | 正交、投影、最小二乘、正交矩阵与 Gram-Schmidt、行列式的性质与公式、克拉默法则、特征值与特征向量、对角化与矩阵的幂、微分方程与 $e^{At}$、马尔可夫矩阵、傅里叶级数 |
| III. 正定矩阵及其应用 | 对称矩阵与正定性、复矩阵与快速傅里叶变换（FFT）、正定矩阵与极小值、相似矩阵与 Jordan 标准形、奇异值分解（SVD）、线性变换、基变换与图像压缩、左逆右逆与伪逆 |

## 官方作业

全部在 [课程主页](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/) 里，按“小节 → 单元”组织，全部有解答：

- **每个小节的 Check Yourself**：一组 Problems，配 Solutions，先自己做完再对答案。
- **习题课视频（Problem Solving Video）**：每个小节一段，一位助教现场讲一道题的解法。不少习题课还有**普通话版本**，页面上标着 “watch this recitation in Mandarin”。
- **每个单元的考试**：先有一节考前复习，然后是考试和解答；最后是期末复习和期末考试。

## 学习建议

- **视频、摘要、习题一个都别落。** 看完讲课视频，读一遍摘要，做 Check Yourself 的题，再看习题课视频对照自己的思路。
- **抓住四个子空间这条主线。** 第一单元的每一节都在往这个图上添东西。学完第一单元，试着自己画出四个子空间的关系图，说出每个的维数，这比记住所有定理有用。
- **用 Python 动手算。** 用 NumPy 算一算投影、特征值、SVD，看看结果和手算的是不是一样。算过一次，概念会具体得多。
- **教材不是必须的。** 推荐阅读对应的是 Strang 的《Introduction to Linear Algebra》，需要另外买。没有教材，靠视频、摘要和习题也能学完。
- **学完别停。** 线性代数真正的用处在后面：机器学习课会反复用到投影、特征值和 SVD，遇到时回来翻对应的那一讲。

## 同类课怎么选

- **[MIT 18.01 / 18.02 微积分](/docs/mathematics/mit-18-01-18-02)**：常和 18.06 一起学。18.02 前几讲的向量和矩阵，正好是 18.06 的起点。
- **[Stanford EE364A 凸优化](/docs/advanced-mathematics/ee364a)**：线性代数之后的一个自然去处，最小二乘就是最简单的凸优化问题。
- 3Blue1Brown 的动画系列《线性代数的本质》很适合当作直观理解的补充，但它不是一门课，不能代替 18.06 的习题。
