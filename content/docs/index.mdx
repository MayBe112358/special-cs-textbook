## 这一步在验证什么

现在验证的是文档框架，而不是正式课程内容。页面应该同时出现左侧目录、中间正文和右侧页内导航。

## 正文元素

中间区域应该能正常显示：

- 一段普通文字
- 一个项目列表
- 一段代码

```js
const textbook = "目录 → 正文 → 官方习题";
console.log(textbook);
```

## 如何检查导航

点击右侧的“正文元素”，页面应滚动回上一节；点击左侧其他页面，正文应切换。
