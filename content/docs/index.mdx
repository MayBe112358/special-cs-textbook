## 如何使用这棵树

展开左侧任一分类，可以进入其中的课程。同一个主题下的不同学校的课程并排摆放，供你比较和挑选。
这里提供课程选择，不内置学习顺序。

你也可以用底部的终端走这棵树：`ls` 看当前位置有什么，`cd` 换位置，`cat` 读简介，`open` 打开页面，
`refs` 在课程和项目代码之间互相反查。鼠标和终端是同一棵树的两个入口，位置始终同步。
`help` 列出全部命令。打到一半按 Tab 可以补全；有多个候选时只列出来，不会替你选一个。

## 三块工作区和 AI 助手

左侧最外面那一条竖栏上面三个图标对应三块地方，最下面一个是 AI 助手：

- **课程目录**（你现在在这里）：每门课一页，只介绍这门课——讲什么、要先学什么、去哪里看官方资料和作业。
  页面标题下可以把这门课标成「想学 / 在学 / 学完」；代码讲解页上可以把一段实现标成「未读 / 读过 / 读懂了」。
  这两套标记都在你自己的浏览器里，和作者写在内容文件里的进度彼此独立。终端里用 `mark` 标记，用 `status` 查看。
- **学习路径**：把课程拖到画布上变成方块，用箭头连成你自己的路线。可以有多条；作者的 learncs.site 路线只是示例，
  复制之后才变成你的。课程目录里没有写死学习顺序。
- **个人心得**：和课程目录一样的一棵树，每门课一个心得空间。可以写 Markdown 文档（代码和公式都能渲染）、
  导入本地的笔记和代码文件、画导图。作者自己的心得也放在对应的心得空间里。
- **AI 助手**：点它，左边的树换成一个对话框，正文不动。先在设置里选模型厂商、填你自己的 API Key（只存在你的浏览器里）。
  它能读你的心得、导图、学习路径和学习状态，帮你答疑、写心得、画导图、起草路线；想改你的东西时，
  默认先给你看改前 / 改后，你同意了才写入。在终端里敲 `agent` 也能和它对话。

打开过的页面会变成内容区上方的标签，点一下就能切回去。先修关系写在每门课的「先修要求」里。
页面上的搜索框（Ctrl K）和终端里的 `search` 都能用中文或英文找课程和代码讲解，查询在浏览器里完成。
心得、学习状态、理解度和学习路径都只在你的浏览器里；个人心得首页可以把它们导出成一个备份文件。

## 课程页上的排版

课程页可以写数学公式、带语法颜色的代码，以及流程图。公式和代码颜色在构建时就生成好了；
流程图在浏览器里绘制，会比周围的文字稍晚出现。源码讲解页里摘出的例子多是终端命令和报错，照原样显示，不上颜色。

## 当前范围

已收录 130 门课程，覆盖 CS 自学指南列出的全部分支：

- **必学工具**、**编程入门**、**数学基础**、**数学进阶**、**数据结构与算法**
- **系统**：计算机系统基础、体系结构、操作系统、计算机网络、数据库系统、编译原理、
  编程语言设计与分析、并行与分布式系统、系统安全
- **人工智能与机器学习**：人工智能、机器学习、深度学习、机器学习进阶、机器学习系统、深度生成模型
- **计算机图形学**、**数据科学**、**Web 开发**、**软件工程**、**电子基础**
- **理论计算机科学**（这一支不在指南的分类里，由作者单独收录）

课程页只提供简介、先修要求和官方链接；练习一律指向课程团队自己发布的作业，本站不自编习题。
少数课程的官方站点已经下线或需要校内账号，页面上会写明，并给出仍然有效的官方入口。
