## 课程简介

CS571 讲的是用 React 做前端、用 React Native 做移动端的最佳实践，
内容完整而不啰嗦。

它有一个在前端课程里少见的优点：采用 React 与 React Native 的最新版本，
并且课程网站每学期都会更新。前端工具迭代极快，
大部分教程写完没多久就过期，这门课的维护节奏因此很可贵。

课程不是保姆式教学：作业涉及的技术和知识点会在课上讲解，
但不会手把手带着写代码。官方也提醒整个学期的作业量不小，
需要做好准备。这种安排更接近真实开发——
你要自己查文档、自己调试。

对想把 React 学扎实、而不是复制粘贴组件的人，这门课很合适。

## 先修要求

- 需要掌握至少一门编程语言。
- 有 JavaScript 与 HTML/CSS 基础会更顺，但不是硬性要求。
