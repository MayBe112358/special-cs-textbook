## 课程简介

CS571（Building User Interfaces）是威斯康星大学麦迪逊分校的本科课，由 Cole Nelson 和 Yuhang Zhao 合开。
课程网站的开场白说：这门课要带计算机系的本科生进入**用户体验（UX）开发**的世界——有时也叫前端开发，
就是做出“人真正会用、也好用”的界面。

课程的特点是**设计和开发交替讲**：一讲“Web 开发”，下一讲就是“视觉设计”“交互设计”“专家评估”“原型”“无障碍”；
开发的部分从网页基础（HTML、CSS、JavaScript）讲到 React，再到用 React Native 做手机应用，最近几个学期还加上了
语音界面和 AI 智能体开发。

作业都是一个接一个的小应用，而且会**用不同技术把同一个应用重写一遍**：Badger Mart 先用原生 JS 写，再用 React 写，
再用 React Native 写成手机应用，你能直接感受到每一层框架替你做了什么。

## 先修要求

- 至少会一门编程语言。JavaScript 从零讲起，HW0 就是写一个介绍自己的 JSON 文件。
- 要会用命令行、会装 Node.js 和 npm。从 HW5 起，作业都是 `npm install`、`npm run dev` 起步的 Vite 项目。
- 做手机应用那几份作业要用 Expo，最好有一台手机可以装 Expo Go 来测试。

## 课程结构

课程网站上 2025 年春季的讲次大致是这样排的（开发和设计交替）：

| 开发线 | 设计线 |
|---|---|
| Web 开发基础 1–3（HTML、CSS、JavaScript） | 设计思维 |
| Web 开发 1–5（React） | 视觉设计、网页设计、交互设计、专家评估、无障碍 |
| 移动开发 1–3（React Native） | 移动设计、原型 |
| 语音界面开发 / 智能体开发、全栈开发 | 语音界面设计、设计智能体、可用性评估 |

2026 年春季的课堂练习仓库显示，语音界面那部分已经换成了两讲“智能体开发”（agentdev1、agentdev2）。

## 官方作业

2026 年春季的作业起始代码都在公开的 GitHub 组织 [CS571-S26](https://github.com/CS571-S26) 下，每个仓库的 README 就是完整的作业说明：

| 作业 | 做什么 |
|---|---|
| HW0 Introductions | 用 JSON 写一份自我介绍 |
| HW1 Badger Mart | 用原生 HTML、CSS、JS 补全一个小超市网站，第一次调用课程 API |
| HW2 Badger Book | 把 HW0 全班交上来的自我介绍 JSON 从 API 取回来，做成一个能搜索的网页 |
| HW3 Badger Mart (React!) | 把 HW1 用 React 重写 |
| HW4 Badger Book (React!) | 把 HW2 用 React 重写 |
| HW5 Badger Buddies | 多页面、状态管理、Bootstrap 组件，数据是当地动物救助机构真实待领养的猫 |
| HW6 BadgerChat | 一个聊天室网站，也是最后一份 React 作业，综合检验前面学的全部内容 |
| HW7 Badger Mart (React Native!) | 第三次重写 Badger Mart，这次是手机应用 |
| HW8 Badger News | 用 Expo 和 React Navigation 做一个可定制的校园新闻 App |
| HW9 BadgerChat | 把聊天室做成手机应用 |
| HW10 BadgerChatGPT (AI!) | 用课程提供的大模型 API 做一个能切换多种角色的聊天界面 |
| HW11 BadgerChat Agent (Bucky) | 做一个会“调工具”的智能体：用户用自然语言说话，由它决定调用 BadgerChat 的哪些接口 |

每份作业还有一个配套的 `-api` 仓库，是这份作业用到的后端接口。
课堂练习也在同一个组织里（`ice-` 开头），每个仓库都有 `starter`（起始代码）和 `solution`（参考答案）两个目录，自学时可以先做再对照。

**校外自学要注意**：作业要调用课程自己的 API，需要一个 Badger ID。README 里给了自助申请的入口，但它是给选课学生准备的，
校外能不能用没有写明。拿不到的话，前端部分照样可以做，后端数据可以参考 `-api` 仓库自己模拟。

## 学习建议

- **一定要体验“同一个应用写三遍”。** Badger Mart 的原生 JS、React、React Native 三个版本做完，
  你会非常清楚 React 的“状态驱动界面”到底解决了什么问题，以及 Web 和手机开发哪里一样、哪里不一样。
- **设计课不要跳过。** 很多人学前端只学框架。这门课一半在讲设计：视觉层次、交互反馈、无障碍、可用性评估。
  这些决定了你做的东西别人愿不愿意用。
- **HW11 值得认真做。** “定义工具 + 写智能体循环”是现在做 AI 应用最核心的模式，这份作业用一个很小的例子把它讲透了。
- **每份作业都读完 README 再动手。** 说明写得很细，常见的坑（比如 HW1 不要用 Live Server）都写在里面。

## 同类课怎么选

- **[Full Stack Open](/docs/web-development/full-stack-open)**：赫尔辛基大学的全栈课，React + Node + 数据库 + 测试 + 部署，后端讲得多得多，完全面向校外，有中文版。
- **[Stanford CS142](/docs/web-development/stanford-cs142)**：斯坦福的 Web 应用开发，偏原理（浏览器、HTTP、安全）。
- **[MIT Web Lab](/docs/web-development/mit-web-dev)**：MIT 一月的速成课，四周做出一个完整网站。
- CS571 是这几门里唯一系统讲**设计**和**手机开发**的，也是唯一把 AI 智能体放进作业的。
