## 课程简介

CS142 是 Stanford 的 Web 应用开发课，覆盖前后端的主要技术栈。

课程从 Web 的基础开始：HTTP、HTML、CSS、
浏览器的渲染模型与文档对象模型，然后是 JavaScript 语言本身，
接着进入 React 的组件模型与状态管理，
再到服务端——Node.js、Express、MongoDB 与 REST API 的设计，
最后是 Web 安全（同源策略、XSS、CSRF、认证与会话管理）。

课程的八个项目串成一条线：从写静态页面开始，
逐步做出一个完整的照片分享应用，前后端都是自己写的。
这种渐进式的项目安排比孤立的练习更能建立整体感。

## 先修要求

- 需要一定的编程经验。
- 不要求预先了解 Web 技术。
