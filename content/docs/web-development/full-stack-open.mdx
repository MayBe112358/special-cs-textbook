## 课程简介

Full Stack Open 是赫尔辛基大学开放的现代 Web 开发课程，
可以按自己的节奏学，全部内容和练习免费公开，并且有完整的中文版。

课程主线是用 JavaScript 开发现代 Web 应用：
重点是用 React 构建单页面应用（SPA），
并用 Node.js 构建 REST API。除此之外还包括
GraphQL（REST 的现代替代方案）、测试、
配置与环境管理，以及用 MongoDB 存储数据。
后续的可选部分还涉及 TypeScript、React Native、
持续集成与容器化。

它的练习量很大——每一章都有一系列递进的练习，
最终你会做出若干个完整可部署的应用。
对想系统学 Web 开发而不是拼凑教程的人，这是很扎实的一条路。

## 先修要求

- 需要良好的编程技能。
- 需要基本的网络编程与数据库知识，以及 Git 的基础用法。
