## 课程简介

MIT 每年一月有一个为期四周的独立活动月（IAP），
师生可以自由开设各种课程，这门 Web 开发速成课就是其中之一。

四周时间里，课程会带你从零掌握一个网站的设计、搭建、
美化与交互：HTML 与 CSS、JavaScript、React、
Node 与 Express、数据库、用户认证与部署。
覆盖的是 Web 开发前后端的大部分主流技术栈。

它的定位很清楚：如果你不需要系统地学网络开发，
只是出于兴趣想把它加进自己的工具箱，这门课的节奏刚好——
时间短、密度高、直接做项目。

课程日程与材料公开在课程网站上。

## 先修要求

- 需要掌握至少一门编程语言。
- 不要求预先了解 Web 技术。
