## 课程简介

EECS126（Probability and Random Processes）是伯克利电子与计算机系的概率课，
把 [CS70](/docs/advanced-mathematics/cs70) 后半学期的概率往前推了一大步。
系里的课程说明列的内容是：样本空间与概率律、条件概率与独立、随机变量与分布、随机向量、
大数定律、中心极限定理、估计与检测、马尔可夫链。2026 年秋季由 Venkatachalam Anantharam 讲授。

这门课在伯克利讲了很多年，长期授课的 Jean Walrand 把它写成了一本书：
《Probability in Electrical Engineering and Computer Science: An Application-Driven Course》（Springer，2021），
**开放获取，按 CC BY 4.0 协议免费下载**。书的组织方式很特别——不是按“随机变量、期望、方差”排章，
而是按应用排：PageRank、多路复用、网络、数字通信链路、跟踪（GPS 与卡尔曼滤波）、语音识别、路径规划。
每个应用分 A、B 两章，A 章用这个问题引出需要的概率工具，B 章把工具讲深。

对想走机器学习、通信或网络方向的人，这门课补的是最容易被跳过、但后面最常用到的那部分数学：
马尔可夫链、检测与估计、卡尔曼滤波、期望最大化。

## 先修要求

- 系里写的是“CS70 优先但不强制，需要熟悉线性代数”。
  实际上，没学过条件概率和期望的人会很吃力，建议先学完 [CS70](/docs/advanced-mathematics/cs70) 的概率部分。
- 线性代数要能熟练做矩阵乘法、求特征向量——马尔可夫链的平稳分布就是一个特征向量问题。
  没学过的话先看 [MIT 18.06](/docs/mathematics/mit-18-06)。
- 配套代码是 Python（NumPy、Matplotlib）。教材附录 1“Prerequisites”里有 Python 入门、函数最大化、线性规划、
  梯度算法和概率的一组练习，可以用来自测。

## 课程结构

伯克利每学期的课程网站需要校内账号，校外看不到日程。下面按公开教材配套代码的各章内容列出，这也是这门课多年来的讲法：

| 应用 | 引出的概率工具 |
|---|---|
| PageRank | 离散时间马尔可夫链、平稳分布、强大数定律、Borel–Cantelli 引理 |
| 多路复用 | 中心极限定理、高斯分布、置信区间、ALOHA 多路访问、特征函数 |
| 网络 | 传染病与社交网络模型、排队模型、连续时间马尔可夫链、排队网络 |
| 数字通信链路 | 霍夫曼编码、带噪声的检测（MAP）、LDPC 纠错码 |
| 跟踪 | 线性回归与最小二乘估计、卡尔曼滤波、可观性 |
| 语音识别 | 贝叶斯更新、维特比算法、聚类、随机梯度下降、期望最大化 |
| 路径规划 | 马尔可夫决策过程、动态规划（Bellman） |

系里的格式是每周 3 小时讲课、1 小时讨论课，有期末考试。

## 官方作业

- **教材习题**：Springer 书的每章末尾有习题，出版社的介绍里写明书中带作业和解答。校外自学以这部分为准。
- **配套 Jupyter Book**（[Probability in EECS](https://jeanwalrand.github.io/PeecsJB/intro.html)）：
  每章对应书里的一章，把书里的图做成可以运行、可以调参数的代码。比如 PageRank A 那章，
  你可以选起始网页和步数，看马尔可夫链在各个网页停留的比例怎么收敛到平稳分布。
  页面上点火箭图标选 Live Code 就能在线运行，不用装任何东西。
- **课程网站**：伯克利的作业、实验和往年考试都放在 `inst.eecs.berkeley.edu/~ee126/` 下，**需要 CalNet 登录**，校外打不开。

## 学习建议

- **先做附录 1。** 它同时检查你的 Python 和概率基础，哪里卡住就先补哪里。
- **每章先读 A 再读 B。** A 章的应用就是后面所有公式的动机，跳过它直接看定理会很难记住为什么要学。
- **每个工具都跑一次配套代码。** 马尔可夫链收敛多快、中心极限定理从多少个样本开始“像正态”，
  自己改参数看一遍，比读推导记得牢。
- **把卡尔曼滤波手推一遍。** 它是这门课里最常在工作中遇到的东西（机器人、导航、金融），
  也是最容易“看懂了但写不出来”的一个。

## 同类课怎么选

- **[CS70](/docs/advanced-mathematics/cs70)** 是它的前置课：概率的基本定义、期望、方差、马尔可夫链入门。
- **[MIT 6.050J](/docs/mathematics/mit-6-050j)** 和 **[MacKay 的信息论](/docs/advanced-mathematics/mackay-information-theory)**：
  如果你更关心“信息”“编码”“推断”，这两门和 EECS126 的检测、估计部分互补。
- 学完之后往机器学习走，可以接 [CS229](/docs/ai-machine-learning/machine-learning/cs229)
  或 [CS189](/docs/ai-machine-learning/machine-learning/cs189)，里面的最大似然、EM、隐马尔可夫模型在这门课都见过了。
