## 课程简介

18.330（Introduction to Numerical Analysis）讲的是：当一个数学问题没有解析解，或者解析解算起来不现实时，
怎么让计算机算出一个足够好的近似，以及怎么证明这个近似有多好。

比如解一个 1000 元的线性方程组，高斯消元为什么要“选主元”，不选会怎样；
牛顿法求根为什么收敛得那么快，又在什么时候会发散；
算一个积分，均匀取点和高斯求积差在哪里。每个方法都要回答两个问题：它收敛吗？误差多大？

目前公开的是两个学期的材料：

- **2023 年秋季**（John Urschel 讲授）：[GitHub 仓库](https://github.com/mitmath/18330) 里有课程大纲、七份习题和期末项目说明，都是 PDF。
- **2012 年春季**（Laurent Demanet 讲授）：[MIT OpenCourseWare](https://ocw.mit.edu/courses/18-330-introduction-to-numerical-analysis-spring-2012/) 上有七章讲义和八份作业。

两个学期的侧重点不同，下面的“课程结构”按 2023 年秋季来写，最后说怎么搭配 2012 年的讲义。

## 先修要求

- 2023 年大纲写的先修是 Calculus II（多变量微积分）和 18.03（常微分方程）；线性代数 [18.06](/docs/mathematics/mit-18-06) 有用，但不是必需。
  微积分没学好的话先看 [MIT 18.01/18.02](/docs/mathematics/mit-18-01-18-02)。
- 每份习题有两道编程题，课程没有指定语言。Python（NumPy）、Julia、MATLAB 都可以，交作业时附上代码和输出。

## 课程结构

2023 年秋季的大纲分七个主题，每个主题配一份习题：

| 主题 | 讲什么 |
|---|---|
| 数值分析基础 | 浮点运算、赋范空间、误差分析、算法设计 |
| 线性方程组的直接法与迭代法 | 高斯消元、选主元策略、Jacobi 迭代、Gauss-Seidel 方法 |
| 非线性方程 | 不动点定理、二分法、牛顿法、割线法、Aitken Δ² 加速、多项式求根 |
| 特征值问题 | 幂法、Householder 反射、QR 算法 |
| 函数逼近 | 多项式插值、三次样条、正交多项式 |
| 数值微分与积分 | 有限差分、Newton-Cotes 公式、高斯求积 |
| 微分方程的数值解 | 初值问题、边值问题、偏微分方程入门 |

学期末如果有时间，会按学生兴趣讲 Krylov 子空间方法、有限元、数值优化、最小二乘、蒙特卡洛、自动微分等。

2023 年没有指定教材，大纲推荐了四本（都能在网上找到）：Burden 和 Faires 的《Numerical Analysis》（最容易读）、
Stewart 的《Numerical Analysis: A Graduate Course》（偏计算）、Stoer 和 Bulirsch 的《Introduction to Numerical Analysis》（经典）、
Kress 的《Numerical Analysis》（更深）。

## 官方作业

2023 年秋季的七份习题（`p1.pdf` 到 `p7.pdf`）和期末项目都在 [GitHub 仓库](https://github.com/mitmath/18330) 里：

- **Problem Set 1～7**：每份对应上面一个主题，名字就是主题名（比如 Problem Set #4: Eigenvalue Problems）。
  每份有八道题，六道理论题（标 M）、两道编程题（标 C），带星号的是难题。
  **只需要挑四道交**，编程题要附代码和输出。每份占总评 10%。
- **期末项目**（`final.pdf`，占 30%）：选一个课上没有深入讲的数值分析主题，写一份技术报告。
  选题的标准是“你能就它讲一节 75 分钟的课”——不能太窄，也不能大到要讲好几次。先交一页的选题提案，再交报告。
  文件里附了一些参考题目。

**这些习题都没有公开解答。** 如果想对答案，OCW 上 2012 年的[八份作业](https://ocw.mit.edu/courses/18-330-introduction-to-numerical-analysis-spring-2012/pages/assignments/)内容相近，可以搭配着做。

## 学习建议

- **理论题和编程题都要做。** 官方只要求交四道，自学时建议每份至少一道理论、一道编程：
  证明告诉你误差的上界，程序让你亲眼看到误差怎么随步长、迭代次数变化。
- **把误差画成对数坐标图。** 比如用梯形公式算积分，把误差对步长 h 画在双对数坐标上，得到一条斜率约为 2 的直线，
  这个斜率就是方法的阶。牛顿法是二阶收敛，每迭代一次有效数字大约翻倍，打印出来一目了然。
- **故意把方法用坏。** 不选主元的高斯消元、初值离得太远的牛顿法、在等距点上做高次插值（龙格现象），
  亲手让它们出错一次，比读十遍“注意事项”都管用。
- **期末项目当作一次真的学习。** 挑一个你将来可能用到的题目（比如自动微分、蒙特卡洛），写报告的过程就是把它学透的过程。

## 同类课怎么选

- **2012 年 OCW 版**：Demanet 的七章讲义是 级数与数列、积分与导数的离散化、插值、非线性方程、常微分方程的数值方法、
  傅里叶分析、谱方法（谱插值、谱微分、谱求积）。它讲傅里叶和谱方法更多，线性方程组和特征值讲得少，
  正好和 2023 年版互补。
- 对优化更感兴趣的话，看 [Stanford EE364A](/docs/advanced-mathematics/ee364a)（凸优化），它把“怎么数值求解”换成了“怎么把问题写成能高效求解的形式”。
- 数值线性代数想学得更深，[MIT 18.06](/docs/mathematics/mit-18-06) 是基础，之后可以找专门的数值线性代数课。
