## 课程简介

18.330 讲的是：当一个数学问题没有解析解，或者解析解算起来不现实时，
怎么让计算机算出一个足够好的近似，以及怎么知道这个近似有多好。

课程从浮点数开始——为什么 0.1 + 0.2 不等于 0.3，误差怎么累积——
然后依次是求根、插值与逼近、数值积分、线性方程组与特征值的数值解法、
常微分方程的数值积分，最后是快速傅里叶变换。

课程用 Julia 授课，所有讲义和代码以 Jupyter Notebook 的形式公开在 GitHub 上，
可以直接运行、直接改参数看误差怎么变。这种“可执行的讲义”对理解数值方法特别有效。

## 先修要求

- 需要微积分与线性代数。
- 需要概率论基础，以及一定的编程能力（课程用 Julia，但不要求预先会）。
