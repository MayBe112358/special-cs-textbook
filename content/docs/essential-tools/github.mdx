## 课程简介

Git 管的是你自己机器上的版本历史，GitHub 管的是一群人怎么围着同一份历史协作。
它加进来的东西——Issue、Pull Request、代码评审、Actions 自动化——本身不是 Git 的一部分，
但已经成为开源世界事实上的协作约定。

对自学者来说，GitHub 还有另一层意义：绝大多数公开课的代码框架、绝大多数你会读的开源项目，
都在这里。学会读一个陌生仓库、看懂它的提交历史和 Issue 讨论，是一项独立于写代码的能力。

这本教材本身就托管在 GitHub 上，页面底部的公开评论用的也是这个仓库的 Discussions。

## 先修要求

- 先了解 Git 的基本概念（提交、分支、远程仓库）。
- 需要一个 GitHub 账号。
