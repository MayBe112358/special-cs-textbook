## 课程简介

Emacs 官方对自己的描述是“advanced, extensible, customizable, self-documenting”——
先进、可扩展、可定制、自带文档。前三个词说的是同一件事：Emacs 的绝大部分功能是用
Emacs Lisp 写的，你可以在运行时读它、改它、替换它。

这让它不只是编辑器。收发邮件、管理待办、写论文、跑 shell、连数据库，都有人用 Emacs 做。
代价是学习曲线陡：默认的快捷键体系和现代编辑器很不一样，而且你迟早要学一点 Lisp。

“自带文档”是它最被低估的优点：任何一个按键、任何一个函数，都能用 `C-h k`、`C-h f`
当场查到它是什么、定义在哪里。这套自省能力本身就值得一看。

## 先修要求

- 没有硬性先修要求。
- 愿意接受一套和主流编辑器不同的快捷键约定，是能坚持下去的前提。

- [Emacs 官网](https://www.gnu.org/software/emacs/)：下载与项目信息。
- [全部官方手册](https://www.gnu.org/software/emacs/manual/)：包括 Emacs Lisp 参考手册在内的文档集。

## 官方作业

- [官方导览](https://www.gnu.org/software/emacs/tour/)：先花二十分钟看完这个，再决定要不要深入。

这是工具而不是课程，没有官方作业。
