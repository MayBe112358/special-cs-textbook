## 简介

把终端用顺手，靠的不是背更多命令，而是几样具体的功夫：

- **管住正在跑的程序。** 一个任务跑太久，怎么停下来、丢到后台、过会儿再拿回来（作业控制：`Ctrl-C`、`Ctrl-Z`、`bg`、`fg`、`jobs`、`kill`）。
- **一个窗口干几件事。** 用 tmux 在一个终端里开多个窗格和会话，断开 SSH 以后程序照样在跑，重新连上还能接着看。
- **把习惯带到每台机器上。** 常用命令起个短别名（alias），把配置写在 dotfiles（`~/.bashrc`、`~/.gitconfig` 这类点开头的文件）里，用 Git 管起来，换台电脑一拉就有。
- **在远程机器上干活。** SSH 登录、用密钥代替密码、写 `~/.ssh/config` 给常用主机起名字、端口转发。
- **用管道处理数据。** 把 `grep`、`sed`、`awk`、`sort`、`uniq` 这些小工具串成一条流水线，几行命令就能从一大堆日志里算出你要的数字。

这些平时没人系统地教，MIT 的 [Missing Semester](/docs/essential-tools/missing-semester) 把它们集中讲了几讲。
学完以后，你对终端的感觉会从“一个输命令的框”变成“一个可以编程的环境”。

管道那部分和这本教材关系特别近：这本教材的终端里，命令之间传的是带结构的数据而不是纯文本，正是从 Unix 管道的思路改出来的（讲解区第 3 章讲了这件事）。

| 功夫 | 讲在哪儿 |
|---|---|

| 作业控制、tmux、别名、dotfiles、SSH（密钥、配置、端口转发） | Missing Semester 2020：Command-line Environment |

| 更好用的现代命令行工具 | Missing Semester 2026 第 1 讲里的推荐 |

2026 版第 1 讲顺手推荐了几件比老工具更好用的替代品，值得装上试试：
`tldr`（配合 `man`，直接给常用例子）、`zoxide`（记住你常去的目录，`z` 一下就跳过去）、`eza`（更好读的 `ls`）、
`bat`（带语法高亮的 `cat`）、`ripgrep`（更快更顺手的 `grep`）、`fd`（更顺手的 `find`）。
讲义也提醒了：它们更好用，但不一定每台机器上都有，老工具还是要会。

## 学习建议

- **每学一招，马上用在你的日常里。** 学完 tmux 就在下一次跑长任务时用它，学完别名就把你每天敲十遍的命令缩短。不用就会忘。
- **dotfiles 从现在开始积累。** 建一个 dotfiles 仓库，每改一次配置就提交一次。几年后这会是你最值钱的仓库之一。
- **管道要一段一段地搭。** 先写第一段看输出，对了再接下一段。一口气写一长串，出错了都不知道错在哪。
- **SSH 用密钥，不用密码。** 更安全，也不用每次都输入。
