## 课程简介

自学过程中卡住是常态，区别在于卡住之后多久能自己出来。
这一页关注的就是这项能力：怎么把一个模糊的困惑变成一个可检索的问题，
怎么在代码里而不是在搜索引擎里找答案。

具体包括几件事：读懂报错信息里真正有用的那一行；用 GitHub 的代码搜索
在真实项目里找某个 API 的实际用法；直接读官方文档和源码，而不是先看二手教程；
以及判断一份搜索结果是不是过期了。

这项能力没有课程会教，但它决定了你能不能独立学下去。

## 先修要求

- 没有先修要求。
- 有一个自己正在卡住的真实问题，练习效果最好。

## 官方资源

- [GitHub 搜索文档](https://docs.github.com/en/search-github)：在代码、Issue 和讨论里检索。
- [代码搜索语法](https://docs.github.com/en/search-github/github-code-search/understanding-github-code-search-syntax)：按语言、路径、仓库精确限定。
- [MDN Web 文档](https://developer.mozilla.org/)：Web 相关问题的权威一手资料。

## 官方作业

- [代码搜索练习](https://docs.github.com/en/search-github/github-code-search/understanding-github-code-search-syntax)：挑一个你正在用的库，用代码搜索找出它在真实项目里怎么被调用。

这是一项习惯而不是课程，没有官方作业。
