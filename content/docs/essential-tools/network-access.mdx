## 课程简介

自学公开课会反复遇到一类问题：某个课程网站打不开、某个包装不上、
某个仓库克隆到一半断了。把这些都归结为“网络不好”没有用，值得先理解中间到底有哪些环节。

从浏览器地址栏到对方服务器，一次请求要经过域名解析、路由、TCP 连接、TLS 握手、
HTTP 响应这几层。知道这条链路之后，排查就有了顺序：是解析不出来，还是连不上，
还是连上了但返回错误。

这一页给的是入门材料。真正系统的网络知识在“系统 → 计算机网络”那一支，
CS144 会让你把整个 TCP/IP 协议栈亲手实现一遍。
