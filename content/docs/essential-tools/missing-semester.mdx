## 课程简介

大学课程会教你操作系统、机器学习这些高深题目，却几乎没有一门课教你怎么用手边的工具。
Missing Semester 就是为这个空缺开的：官方的说法是，学生在整个求学期间要花几百个小时、
在职业生涯里要花几千个小时使用这些工具，那就值得把这件事做得顺手一些。

课程按主题分成十来讲：shell 的使用与脚本、命令行环境（作业控制、别名、dotfiles、SSH）、
编辑器（以 Vim 为例）、数据处理、命令行工具、版本控制（Git 的内部模型）、调试与性能分析、
元编程（构建系统、依赖管理、测试）、安全与密码学，以及大杂烩式的实用技巧。

这门课的价值不在于某一条命令，而在于它让你意识到：工具是可以被理解和改造的，
不是只能照着教程抄。这本教材底部的终端就是照着这套 shell 语义做的——`ls`、`cd`、`cat`
为什么是那样的行为，答案在这门课里。

## 先修要求

- 没有先修要求。会用电脑、愿意打开终端就可以开始。
- 如果你从没用过命令行，从第一讲的 shell 入门开始，不要跳。

## 官方资源

- [课程主页](https://missing.csail.mit.edu/)：当前年份的讲座列表与讲义，每一讲都有完整的文字版。
- [往年版本](https://missing.csail.mit.edu/2020/)：2020 年版内容完整、配套练习齐全，中文社区引用的多是这一版。
- [开课动机](https://missing.csail.mit.edu/about/)：这门课为什么存在，作者自己的说明。

## 官方作业

- [Shell 入门与练习](https://missing.csail.mit.edu/2020/course-shell/)：每一讲文字版的末尾都有 Exercises 一节，练习就在那里。
- [命令行环境](https://missing.csail.mit.edu/2020/command-line/)：作业控制、别名与 dotfiles 的练习。
- [版本控制](https://missing.csail.mit.edu/2020/version-control/)：从 Git 的数据模型入手理解命令。

练习没有自动评分，判断标准是你能不能在自己的机器上把它跑出来。
