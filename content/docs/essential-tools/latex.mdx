## 简介

LaTeX 不是 Word 那样“所见即所得”的软件。你写的是一份带标记的纯文本：这里是一节的标题（`\section`），这里是一个公式（`$...$`），这里引用第 3 张图。
然后交给 TeX 系统去编译，它把排版的活全包了，吐出一份 PDF。

这种“只管说清楚结构、样子交给系统”的方式，在几件事上特别好用：
**数学公式**，写起来快、排出来漂亮，几乎所有数学、物理、计算机的论文和教材都用它；
**长文档**，章节编号、图表编号、交叉引用、目录、参考文献全自动，改了顺序也不用手动重新编号；
**版本管理**，源文件是纯文本，可以用 Git 管理，能看清每次改了什么。

你在这本教材里写心得时用的 `$...$` 公式写法，还有很多课程作业要求用 LaTeX 交的书面题，都是这一套。

## 先修要求

- 没有先修要求。
- 需要一个 TeX 系统（比如 TeX Live、MiKTeX），或者直接用在线编辑器，不用装任何东西。

## 学习路线

以 [learnlatex.org](https://www.learnlatex.org/en/) 的 16 课为主线，每课都很短：

| 阶段 | 课次 | 学什么 |
|---|---|---|
| 起步 | 1–3 | LaTeX 是怎么工作的、TeX 系统和编辑器、一份文档的基本结构 |
| 结构 | 4–6 | 逻辑结构和外观分开、文档类、用宏包扩展功能 |
| 内容 | 7–10 | 插图、表格、交叉引用、数学公式 |
| 进阶 | 11–14 | 字体与间距、参考文献、把长文档拆成多个文件、字体和 Unicode 引擎 |
| 自助 | 15–16 | 看懂报错、去哪里找帮助和文档 |

学完这 16 课，写一份作业、一篇课程报告已经足够；写学位论文时再深入参考文献、模板和排版细节。

## 官方教程与练习

- [learnlatex.org](https://www.learnlatex.org/en/)：LaTeX 社区做的免费入门教程，16 节短课，每课都有很多示例，**示例能在网页里直接修改、编译、看结果**，不用装任何东西。每课还有一页“More on this topic”补充细节。有[简体中文版](https://www.learnlatex.org/zh-hans/)。
- [LaTeX 项目的文档页](https://www.latex-project.org/help/documentation/)：LaTeX 团队维护的核心文档，包括 LaTeX2e 的入门指南和各种说明。

LaTeX 是工具，没有作业；最好的练习，是下一次写作业报告、写课程笔记时就用它。

## 学习建议

- **先在网页里玩起来。** learnlatex.org 的示例能直接在浏览器里跑，先不装软件，把 16 课过一遍。
- **公式是最值得先学的。** 第 10 课的数学公式，学会了在各种地方都能用：写心得、写 Markdown、在论坛里提问。
- **学会看报错。** LaTeX 的报错信息看着吓人，其实大多数时候只是少了一个括号或一个 `\end`。第 15 课专门讲这个。
- **别急着调样子。** LaTeX 的精神是“先写内容和结构，样子交给文档类”。新手最容易掉进的坑，是花一下午调一个间距。
- **中文要用 XeLaTeX 或 LuaLaTeX。** 写中文文档时要用支持 Unicode 的引擎，第 14 课讲了为什么。

## 同类工具怎么选

- **Markdown**：更轻，适合笔记、文档、README，也能写公式（`$...$`），但排版控制力远不如 LaTeX。这本教材的心得编辑器用的就是 Markdown 加公式。
- **Typst**：一个较新的排版系统，语法更简单、编译更快，正在流行起来。不过学术界和大部分期刊、课程模板还是以 LaTeX 为主。
- **[学位论文](/docs/essential-tools/thesis)**：用 LaTeX 写毕业论文的专门话题，接着看那一页。
