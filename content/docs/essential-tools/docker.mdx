## 课程简介

很多课程的实验环境配置比实验本身还费时间：版本对不上、依赖装不全、
不同操作系统行为不一致。Docker 的做法是把运行环境本身描述成一个可构建、可分发的镜像，
任何人拉下来跑，得到的环境都一样。

这对自学者的意义很直接：越来越多的公开课（比如 SEED Labs、CMU 15-445）直接提供
Docker 环境，省掉你在配置上卡住的那几天。

概念上要分清三样东西：Dockerfile 是构建说明，镜像是构建结果，容器是镜像的运行实例。
理清这三者，大部分命令就不用死记了。

## 先修要求

- 会用命令行。
- 了解操作系统里进程和文件系统的基本概念会更容易理解它在做什么。
