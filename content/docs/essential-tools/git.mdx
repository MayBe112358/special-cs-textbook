## 课程简介

大多数人学 Git 的方式是背命令：要提交就 `commit`，要同步就 `push`，出了问题就上网搜。
这种学法能应付日常，但一遇到分支冲突、误删提交、历史重写就会束手无策。

更省力的顺序是反过来：先理解 Git 的数据模型——一个由快照组成的有向无环图，
分支只是指向某个提交的可移动指针——再看那些命令。你会发现命令行界面确实有些别扭，
但它背后的模型其实非常简洁。

官方的 Pro Git 是这方面最完整的免费材料，中文版也由社区译好放在同一个站点上。

## 先修要求

- 会用命令行执行基本命令。
- 有一个自己的项目可以拿来练手，效果比看教程好得多。
