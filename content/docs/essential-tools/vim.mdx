## 课程简介

Vim 的核心不是快捷键多，而是它把编辑动作设计成了一门可以组合的小语言：
一个动词（删除、修改、复制）加一个范围（一个词、一个句子、到行尾），
组合出来的命令数量远多于你需要记住的零件数量。

它的另一个特点是模式：普通模式下按键是命令而不是输入文字。这是初学者最容易卡住的地方，
也是它效率的来源——大部分时间你不是在打字，而是在移动和改动。

Vim 自带一套极其完整的文档系统，用 `:help` 就能查。装好 Vim 之后先在终端里运行
`vimtutor`，那是官方自带的三十分钟交互教程，比任何第三方入门文章都靠谱。

## 先修要求

- 会在终端里打开和退出一个程序即可。
- 最好先知道怎么退出 Vim（`:q!`），这是所有人的第一道坎。
