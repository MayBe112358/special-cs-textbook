## 课程简介

CMake 不直接编译代码，它生成构建系统：Makefile、Ninja 文件，或者 Visual Studio、
Xcode 的工程文件。你写一份 `CMakeLists.txt`，在不同平台上得到各自能用的构建方式。

官方文档按人群分了几条入口：只想编译别人的源码包，看 User Interaction Guide；
想在自己的项目里用第三方库，看 Using Dependencies Guide；从零开始建项目，
从 CMake Tutorial 开始。这几条路要求的知识量差别很大，先认准自己属于哪一类。

CMake 主要服务 C 和 C++，但也能用于其他语言。它是许多公开课（比如 CMU 15-445、
KAIST CS420）实验框架的构建方式，所以即使你不打算深入，也值得会读。

## 先修要求

- 了解编译、链接的基本概念。
- 最好先用过 Make 一类的构建工具。

## 官方资源

- [使用者指南](https://cmake.org/cmake/help/latest/guide/user-interaction/index.html)：只想把别人的源码编译出来时看这个。
- [依赖管理指南](https://cmake.org/cmake/help/latest/guide/using-dependencies/index.html)：在自己的项目里引入第三方库。
