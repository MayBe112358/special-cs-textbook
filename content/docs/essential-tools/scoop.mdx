## 课程简介

在 Linux 上装个工具是一条命令的事，在 Windows 上往往要找官网、下安装包、
点下一步、再手动配环境变量。Scoop 把这套流程变成 `scoop install <名字>`，
并且默认装到用户目录下，不需要管理员权限，也不往系统里乱塞东西。

对跟着公开课自学的人，它解决的是一个很具体的麻烦：课程假设你有 git、make、gcc、
python 这些工具，而 Windows 上并不自带。

它的另一个好处是可复现：装了什么、什么版本，都能导出成清单，换台机器照着装回来。

## 先修要求

- 使用 Windows。
- 会打开 PowerShell 并执行命令。
