## 课程简介

17-803（Empirical Methods）是卡内基梅隆大学软件研究所的研究生课，主讲 Bogdan Vasilescu。
课程网站公开了 **2026 年春季**的全部幻灯片和讲课录像，还有 2024、2022、2021、2018 年的存档。

官方的出发点很实在：不管你研究什么，迟早都要做实证研究——评估一个新算法、一个新工具、分析一批大数据、
弄清楚某个领域的从业者遇到了什么困难。这门课就是教你**用有原则、严谨的方式**做这些事。

内容覆盖质性和量化两类方法：访谈、质性编码与主题分析、问卷设计、混合方法、实验设计、
各种回归（线性回归、混合效应模型）、时间序列分析、因果推断。

官方还说了一个“副作用”：这门课会让你对科学结论保持一份健康的怀疑——研究设计真的支持作者的结论吗？
分析方法呢？证据是不是还能更强？有没有根本性的缺陷？

## 先修要求

- 官方写的是：基础统计和基础编程，比如会写脚本提取、整理数据，熟悉假设检验。
- 回归那几讲用 R 做示例，推荐的参考书也以 R 为主（《R for Data Science》），会 Python 的话也能看懂。
- 课程主要面向博士生，每周阅读量很大。官方估计每周约 12 小时：3 小时上课、9 小时阅读和作业。

## 课程结构

2026 年春季按日程表：

| 部分 | 讲什么 |
|---|---|
| 研究的起点 | 导论、提出研究问题、文献综述、理论的作用 |
| 质性方法 | 访谈、质性数据分析（编码）、课堂实操：给访谈记录做编码和主题分析 |
| 问卷与混合方法 | 混合方法、问卷设计（两讲） |
| 实验 | 实验设计三讲（含课堂活动：给定场景设计实验） |
| 量化分析 | 回归建模三讲（含混合效应模型）、时间序列 |
| 收尾 | 客座讲座、期末研究项目展示 |

中间穿插了很多次论文讨论课，由学生轮流讲一篇实证研究论文。

## 官方作业

课程的评分：研究项目 50%（开题展示 10%、期末展示 10%、期末报告 30%），其他作业 40%，课堂展示和参与 10%。

- **学期研究项目**：一整个学期做一项自己的实证研究，最后要写报告、做展示。这是整门课的核心。
- **作业**：很多是两人一组完成，一份接一份递进。作业题目发在 CMU 内部的 Canvas 上，**校外看不到**。
- **课堂活动**：比如给访谈记录做质性编码、为给定场景设计实验，活动说明和幻灯片是公开的。
- **阅读**：每讲的页面列出必读和选读文献，并附一两句说明为什么要读它。多数文献可以在网上找到，部分放在需要 CMU 账号的 Google Drive 里。

## 学习建议

- **把每讲页面当成带注释的书单。** 比如“提出研究问题”那一讲，推荐的是 Easterbrook 等人的《Selecting Empirical Methods for Software Engineering Research》，
  讲清楚了每种方法适合回答哪类问题；回归那一讲推荐了《An Introduction to Statistical Learning》第 3 章和一篇《十二个关于 p 值的误解》。
- **一边学一边做一个小研究。** 没有作业题也没关系：找一个你真正好奇的问题（比如“开源项目里新人的第一个 PR 多久能被合并”），
  按课程顺序走一遍：提问题 → 找文献 → 选方法 → 收数据 → 分析 → 写报告。
- **每读一篇论文，都问一遍官方那几个问题。** 研究设计能不能支撑结论？分析方法对不对？有没有效度威胁？这就是这门课想练的眼光。

## 同类课怎么选

- 这门课在本站软件工程分类里比较特别：它不教你怎么写软件，而是教你怎么**研究**软件工程（以及更广的计算机问题）。
  想学怎么写好软件，看 [MIT 6.102](/docs/software-engineering/mit-6-031) 和 [UC Berkeley CS169A](/docs/software-engineering/cs169)。
- 回归和统计推断想打得更扎实，可以先学 [Data100](/docs/data-science/ucb-data100) 的建模和推断部分。
