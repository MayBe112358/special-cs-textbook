## 课程简介

CS169 讲的是怎么以团队方式开发和维护一个真实的软件产品，
而不是怎么写一个算法。

课程按软件工程的实践组织：敏捷开发方法（Scrum、用户故事、迭代）、
版本控制与协作流程、行为驱动开发（BDD）与测试驱动开发（TDD）、
重构与遗留代码的处理、设计模式、
Web 应用的架构（课程用 Ruby on Rails）、
持续集成与云端部署，以及项目管理与团队协作。

它的特点是把"过程"本身当成教学内容：
大多数课程只关心代码写得对不对，这门课还关心
需求怎么来、改动怎么验证、团队怎么不互相踩脚。

配套教材《Engineering Software as a Service》由课程团队编写。

## 先修要求

- 需要编程基础与数据结构知识。
- 不要求预先了解 Ruby 或 Web 开发。
