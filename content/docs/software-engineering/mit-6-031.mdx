## 课程简介

6.031 关心一个具体的问题：怎么写出别人敢用、以后敢改的代码。

课程围绕三个目标组织——safe from bugs（不出错）、
easy to understand（读得懂）、ready for change（改得动），
每一讲都在回答“这个技术怎么服务这三个目标”。

内容包括：静态类型与不可变性、规约（specification）的写法、
测试与测试用例设计、抽象数据类型与表示不变量、
接口与子类型、递归与递归数据类型、
调试、并发与线程安全、以及设计模式。

它最有价值的地方是把“写规约”当成一项可以训练的技能来教：
一个方法的前置条件、后置条件是什么，
哪些情况是未定义的——这些问题在大多数课程里被含糊带过。

课程材料（阅读、课堂练习、作业）全部公开。

## 先修要求

- 需要掌握至少一门编程语言，课程使用 Java 与 TypeScript。
- 需要基本的数据结构知识。
