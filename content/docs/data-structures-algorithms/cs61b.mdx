## 课程简介

CS61B（Data Structures）是伯克利 CS61 系列的第二门，接在 [CS61A](/docs/programming-intro/cs61a) 后面。
官方的说法是：61A 教你用函数、对象、规则去组织程序；61B 往下走一层，关心两种效率——
写程序的效率（设计）和跑程序的效率（时间和空间）。课程语言是 Java。

内容上，前三分之一在补工程能力：Java 的类与引用、链表和数组的实现、测试、Git、接口与继承、迭代器；
然后是渐近分析和一连串经典数据结构：并查集、二叉搜索树、B 树、红黑树、堆、哈希表、字典树；
再往后是图（遍历、最短路、最小生成树、有向无环图）和排序（快排、排序的下界、基数排序），
最后讲压缩，以及“软件工程”三讲，其中一讲专门讲 AI 在软件工程里的角色。

它的作业量很大，而且都要自己实现，不能调库。两个大项目最有名：
用 Google Ngram 数据和 WordNet 词库做一个查询词频和上下位词的网页工具；
以及 BYOW（Build Your Own World），用随机种子生成带房间和走廊的地牢地图，再做成能玩、能存档的小游戏。

## 先修要求

- 官方写的是：上过 CS61A、CS88 或 E7，或有同等基础。课程默认你学过 61A，E7 出身的同学前两周在面向对象上会吃力一些。
- **不需要会 Java。** 官方说一半以上的学生之前没见过 Java，但语法会讲得很快。
  会 Python 的话，第一周把“静态类型”和“类”这两件事弄懂就能跟上。

## 课程结构

2026 年秋季每周三讲，日程上每讲都对应一章[在线教材](https://cs61b-2.gitbook.io/cs61b-textbook-fall-2026/1.-introduction)：

| 阶段 | 讲什么 |
|---|---|
| Java 与链表数组 | Java 入门、类、引用与递归、单链表与哨兵节点、双链表、可变长数组 |
| 测试与继承 | 测试、接口与实现继承、迭代器与 equals、多态、Comparable 与 Comparator |
| 渐近分析与并查集 | 渐近分析三讲、并查集 |
| 树 | 集合与二叉搜索树、B 树、红黑树、堆与优先队列 |
| 图 | 树和图的遍历、图的实现、最短路、最小生成树、有向无环图 |
| 哈希与字典树 | 哈希两讲、字典树 |
| 排序 | 基础排序、插入排序、快速排序、排序的下界、基数排序 |
| 软件工程与收尾 | 软件工程三讲（第三讲讲 AI）、计算的社会影响、压缩 |

考试有三次：小期中（70 分钟）、期中（120 分钟）、期末（170 分钟），而且是**纸上手写代码**。

## 官方作业

2026 年秋季的作业分四类，都在 [课程主页](https://fa26.datastructur.es/) 的日程表里按周发布：

- **Homework（HW1～HW8）**：HW1 配环境，HW2 Java 入门，HW3 IntList（递归链表），
  HW4 渐近分析（理论题），HW5 BSTMap（自己写一个二叉搜索树映射），HW7 HashMap，HW6 和 HW8 是考前复习。
  八份里做满六份就是满分。
- **Lab（约 14 次）**：调试、链表、Git、Comparable、并查集、渐近分析、BST 和左倾红黑树、图、最短路、哈希、排序等，
  基本每个数据结构都有一次亲手实现。最后一次叫 Agentic Development，讲怎么和 AI 编程代理合作。
- **小项目（Project 0～3）**：粒子模拟器、双端队列（先写测试再实现链表版）、ArrayDeque（环形数组版），
  完全可选的 Sound Synthesis（没有评分，用你写的 ArrayDeque 模拟吉他弦振动来合成声音），以及用并查集模拟渗流（Percolation）。
- **设计项目（Project 4、5）**：Project 4 分四步：TimeSeries 和 NGramMap、WordNet 设计、WordNet 查询两步；
  Project 5 是 BYOW，分设计、世界生成、交互三步。这两个项目要先交设计文档，一般两人一组。

**校外自学怎么交作业**：当前学期的 Gradescope 不对外开放。官方为旁听者开了 **2021 春季**的公开自动评分：
在 Gradescope 上点“Add a course”，输入课程码 `MB7ZPY`，然后用 [2021 春季网站](https://sp21.datastructur.es/)
上的讲座、题目和骨架代码。官方特别提醒：要用就全部用 2021 春季的版本，不要和当前学期混着用；旁听者没有助教答疑。
2021 春季的项目是 2048 游戏、双端队列加吉他合成器、Gitlet（自己实现一个迷你版 Git）和 BYOW。

## 学习建议

- **选定一个学期跟到底。** 想要自动评分，就跟 2021 春季；想要最新的内容（比如 AI 那一讲和最后的 Lab），
  就跟 2026 秋季，作业自己写测试来检查。两边混着做，骨架代码对不上，会浪费很多时间。
- **注意课程的 AI 政策。** 在校生禁止让任何 AI 工具读自己的代码仓库，只能在浏览器里问概念问题；
  官方的理由是，亲手写每一行代码是训练拆解问题、管理复杂度的最好方式。自学时不受约束，
  但建议照着这个规矩来——这门课练的就是“自己写出来”这件事。
- **先写测试。** Project 1 的第一步就是先写测试再写实现。养成这个习惯，后面几个大项目会省很多调试时间。
- **Gitlet（2021 春季）或 BYOW 一定要做完。** 它们是第一次写几千行、要自己设计类和数据结构的程序，
  也是这门课最能练人的地方。动手前先写设计文档，官方的 [设计文档指南](https://fa26.datastructur.es/resources/design-doc-guide/) 值得一读。
- **手写代码练起来。** 考试是纸笔写代码，平时做讨论课题目时不开 IDE 写一遍。

## 同类课怎么选

- **[Princeton Algorithms](/docs/data-structures-algorithms/princeton-algorithms)**：同样用 Java，内容高度重合（连渗流作业都一样）。
  它的代码实现更讲究，作业有公开的自动评分；CS61B 的工程训练（Git、测试、设计文档、大项目）更多。
- **[Stanford CS106B](/docs/programming-intro/cs106b-cs106x)**：斯坦福的对应课，用 C++。
- **[MIT 6.006](/docs/data-structures-algorithms/mit-6-006)**：偏算法分析和证明，代码写得少。
- 学完 CS61B 和 [CS70](/docs/advanced-mathematics/cs70)，下一步就是 [CS170](/docs/data-structures-algorithms/cs170)（算法设计与分析）。
