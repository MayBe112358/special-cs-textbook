## 课程简介

6.006 是 MIT 的算法入门课，用 Python 授课。
它的组织方式是先立框架再填内容：一开始就讲清楚计算模型和渐近复杂度怎么算，
之后每引入一种技术，都回到“它把什么问题从多慢变成了多快”这个问题上。

内容覆盖排序与查找、二叉搜索树与平衡树、哈希、堆、
图的遍历与最短路（BFS、DFS、Dijkstra、Bellman-Ford）、
动态规划，最后是数值算法与复杂度类的简介。

Erik Demaine 的讲课风格很有辨识度，讲座视频、讲义、
recitation 笔记和习题在 OCW 上都有。
课程还提供了一份 Python Cost Model，说明各种 Python 操作的实际代价——
这是很多算法课会忽略但实际写代码时很要紧的细节。

## 先修要求

- 需要编程入门基础（官方按 CS50/CS61A 一类课程设定）。
- 需要离散数学基础，尤其是证明与求和的处理。
