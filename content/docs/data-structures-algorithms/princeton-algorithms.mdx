## 课程简介

这是普林斯顿 Robert Sedgewick 和 Kevin Wayne 的算法课，配套教材是他们的《Algorithms, 4th Edition》。
课程在 Coursera 上分两部分，**所有功能免费**（按普林斯顿的规定不发证书）。

它和偏理论的算法课是两条路子：书里每个算法都有一份完整、可运行、写得很讲究的 Java 实现，
配上真实数据的实验，告诉你它在实际输入上跑得多快。教材的第 1 章就专门讲怎么用科学实验的方法预测程序的运行时间。

- **Part I**：并查集、算法分析、栈与队列、初级排序、归并排序、快速排序、优先队列、符号表、平衡搜索树、
  二叉搜索树的几何应用、哈希表。
- **Part II**：无向图、有向图、最小生成树、最短路、最大流与最小割、基数排序、字典树、子串查找、正则表达式、
  数据压缩、归约、难解性。

每部分约 5～6 周，官方估计每周 10 小时。

## 先修要求

- 需要会一点 Java。编程作业只能用 Java 提交；讲师说书里的代码主要是为了讲清楚思路，换成别的语言也能读懂。
  如果你学过 Python 但没学过 Java，先花一周熟悉 Java 的类和接口就够了。
- 数学上只需要高中水平：求和、对数、一点概率。

教材的六章和课程的对应关系：

| 教材 | 内容 | 课程 |
|---|---|---|

## 官方作业

十个编程作业，题面、常见问题（FAQ）和项目骨架都在 [作业页](https://coursera.cs.princeton.edu/algs4/assignments/) 公开，
提交和自动评分在 Coursera 上（免费）。自动评分不只看结果对不对，还会用 Checkstyle 等工具检查代码风格和常见 bug（评分环境是 OpenJDK 11）。

**Part I：**

1. [Percolation](https://coursera.cs.princeton.edu/algs4/assignments/percolation/specification.php)：用并查集和蒙特卡洛模拟估计“渗流阈值”。
2. [Deques and Randomized Queues](https://coursera.cs.princeton.edu/algs4/assignments/queues/specification.php)：自己实现双端队列和随机队列，要求每个操作的时间和内存都达标。
3. [Collinear Points](https://coursera.cs.princeton.edu/algs4/assignments/collinear/specification.php)：在平面点集里找出所有四点及以上共线的线段，用排序把暴力解法加速。
4. [8 Puzzle](https://coursera.cs.princeton.edu/algs4/assignments/8puzzle/specification.php)：用 A* 搜索和优先队列解八数码问题。
5. [Kd-Trees](https://coursera.cs.princeton.edu/algs4/assignments/kdtree/specification.php)：用二维树做范围查询和最近邻查询。

**Part II：**

1. [WordNet](https://coursera.cs.princeton.edu/algs4/assignments/wordnet/specification.php)：在 WordNet 词库构成的有向图里算两个词的“最近公共祖先”。
2. [Seam Carving](https://coursera.cs.princeton.edu/algs4/assignments/seam/specification.php)：按内容缩放图片，每次删掉“最不重要”的一条像素路径，本质是有向无环图上的最短路。
3. [Baseball Elimination](https://coursera.cs.princeton.edu/algs4/assignments/baseball/specification.php)：用最大流判断一支球队是否已经在数学上被淘汰。
4. [Boggle](https://coursera.cs.princeton.edu/algs4/assignments/boggle/specification.php)：用字典树在字母方阵里找出所有单词。
5. [Burrows–Wheeler](https://coursera.cs.princeton.edu/algs4/assignments/burrows/specification.php)：实现 Burrows–Wheeler 压缩算法，官方说它压得比 gzip 和 PKZIP 还小。

此外 Coursera 上每周还有不计分的面试题和练习。

## 学习建议

- **每个作业先读 FAQ。** 作业页每个作业都有一份 FAQ，常见的坑（比如 Percolation 里的“回流”问题）都写在里面。
- **看自动评分的完整报告。** 它会列出每个没通过的测试和风格问题。按报告一点点改到满分，是这门课最有价值的训练。
- **把书上的实现当范本读。** 教材网站的 [代码库](https://algs4.cs.princeton.edu/code/) 里有全部算法的 Java 实现，
  写法都经过反复打磨，读它们能学到怎么写干净的代码。
- **先做出能过的版本，再优化。** 很多作业（比如 Percolation 的“回流”问题）FAQ 里明说第一版可以不处理，先把主体写对。

## 同类课怎么选

- **[UC Berkeley CS61B](/docs/data-structures-algorithms/cs61b)**：同样用 Java，内容高度重合（它也有渗流作业）。
  CS61B 的工程训练（Git、测试、设计文档、大项目）更多；这门课的算法覆盖更全（字符串、最大流），自动评分对校外完全开放。
- **[MIT 6.006](/docs/data-structures-algorithms/mit-6-006)**：偏分析和证明，代码写得少。两门搭配学效果最好：一门练实现，一门练分析。
- 学完之后想深入算法设计与证明，接 [CS170](/docs/data-structures-algorithms/cs170) 或 [MIT 6.046J](/docs/data-structures-algorithms/mit-6-046j)。
