## 课程简介

CS346 Database System Implementation 是斯坦福的数据库实现课，这里收的是公开存档的 **2015 年春季**版，由 **Chris Ré** 讲授。

官方的课程描述是：用一个大型的数据库实现项目，把前面课程里学到的原理和技术落地——**每个学生独立**搭一个完整的数据库管理系统，
从文件结构一直做到查询处理，最后再加上自己设计的功能或扩展。讲课一部分讲项目的细节，一部分讲数据库实现的高级技术（重点是查询处理与优化），
还请了业界的工程师来讲商业数据库的实现。

项目叫 **RedBase**，结构非常清晰：整个数据库被切成几层，每层有明确的接口约定，上一层只依赖下一层——
做完之后，你会清楚地看到一个数据库的每一层各管什么。

## 先修要求

官方的要求：

- **斯坦福 CS145（数据库入门）和 CS245（数据库系统原理）或同等知识是必需的**，课程默认你已经懂基本的数据库实现技术；
- 要有 Unix 和 C 语言的经验，最好也会 C++；官方说没有 C 和 Unix 经验的同学大概不适合上这门课，不会 C++ 的要快速学起来。

## 课程结构

2015 年春季约十周：

| 周 | 讲什么 |
|---|---|
| 1 | 课程与数据库回顾、RedBase 概览；文件与缓冲区回顾，分页文件（PF）与记录管理（RM）组件 |
| 2 | 缓冲区管理；页面布局与记录文件 |
| 3 | RedBase 索引组件，B+ 树回顾；索引中的并发，B-link 树 |
| 4 | 系统管理与查询语言组件，元数据与查询处理回顾；查询处理（代价模型） |
| 5 | 恢复（ARIES）；客座：Oracle |
| 6 | 客座：Pivotal；数据库分析（DeepDive、Hogwild!） |
| 7～9 | 客座：Databricks、Hadoop 联合创始人 Mike Cafarella、SAP、Twitter、LogicBlox |
| 10 | 不上课，专心做项目，最后演示个人扩展 |

没有指定教材，推荐一本综合性的数据库教材作参考，比如《Database Systems: The Complete Book》。

评分：项目占 90%（前三部分各 15%、第四部分 20%，其余是个人扩展），课堂参与 10%。

## 官方作业

**RedBase 项目**（C++，个人独立完成）：

| 部分 | 内容 |
|---|---|
| Part 0：PF 分页文件 | 课程直接提供，负责把文件按页读写并做缓冲 |
| Part 1：RM 记录管理 | 在页上存放和管理记录（元组）与空闲空间 |
| Part 2：IX 索引 | 实现 B+ 树索引 |
| Part 3：SM 系统管理 | 处理 DDL 语句、命令行工具、数据装载与元数据（系统目录） |
| Part 4：QL 查询语言 | 实现查询的执行：选择、投影、连接、插入、删除、更新 |
| Part 5：EX 个人扩展 | 自己设计一个扩展，先交提案，期末演示 |

每个组件都有一份详细的规格说明，定义了要实现的类和接口，官网上完整公开。
**但起始代码（PF 层）、测试程序和数据都放在斯坦福的校内机器上**（/usr/class/cs346），校外拿不到，自学要照着规格说明自己搭。

## 学习建议

- **把规格说明当“接口设计”范本读。** RedBase 最大的价值是它的分层设计：每一层暴露什么接口、隐藏什么细节，读懂了对设计任何系统都有帮助。
- **自己动手要先补上 PF 层。** 没有官方代码，就先自己写一个简单的分页文件和缓冲池，再往上搭 RM、IX。
- **B-link 树那一讲值得看。** 讲的是怎样让 B+ 树支持高并发访问，配套的论文是经典。
- **材料比较老。** 2015 年的课，客座讲座反映的是当时的业界，核心的实现技术并不过时。
