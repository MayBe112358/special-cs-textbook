## 课程简介

CS346 的核心是 RedBase——一个高度结构化的教学数据库项目。
整个项目被切成四个部分，也正好是四个实验：

记录管理组件负责把元组存到页里并管理空闲空间；
索引组件实现 B+ 树；系统管理组件处理 DDL 语句、
命令行工具、数据装载与元数据管理；查询处理组件实现选择、投影、连接等操作。

这种分层切分让你能清楚看到一个数据库的各层职责，
每一层都有明确的接口约定，上一层依赖下一层。
项目用 C++ 完成，做完之后你手上会有一个虽然简单但功能完整的数据库系统。

## 先修要求

- 需要 C++ 编程能力与数据结构基础。
- 官方未设硬性先修，但了解 SQL 与关系模型会更顺。
