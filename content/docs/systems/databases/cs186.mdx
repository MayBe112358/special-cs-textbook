## 课程简介

CS186 从一串很具体的问题开始：一条 SQL 查询是怎么被拆解、优化、
变成一个个磁盘操作的？怎么让很多人同时读写还不出错？数据库崩了怎么恢复？

课程依次讲 SQL 与关系模型、磁盘与缓冲区管理、B+ 树索引、
排序与哈希、连接算法、查询优化与代价估计、
并发控制（两阶段锁、死锁处理）、日志与恢复（ARIES），
最后是分布式事务与 NoSQL。

项目用 Java 完成，你会实现一个支持 SQL 查询、B+ 树索引、
并发控制和故障恢复的关系型数据库。
和 CMU 15-445 相比，这门课的 SQL 与关系理论部分讲得更多，
项目语言是 Java 而不是 C++。
