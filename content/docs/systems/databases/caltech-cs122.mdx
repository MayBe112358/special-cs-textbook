## 课程简介

CS122 和大多数数据库实现课的分工不同：它把重点放在 SQL 层。
课程实验基于教学数据库 NanoDB（Java 编写），你要动的是查询处理的上半部分——
SQL 解析、逻辑计划生成、查询优化器的各个模块、连接算法的选择、
统计信息与代价估计、子查询的处理、聚合与分组的实现。

除此之外还有 B+ 树索引和 WAL 日志相关的实验。

这门课很适合接在 CMU 15-445 之后：那门课让你实现了存储与执行引擎，
这门课补上查询优化这一块。课程提供了 NanoDB 的完整代码库和 Javadoc，
实验说明写得很细。

## 先修要求

- 需要 Java 编程能力与数据结构基础。
- 建议先学过一门数据库入门课程。
