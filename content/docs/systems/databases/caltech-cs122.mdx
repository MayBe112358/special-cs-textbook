## 课程简介

CS122 Relational Database System Implementation 是加州理工学院的数据库实现课，由 **Donnie Pinkston** 讲授。这里收的是公开存档的 **2019 年冬季**版。

课程的主线是**怎样实现一个关系数据库**：从存储层次和磁盘访问讲起，到记录格式与文件组织、查询求值流水线、SQL 翻译成关系代数、各种计划节点的实现、
代价估计与查询优化，再到索引、事务和恢复。

项目全部在 **NanoDB** 上做——一个用 Java 写的教学数据库，官方的原则是“在性能和清晰之间，NanoDB 一般选清晰”，目标是好懂、好扩展。
和别的数据库实现课相比，它在 **SQL 翻译（包括子查询和去相关）和查询优化器**上花的篇幅特别多。

课程还有一个次要目标是**软件工程实践**：用 Maven 构建、Javadoc 写文档、TestNG 写自动化测试、Git 管理版本，代码质量和提交记录都算分。
官方说课上没有期中也没有期末，成绩主要看作业（另有少量阅读和习题）。

## 先修要求

第一讲的先修清单：

- 熟悉 SQL（DDL 和 DML）、关系模型和关系代数（加州理工的 CS121 讲这些，官方会给出 CS121 的幻灯片）；
- 算法与数据结构（排序、查找、树、图）以及时间和空间复杂度；
- 所有编程都用 Java。

## 课程结构

2019 年冬季共 23 讲：

| 部分 | 讲什么 |
|---|---|
| 存储 | 数据库架构与组成；存储层次；磁盘与 SSD 的访问特性；块级与记录级访问；记录格式（null 位图、槽页结构）；堆文件、顺序文件与哈希文件组织 |
| 查询求值 | 查询求值流水线；计划节点、物化求值与流水线求值；SQL 翻译成关系代数（选择、投影、分组聚合、连接语法） |
| 子查询 | SELECT、FROM、WHERE 子句中的嵌套子查询；半连接与反连接；去相关 |
| 算子实现 | 基于哈希和排序的分组聚合；外部排序；嵌套循环连接；哈希连接 |
| 代价与优化 | 表统计与代价估计；选择谓词的选择率；连接代价；启发式优化与基于代价的优化；计划枚举 |
| 索引 | B+ 树的插入与删除；动态哈希（可扩展哈希、线性哈希）；索引扫描的代价；位图索引 |
| 事务与恢复 | ACID；可串行化调度；影子分页；预写日志；force/steal 策略；检查点；ARIES 恢复算法 |
| 隔离 | 脏读、不可重复读、幻读等现象；SQL 隔离级别与快照隔离 |

每讲的幻灯片（PDF）和录像（MP4）都能在课程网站上下载，2018 年的讲课也保留着。

## 官方作业

**七个作业**（2～3 人一组，在 NanoDB 上做）：

| 作业 | 内容 |
|---|---|
| 1 环境与存储层 | 支持元组的更新和删除；正确地 pin/unpin 页面和元组；提高堆文件的插入性能 |
| 2 SQL 翻译与连接 | 把 SQL 翻译成查询计划，实现连接 |
| 3 表统计与计划代价 | 收集表统计信息，估计计划的代价 |
| 4 连接优化 | 用动态规划选出最优的连接顺序，要支持外连接 |
| 5 高级子查询 | 支持更复杂的子查询 |
| 6 B+ 树索引 | 实现 B+ 树索引 |
| 7 预写日志 | 实现预写日志与恢复 |

另有两个挑战题：导入 TPC-H 数据集，并跑通 TPC-H 的查询。每个作业还要交一份设计文档。

**注意**：作业说明、NanoDB 的文档和 Javadoc 都公开，但 **NanoDB 的起始代码是按队伍分发的私有仓库，官方没有公开发布**，
校外很难照原样做。GitHub 上能搜到一些往届学生的仓库，不是官方材料，也不建议照抄。

## 学习建议

- **把它当成“查询处理与优化”的专题课。** 录像和幻灯片公开，SQL 翻译、子查询去相关、代价估计、连接顺序优化这几部分讲得格外细，别的课很少这么讲。
- **作业说明当设计题读。** 即使拿不到代码，每份作业说明都详细描述了要实现的算法和 NanoDB 的相关类，照着想一遍怎么设计也很有收获。
- **想完整做一遍项目，配 CMU 15-445 或 CS186。** 它们的项目代码公开，校外能完整做完。
