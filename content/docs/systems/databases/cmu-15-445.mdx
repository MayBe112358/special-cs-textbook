## 课程简介

15-445/645 Intro to Database Systems 是卡内基梅隆大学的数据库系统课，出自 **Andy Pavlo** 的 CMU 数据库组，
2025 年秋季由 Andy Pavlo 讲，2026 年秋季由 Jignesh Patel 讲。官网自称“**卡内基梅隆最好的数据库课**”。

课程讲的是**数据库管理系统的设计与实现**：数据模型（关系、文档、键值）、存储模型（行存、列存）、查询语言、存储架构（堆文件、日志结构）、
索引与过滤器（树、哈希表、向量索引）、事务处理（ACID、并发控制）、恢复（日志、检查点）、查询处理（连接、排序、聚合、优化），
以及并行架构（多核、分布式），并用开源和商业数据库的案例来说明各种技术的取舍。官方的说法是：这门课适合“准备好过上以数据库为中心的生活、想秀一秀系统编程能力”的学生。

它最有名的是**项目**：全部在 CMU 自己的教学数据库 **BusTub**（C++20）上做，一个项目接一个项目地实现一个磁盘数据库的核心组件。

## 先修要求

- 官方先修：**CMU 15-213**（本站的 [CSAPP](/docs/systems/systems-fundamentals/cmu-15-213-csapp)）。
- **C++**：必须熟练地用 C++ 编程和调试。官方明说学期中不会教 C++，开学的 Project 0 就是 C++ 水平测试，没在截止日前拿满分的会被要求退课。
- 数据结构与算法的基础。

## 课程结构

2025 年秋季（录像公开的一期）共 25 讲，括号里是教材章节：

| 部分 | 讲什么 |
|---|---|
| 关系模型与 SQL | 关系模型与关系代数；现代 SQL（第 1～5 章） |
| 存储 | 数据库存储（两讲）；内存管理与缓冲池；存储模型与压缩（第 11～13 章） |
| 索引 | 哈希表；索引与过滤器（两讲，B+ 树等）；索引的并发控制（第 14 章） |
| 查询处理 | 排序与聚合算法；连接算法；查询执行（两讲）；查询规划与优化（两讲）（第 15～16、22 章） |
| 事务 | 并发控制理论；两阶段锁；时间戳排序；多版本并发控制 MVCC（第 18 章） |
| 恢复 | 数据库日志；数据库恢复（第 19 章） |
| 分布式 | 分布式数据库（两讲）；期末复习与系统杂谈 |

很多讲的开头有数据库公司（dbt Labs、SingleStore、YugabyteDB、MotherDuck、ClickHouse 等）的工程师做的短讲。
教材是《Database System Concepts》（第 7 版，中译《数据库系统概念》）。

评分（2026 年秋季）：作业 15%、项目 40%、期中 20%、期末 25%。

## 官方作业

**项目**（C++，在 BusTub 上，一个接一个，后面依赖前面）：

| 项目 | 内容 |
|---|---|
| Project 0：C++ Primer | C++ 水平测试 |
| Project 1：Buffer Pool Manager | 自适应替换缓存（ARC）页面置换策略、磁盘调度器、缓冲池管理器（要支持并发） |
| Project 2：Database Index | B+ 树：页面结构、插入删除与点查、索引迭代器、并发控制 |
| Project 3：Query Execution | 查询执行（2026-09 核对时还没发布） |
| Project 4：Concurrency Control | 并发控制（同上） |

**作业**：SQL；存储；索引与过滤器；执行与规划；事务；恢复。作业的题目和答案 PDF 随学期陆续在网站上公开。

**校外也能做**：BusTub 的代码公开在 GitHub 上。官方为非 CMU 学生开了一个 Gradescope 课程（入口码写在官网 FAQ 里），
每个项目在 CMU 学生截止之后，自动评分器会对校外开放。作为交换，官方请大家**不要把自己的实现公开到 GitHub 上**。
校外学生可以去官方列出的 Discord 频道讨论（不是官方运营的）。

**AI 政策（2026 年秋季）**：P1、P2 禁止使用编程智能体；P3、P4 允许，但 P4 要交一页反思报告。项目成绩里还有两次课堂上的“调试与推理检查”：
给你一段 50～200 行、藏着细微 bug 的代码，要找出来、解释清楚、给出修法。官方强调“代码所有权”——不管是不是 AI 生成的，交上去的每行代码你都得能解释、辩护和修改。

## 学习建议

- **先过 Project 0。** 它就是一次 C++ 体检，做得吃力就先补 C++（本站 [CS106L](/docs/programming-intro/cs106l)）。
- **看 2025 年秋季的录像。** 官方明确说 2026 年的录像只对 CMU 学生开放，校外看 2025 年秋季的 YouTube 录像。
- **项目早开工。** 项目环环相扣，缓冲池写不对，后面的索引和执行器都会跟着出问题；多写测试，官方不公开评分用的测试。前两个项目都有可选的性能排行榜。
- **把作业当期中期末的练习。** 作业题和答案公开，覆盖每一部分的核心概念。
