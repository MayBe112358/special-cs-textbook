## 课程简介

这是南京大学软件学院 **魏恒峰** 老师的《编译原理》（本科必修课），课件、习题、录像和实验文档都逐年公开，这里以 2024 年春季为准。

实验的主线是用 **Java** 为 **SysY**（全国大学生编译系统设计赛用的 C 语言子集）写一个编译器。它的一个明确取舍是：
**用成熟的解析器生成工具 ANTLR 4 来做词法和语法分析**，把精力留给编译器更核心的部分——类型检查、中间代码生成和目标代码生成。
中间代码用的是 **LLVM IR**（通过 LLVM 的 Java 接口生成），最后再自己生成 RISC-V 汇编并做寄存器分配。

ANTLR 生成的解析器可读性好，配合监听器和访问者模式遍历语法树，是这门课实验的基本套路。

## 先修要求

官方列的“课前准备”：

- C 程序设计语言；**Java** 程序设计语言（实验用 Java）；
- 离散数学（证明策略、集合与关系）；
- 数据结构与算法（栈、树、深度优先搜索、基本的图算法、贪心算法）；
- 软件工程里的**监听器/观察者模式和访问者模式**。

## 课程结构

2024 年春季的书面作业大致对应理论课的进度：

| 部分 | 讲什么 |
|---|---|
| 概述 | 编译器的结构 |
| 词法分析 | 词法分析；正则表达式与自动机 |
| 语法分析 | 上下文无关文法；LL 分析 |
| 语义分析 | 属性文法 |
| 中间代码 | 中间表示 |
| 目标代码 | RISC-V 代码生成 |

教材是“龙书”《编译原理》（可以用国内出版的本科教学版），推荐阅读《ANTLR 4 权威指南》《自制编译器》《LLVM Cookbook》。

## 官方作业

**实验**（ANTLR 4 + Java，JDK 11，推荐在 Ubuntu 20.04 上做，每个实验在 Git 的一个分支上）：

| 实验 | 内容 |
|---|---|
| Lab0 | 环境配置，了解提交和评测方式 |
| Lab1 词法分析 | 用 ANTLR 4 为 SysY 写词法分析器 |
| Lab2 语法分析 | 语法分析 |
| Lab3 类型检查 | 类型检查 |
| Lab4 中间代码 | 翻译成 LLVM IR |
| Lab5 函数与控制流 | 函数定义与调用；`if`、`while` 等流程控制 |
| Lab6 目标代码 | 生成 RISC-V 汇编并做寄存器分配（用 RARS 模拟器运行） |
| Lab7（选做） | 静态检查器 |
| Lab8（选做） | 数组 |

成绩按样例测试（约 70%）和部分实验的报告（约 30%）算。
**在线评测对校外开放**：校外学生可以在实验文档里填表申请 OJ 账号；截止之后也能提交到对应的 copy 版本继续评测。

**书面作业**：2024 年共八次（概述、词法、正则与自动机、上下文无关文法、LL 分析、属性文法、中间表示、RISC-V），题目在 GitHub 上，大多附有助教或老师写的**参考答案**（官方提醒答案不保证完全正确，要保持批判精神）。

## 学习建议

- **跟着 B 站录像学。** 魏老师把每年的课程录像按学年整理成合集放在 B 站，课件也在 GitHub 上按学年归档。
- **先把 ANTLR 的监听器和访问者用熟。** 后面的类型检查和代码生成都是在语法树上遍历，这两种模式是基本功。
- **书面作业配答案做。** 自动机构造、LL 分析表、属性文法这些题，做完对照参考答案检查。
- **Lab6 最有挑战。** 生成的汇编不要求和助教一致，只要能正确运行；但禁止用任何方式提前算出程序结果来“作弊”。
