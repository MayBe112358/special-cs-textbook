## 课程简介

这门课的一个明确取舍是：用 ANTLR v4 这个成熟的解析器生成工具来处理词法和语法分析，
把学生的精力留给编译器真正核心的部分——语义分析、中间代码生成与优化。

ANTLR 是 LL 解析器生成器，能处理的文法范围比 LR/LALR 窄一些，
但它生成的解析器可读性好，还有 IDE 插件能实时把语法树画出来，
这对理解分析过程很有帮助。

课程有十个书面作业和八到十个编程作业，
一路把一个编译器搭起来。课程文档站点组织得很清楚，
每个作业都有明确的目标与测试方式。

- 需要 Java 编程能力。
