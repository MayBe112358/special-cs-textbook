## 课程简介

这是中国科学技术大学的《编译原理和技术》，2023 年秋季由 **李诚** 老师主讲，课程主页、实验文档和实验框架都公开在 GitHub 上。

实验的主线是为 **Cminusf**（一种 C 语言子集，支持整数和浮点数）写一个从前端到后端的完整编译器：

1. 用 Flex 和 Bison 写词法、语法分析器；
2. 从语法树自动生成中间代码 **Light IR**——它是 LLVM IR 的一个子集，课程提供了配套的 C++ 库；
3. 把 Light IR 翻译成**龙芯（LoongArch）汇编**；
4. 再加上优化 pass（Mem2Reg 等），体验优化让代码变快。

配套教材是李诚、徐伟的《现代编译器设计与实现》（实验讲义版），教材站点公开了教材代码和六个实验的框架，还有一套 B 站上的编译器设计与实现慕课。

## 先修要求

官网没有单列先修。从实验内容看，你需要：

- 数据结构；
- 计算机系统基础：汇编、栈、调用约定（后端要写龙芯汇编）；
- **C++**：实验框架是 C++ 写的，Lab2 要理解访问者模式，课程有一份 C++ 介绍文档；
- Linux 和 Git：Lab0 专门讲环境配置、LLVM 等软件的安装和 Git 的使用。

## 课程结构

2023 年秋季的实验安排（理论课与实验同步推进）：

| 阶段 | 内容 |
|---|---|
| Lab0 | Linux 环境配置；LLVM 等软件环境；Git 的使用 |
| Lab1 词法语法解析 | 正则表达式、Flex、Bison；从无到有完成 Cminusf 的词法和语法分析器 |
| Lab2 中间代码生成 | 手写 Light IR、用 C++ 库生成 IR；访问者模式；从语法树自动生成 IR |
| Lab3 后端代码生成 | 把 Light IR 翻译成龙芯汇编：栈式分配、后端框架 |
| Lab4 Mem2Reg | 支配树分析，实现 Mem2Reg 优化 pass，对比优化前后的性能 |
| 创新实验（建木杯） | 1～3 人一组，用实验框架开发一个面向 SysY 语言的龙芯后端编译器，按测试通过情况、性能和答辩评分 |

课程还有公共文档：Cminusf 语法语义、Light IR 简介、日志工具的使用、龙芯汇编介绍。

教材：陈意云、张昱《编译原理》（第 3 版）；李诚、徐伟《现代编译器设计与实现》（实验讲义版）；参考书“龙书”《编译原理》（Aho 等）。

## 学习建议

- **Lab0 别跳。** 环境（Linux、LLVM 等软件）配不好，后面寸步难行。
- **先手写几段 Light IR。** Lab2 的预热部分让你手写 IR、再用 C++ 库生成同样的 IR，做完就知道自动生成要干什么。
- **访问者模式要吃透。** 整个 IR 生成都建立在对语法树的访问者遍历上。
- **Mem2Reg 是理解 SSA 的关键一步。** 支配树、支配边界、φ 函数在这里第一次落地，做完再去学寄存器分配等优化会顺很多。
- **想挑战就参加建木杯。** 它用的 SysY 语言和全国大学生编译系统设计赛一致，能把整个编译器从头到尾做一遍。
