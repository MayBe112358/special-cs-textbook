## 课程简介

CS143 是 Stanford 的编译原理课，也是这个方向流传最广的公开课之一。
课程设计了一门教学语言 COOL（Classroom Object-Oriented Language），
整门课的主线就是为它实现一个完整的编译器，
把 COOL 源程序编译成 MIPS 汇编并在 Spim 模拟器上成功运行。

理论部分基本按龙书的顺序：词法分析（正则与有限自动机）、
语法分析（上下文无关文法、LL 与 LR 分析）、语义分析与类型检查、
运行时环境与活动记录、代码生成、寄存器分配与代码优化。

实践部分相应地分成词法、语法、语义、代码生成四个编程作业，
外加五次书面作业。每个阶段都有官方测试用例，
做完最后一个阶段，你会有一个真正能用的编译器。

## 先修要求

- 需要计算机体系结构基础（要能读懂汇编）。
- 需要 C++ 或 Java 编程能力，以及基本的形式语言概念。
