## 课程简介

CS143 Compilers 是斯坦福的编译原理课，2026 年春季由 **Fredrik Kjolstad** 讲授。Alex Aiken 讲过的版本至今还作为免费的自学课放在 edX 上。

课程的主线是一个贯穿全学期的项目：为一门专门设计的教学语言 **Cool**（Classroom Object-Oriented Language）写一个**完整的编译器**。
Cool 虽小，却有类、继承、静态类型、垃圾回收这些真实语言的特性。你会依次写出词法分析器、语法分析器、语义分析器和代码生成器，
最后编译出的 MIPS 汇编能在 SPIM 模拟器上真正跑起来。

讲课覆盖编译器的全流程：词法分析、语法分析、语义分析与类型检查、运行时组织、代码生成，再到中间代码、优化、寄存器分配和自动内存管理。

## 先修要求

官网没有单列先修。实际上你需要：

- **C++**：作业的支持代码和你要写的代码都是 C++；
- 数据结构与算法（树、图、哈希表）；
- 计算机组成与汇编的基本概念，代码生成那部分要写 MIPS 汇编（本站的 [CS61C](/docs/systems/computer-architecture/cs61c) 或 [CSAPP](/docs/systems/systems-fundamentals/cmu-15-213-csapp)）。

## 课程结构

2026 年春季的讲义：

| 部分 | 讲什么 |
|---|---|
| 导论 | 课程概述；Cool 语言与课程项目 |
| 词法分析 | 词法分析；词法分析的实现（正则表达式、有限自动机） |
| 语法分析 | 语法分析导论；语法制导翻译；自顶向下分析；自底向上分析 |
| 语义分析 | 语义分析与类型检查（两讲） |
| 代码生成 | 运行时环境；代码生成；操作语义 |
| 优化 | 中间代码与局部优化；全局优化（数据流分析）；寄存器分配 |
| 运行时 | 自动内存管理（垃圾回收） |

没有指定教材，可选参考“龙书”《Compilers: Principles, Techniques, and Tools》（Aho、Lam、Sethi、Ullman）。

评分：四个编程作业 50%（前两个各 10%、后两个各 15%）、四次书面作业 10%、期中 15%、期末 25%。

## 官方作业

**编程作业**（C++，每个都建立在前一个之上）：

| 作业 | 内容 |
|---|---|
| PA1 词法分析 | 用 Flex 写 Cool 的词法分析器 |
| PA2 语法分析 | 用 Bison 写语法分析器，在语义动作里构建抽象语法树 |
| PA3 语义分析 | 实现 Cool 的静态语义：类型检查，拒绝错误程序，为代码生成收集信息 |
| PA4 代码生成 | 生成 MIPS 汇编，做完就是一个完整的 Cool 编译器 |
| PA5 优化（加分） | 在编译器里实现一些优化，完全选做 |

**书面作业**：四次，题目、LaTeX 模板和**答案**都在网站上。

**往年试题**：网站上有 2024～2026 年的期中、期末卷及答案。

**注意**：作业的起始代码要在斯坦福的 myth 机器上用课程脚本获取，校外拿不到。Cool 语言手册、支持代码导览、运行时说明和 SPIM 手册都公开。
想要讲课视频，可以看 **edX 上的自学版**（Alex Aiken 讲，免费），内容覆盖词法分析到运行时系统的完整流程。

## 学习建议

- **先读 Cool 手册。** 整个学期都在给这门语言写编译器，语法和类型规则要熟到能随手查。
- **PA3 最难。** 类型检查要处理继承、SELF_TYPE、方法分派，规则要一条条对照手册实现。
- **书面作业配答案做。** 自动机构造、LL/LR 分析表、数据流分析这些题，官方答案公开，适合检验理解。
- **往年试卷做一遍。** 三年的期中期末都附答案，覆盖了整门课的重点。

## 同类课怎么选

- **[北京大学 编译原理实践](/docs/systems/compilers/pku-compilers)**：中文课，从零把 SysY（C 的子集）编译到 RISC-V，文档和评测全公开，最适合自学动手。
- **[KAIST CS420](/docs/systems/compilers/kaist-cs420)**：用 Rust 在 KECC 框架上做 SSA 中间代码、优化和后端，偏现代编译器。
- **[南京大学 编译原理](/docs/systems/compilers/nju-compilers)**：中文课，用 ANTLR 辅助前端，重点放在编译器的设计上。
- 想从另一头接近编译器，可以看 [Nand2Tetris](/docs/systems/computer-architecture/nand2tetris) 的后半段，它也要写一个简单编译器。
