## 课程简介

这是北京大学《编译原理》课程的**实践部分**，助教团队（pku-minic）写了一份非常详细的**在线文档**，把整个实验讲得清清楚楚。

任务是：开发一个把 **SysY 语言**（一种精简的 C 语言子集）编译到 **RISC-V 汇编**的编译器。一步跨过去太大，所以分成两步：

1. 把 SysY 编译到 **Koopa IR**——课程专门设计的中间表示，形式上类似 LLVM IR，但简化了很多，只保留实践需要的部分；
2. 把 Koopa IR 生成 RISC-V 汇编。

课程为 Koopa IR 提供了配套的运行时库，你的编译器可以用它方便地解析、生成、修改、输出 Koopa IR。

这门实践课最大的特点是**自由度高**：它**不给框架代码**，编译器怎么设计、用 C、C++ 还是 Rust 写，全由你决定。
追求更高的同学甚至可以不用 Koopa IR，自己设计 IR、自己做优化——评测只看最后生成的汇编对不对、跑得快不快。

## 先修要求

- 编程：C、C++、Rust 三选一，要能写中等规模的程序；
- 文档的“前置知识”一节要求会用 Linux 命令行（重定向、管道、常用命令）和 Git；
- 编译原理理论课的基本概念（词法分析、语法分析），实践文档会结合着讲。

## 课程结构

在线文档把实验分成十个阶段，由易到难、增量地搭出一个真正的编译器：

| 阶段 | 内容 |
|---|---|
| Lv0 环境配置 | 配置 Docker；Koopa IR 和 RISC-V 简介；选择编程语言 |
| Lv1 `main` 函数 | 编译器的结构；词法与语法分析初见；解析 `main`；生成 IR |
| Lv2 目标代码生成 | 处理 Koopa IR，生成 RISC-V 汇编 |
| Lv3 表达式 | 一元、算术、比较和逻辑表达式 |
| Lv4 常量和变量 | 常量；变量和赋值 |
| Lv5 语句块和作用域 | 实现块作用域 |
| Lv6 `if` 语句 | `if/else`；短路求值 |
| Lv7 `while` 语句 | 循环；`break` 和 `continue` |
| Lv8 函数和全局变量 | 函数定义和调用；SysY 库函数；全局变量和常量 |
| Lv9 数组 | 一维、多维数组；数组参数 |
| Lv9+ 新的开始 | 寄存器分配；优化；SSA 形式；性能测试 |

附录里有 SysY 语言规范、运行时库、Koopa IR 规范与 C 接口、RISC-V 指令速查等参考资料。

## 官方作业

整个实验就是这一个编译器，按阶段推进，每个阶段都有测试：

- **本地测试**：课程提供了 Docker 镜像（`maxxing/compiler-dev`），里面装好了工具链和自动测试脚本 `autotest`，可以按阶段测试你的编译器
  （比如 `autotest -koopa -s lv1 /root/compiler` 测第一阶段生成的 Koopa IR）。
- **在线评测**：选课学生把代码放到评测平台自带的 GitLab 上提交，分三个入口：SysY 到 Koopa、SysY 到 RISC-V、性能测试（有排行榜）。账号只发给选课学生。
- **项目模板**：课程提供 Make、CMake、Cargo 三种项目模板，写好配置就能直接用。
- **示例编译器**：课程有一个 Rust 写的参考实现 kira-rs（前端用 lalrpop），供参考，官方明确要求遵守学术诚信、不要照抄。

校外自学完全可行：文档、模板、Docker 镜像和本地测试都公开，缺的只是在线评测的账号。

## 学习建议

- **严格按阶段走。** 文档的阶段划分很合理，每一阶段只加一点新东西，做完测试再往下。
- **先搭通整条链路。** Lv1、Lv2 只处理 `return 0`，但已经走完“解析—生成 IR—生成汇编”的全流程，之后每个阶段都是在这条链路上扩展。
- **用熟悉的语言写。** 文档对 C/C++ 和 Rust 都有指引；如果想顺便练 Rust，这是个很好的机会。
- **Lv9+ 量力而行。** 寄存器分配、SSA 和优化是进阶内容，前面做扎实了再挑战性能排行榜。
