## 课程简介

SE3355 Compilers 是上海交通大学软件学院的编译原理课，由 IPADS 实验室开设，2026 年秋季由 **吴明瑜** 老师讲授。

教材是 Andrew Appel 的《Modern Compiler Implementation in C》（“虎书”），课程网站提供中英文版的下载（仅供选课学生使用，官方要求不要传播）。
实验跟着虎书走：为书中的 **Tiger 语言**（一门带嵌套函数、记录和数组的小语言）写一个编译器，中间表示用 **LLVM IR**。

课程覆盖面很宽：除了词法、语法、语义分析和中间表示，还讲全局优化、指令选择、寄存器分配、**垃圾收集**，
以及函数式语言的实现、语言虚拟化，2026 年秋季还新增了 **AI 编译器**两讲。寄存器分配和垃圾收集在很多编译课里会被略过，这里都有专门的讲次。

## 先修要求

官网没有单列先修。从课程内容看需要：

- 计算机系统基础：汇编、栈帧、调用约定（后面讲静态链与栈帧、代码生成）；
- 数据结构与算法；
- **C++**：实验框架是 C++ 的；
- Git 和 Linux：实验通过课程的 GitLab 和 CI 提交，环境是 Docker 镜像。

## 课程结构

2026 年秋季共 28 讲：

| 部分 | 讲什么 |
|---|---|
| 词法分析 | 编译器是什么；正则表达式；正则表达式的实现（自动机） |
| 语法分析 | 语法分析导论；自顶向下分析；LR 分析导论；构造 LR 分析器生成器 |
| 语义分析 | 抽象语法树与名字解析；类型系统（两讲） |
| 中间表示与优化 | 中间表示（两讲）；全局优化（四讲） |
| 后端 | 指令选择；寄存器分配（两讲）；垃圾收集（两讲） |
| 专题 | 函数式语言（两讲）；语言虚拟化（两讲）；AI 编译器（两讲） |

期中期末各一次。

## 官方作业

2025 年秋季的实验（2026 年的会在学期中陆续发布），全部围绕 Tiger 编译器：

| 实验 | 内容 |
|---|---|
| Lab 1 | 热身 |
| Lab 2：Lexer | 词法分析 |
| Lab 3：Parser | 语法分析 |
| Lab 4：Type Checking | 类型检查 |
| Lab 5：Translate to LLVM | 先做 LLVM 101 热身，再分两部分把 Tiger 翻译成 LLVM IR |
| Lab 6：Code Generation（选做） | 代码生成 |
| Lab 7：Register Allocation（选做） | 寄存器分配 |

实验代码在课程自建的 GitLab 上分支发布，提交后跑 CI 检查；环境是官方提供的 Docker 镜像。GitLab 账号需要按课程文档注册，校外能否使用官网没有说明。

**历年试卷**：官网公开了 2016～2024 年大部分期中、期末卷，多数带答案，是复习的好材料。

## 学习建议

- **以虎书为主线。** 每个实验都对应虎书的一章，先读书再动手；书的中英文版都能在课程网站找到。
- **类型检查和翻译最花时间。** Tiger 的嵌套函数要处理静态链，翻译到 LLVM IR 时要想清楚栈帧和逃逸变量，这是整个实验最难的部分。
- **LLVM 101 别跳。** Lab 5 之前的热身会带你熟悉 LLVM IR 的写法和工具，后面翻译时省很多事。
- **刷历年试卷。** 八九年的卷子覆盖了自动机、LR 分析、数据流分析、寄存器分配等重点，大多附答案。
