## 课程简介

CS420 Compiler Design 是韩国科学技术院（KAIST）的编译器课，由 **Jeehoon Kang** 讲授，课程主页就是 GitHub 上的一个仓库。

课程的开场白说：**编译器架起了人和机器之间的桥梁**——人想轻松地表达复杂的想法，机器只懂少数几条能高效实现在硅片上的指令。
而随着人工智能、大数据带来的新需求和摩尔定律的终结，**新的编译器总要一次又一次地被写出来**，编译器工程师的需求一直很高。

这门课的目标是**通过亲手构建一个编译器来学会构建编译器**。你会在一个干净的教学编译器 **KECC**（KAIST Educational C Compiler，Rust 写的）的骨架上工作：

1. 把 C 程序翻译成基于 **SSA**（静态单赋值）的中间表示；
2. 在 IR 上做寄存器提升、SSA 构造、全局值编号、寄存器分配等优化；
3. 把 IR 翻译成 **RISC-V** 汇编。

语法分析只简单带过（KAIST 的形式语言课会讲），重点放在“从人友好的形式翻译到机器友好的形式”以及编译器优化上。
课程还会简单讨论编译器构造的新趋势（脚本语言的即时编译、自动发掘并行性），并学一点**编译器正确性的理论**——怎样证明 KECC 的变换和优化是对的。

选 SSA 作中间表示是这门课的一大亮点：LLVM、GCC 这些现代编译器内部都用 SSA，但很多教学编译器为了简单会绕开它。

## 先修要求

官方**强烈建议**先学过：

- 数学：命题与证明；
- 数据结构：链表、栈、队列；
- 系统编程或计算机组成：内存布局、栈与堆、汇编语言；
- 程序设计语言：λ 演算、解释器。

另外推荐了解计算机体系结构，以及有 **Rust** 编程经验（可以先学同一个研究组的 [KAIST CS220](/docs/programming-intro/kaist-cs220)）。官方说没有这些基础，这门课会学得很吃力。

## 课程结构

官网没有逐讲日程，主线按编译器的流水线走：

| 部分 | 讲什么 |
|---|---|
| 导论 | 编译器的作用；KECC 概览；（简要的）语法分析 |
| IR 生成 | 从 C 的抽象语法树生成基于 SSA 的 IR |
| 优化 | 控制流图简化；寄存器提升（mem2reg）与 SSA 构造；死代码消除；全局值编号（GVN）；寄存器分配 |
| 代码生成 | 把 IR 翻译成 RISC-V 汇编 |
| 理论与趋势 | 编译器正确性及其证明；脚本语言的运行时编译；为深度学习、高性能计算自动发掘并行性 |

教材就是课程幻灯片、KECC 的代码与文档，以及 LLVM 项目本身。

评分：作业 60%（在线自动评分，交了马上看到分数）、期末考试 40%（考编译器理论），另有课堂小测。

## 官方作业

所有作业都是在 KECC 里实现翻译和优化，每一步都有对应的测试（用 `cargo nextest` 跑）：

| 测试 | 对应要实现的部分 |
|---|---|
| `write_c` | 把解析出的 C 语法树重新输出成 C 代码 |
| `irgen` | 从 C 生成 IR |
| `simplify_cfg` | 控制流图简化 |
| `mem2reg` | 寄存器提升（把内存变量提升成 SSA 值） |
| `deadcode` | 死代码消除 |
| `gvn` | 全局值编号 |
| `asmgen` | 生成 RISC-V 汇编 |
| `end_to_end` | 从 IR 生成、优化到汇编生成的完整流水线 |

**KECC 的代码公开**在 `kaist-cp/kecc-public`，带用户手册和代码文档，还能解释执行 IR、把 IR 画成图，方便调试。
官方要求直接克隆、不要 fork 后公开推送；想用 Git 服务器管理就建私有仓库。在线评分系统只对 KAIST 学生开放，校外用本地测试就够了。

**AI 政策**：官方明确**允许**使用 ChatGPT 或其他大模型。

## 学习建议

- **先把 Rust 学到能读大项目的程度。** KECC 是一个不小的 Rust 代码库，所有权、枚举、模式匹配要熟。
- **用好 IR 可视化和解释器。** `--irviz` 能把 IR 画成图，`--irrun` 能直接解释执行 IR，优化写错时这两样最快能定位问题。
- **mem2reg 是理解 SSA 的关键。** 做完这一步，SSA 的 φ 函数和支配边界就不再是抽象概念。
- **有问题去 GitHub issue 里搜。** 官方要求所有问题都在仓库的 issue 里公开问，历届的问答都留着，很多坑前人已经踩过。
