## 课程简介

CS420 提供一个用 Rust 编写的编译器框架 KECC（KAIST Educational C Compiler），
你要在它的基础上补完几个核心部分：抽象语法树的打印、
SSA 形式的中间代码生成、中间代码优化（控制流图简化、全局值编号等），
以及目标代码生成。

选择 SSA 作为中间表示是这门课的一个亮点——
现代编译器（LLVM、GCC）内部都用 SSA，
但大多数教学编译器为了简单会绕开它。
在这里你会直接面对 SSA 的构造与优化。

课程属于 KAIST 的 Rust 课程系列（CS220 → CS420 / CS431），
共用同一套工程约定：代码框架在 GitHub 上，作业自带测试，
本地 `cargo test` 就能自测。
