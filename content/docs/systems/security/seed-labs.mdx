## 课程简介

SEED Labs 是雪城大学开发的一套安全教学实验，
由美国国家科学基金会资助，目前全球有上千家院校在使用。

它不是一门课，而是一个实验库：四十多个实验按主题分类，
包括软件安全（缓冲区溢出、格式化字符串、竞态、脏牛漏洞）、
网络安全（ARP 欺骗、TCP 攻击、DNS 攻击、防火墙、VPN）、
Web 安全（XSS、CSRF、SQL 注入）、密码学（加密、哈希、PKI、TLS），
以及区块链等新主题。

每个实验都有详细的实验手册，说明背景、步骤和思考题。
环境可以用官方提供的虚拟机或 Docker 快速搭好，
省掉了安全实验里最耗时的配置环节。

## 先修要求

- 没有硬性先修要求，不同实验的难度差别很大。
- 需要 C 语言与 Linux 基础；部分实验涉及汇编。
