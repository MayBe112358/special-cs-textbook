## 课程简介

6.1600 是 MIT 面向本科生的计算机安全基础课，组织得相当清晰，
按五个模块推进：

认证（authentication）——如何证明计算机世界里的“你”确实是你，
涉及口令、多因素、公钥认证。
传输安全（transport security）——数据在网络上怎么加密、
密钥怎么交换、TLS 为什么那样设计。
平台安全（platform security）——操作系统和硬件提供的隔离机制。
软件安全（software security）——代码层面的漏洞与防御。
最后是人与终端用户的安全——技术之外的那一半问题。

课程有六个难度适中的实验，用 Python 3 完成。
相比 6.858 的研究导向，这门课更适合作为系统安全的第一门课。

## 先修要求

- 需要离散数学、编程基础与计算机系统基础。
- 实验使用 Python 3。
