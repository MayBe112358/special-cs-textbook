## 课程简介

6.1600 Foundations of Computer Security 是 MIT 面向本科生的安全基础课，2026 年秋季由 **Srini Devadas** 讲授。

官方的定位是：一门**覆盖安全系统和密码学基础**的计算机安全课，着重讲设计安全系统的基本原则。
课程按五个层次组织：**认证、传输安全、平台安全、软件安全、人与终端用户的安全**。

和研究导向的 [6.858（6.566）](/docs/systems/security/mit-6-858) 相比，这门课密码学的比重更大、更成体系，适合作为安全方向的第一门课。

## 先修要求

官方先修（并提醒不要在没修完这些之前来上）：

- **6.1200（离散数学）**：集合、关系与逻辑、组合、证明、递归、数论、图论、概率；
- **6.1210（算法）**：基本算法经验，会用 Python 3 编程；
- **6.1800（计算机系统工程）**：计算机系统的基础知识。

Lab 0 会检查你对先修内容的掌握，所有人都必须交。

## 课程结构

2026 年秋季 23 讲：

| 部分 | 讲什么 |
|---|---|
| 认证 | 什么是安全；认证人；抗碰撞与文件认证；消息认证码；数字签名（哈希签名、RSA）；案例：公钥基础设施 |
| 传输安全 | 传输安全导论；认证加密；密钥交换与公钥加密；实际中的加密 |
| 平台安全 | 构建安全系统的架构；隔离；软件的可信性；CPU 计时攻击；案例：iOS 安全 |
| 软件安全 | 软件安全；权限分离；运行时防御 |
| 隐私 | 零知识证明；差分隐私；PAC 隐私 |

评分：三次小考各 20%（闭卷，可带逐次增加的小抄）、实验作业 40%。讲课录像放在 MIT 的 Panopto 上，需要登录。

## 官方作业

**六个实验**（Python 为主，代码放在各实验的 GitHub 仓库里，报告用 LaTeX 写）：

| 实验 | 内容 |
|---|---|
| Lab 0 | 口令破解 |
| Lab 1 | Merkle 树 |
| Lab 2 | 坏的随机数 |
| Lab 3 | 性能与侧信道 |
| Lab 4 | 隔离（先从“Python 为什么不提供隔离”入手） |
| Lab 5 | 模糊测试：用 fuzzing 找 bug，让代码更健壮 |

**往年试题**：课程网站上有历年的小考题，复习课的题目和答案也随日程公开。

**AI 政策**：实验里**可以**用 ChatGPT 等 AI 助手，但必须在提交的内容里说明用它做了什么；直接用了它的输出，要像引用其他资料一样加引号并注明出处。

## 学习建议

- **先把数论和概率补好。** RSA、数字签名、认证加密都建立在数论和概率上，这是这门课最容易卡住的地方。
- **实验按顺序做。** 口令破解和 Merkle 树对应前半段的认证部分，侧信道、隔离、模糊测试对应后半段的平台和软件安全。
- **做往年小考。** 题目风格很稳定，是检验对密码学构造理解的好办法。
- **接着学系统安全。** 学完可以接 [6.858（6.566）](/docs/systems/security/mit-6-858)，或者去 [pwn.college](/docs/systems/security/asu-cse365) 练实战。

## 同类课怎么选

- **[UC Berkeley CS161](/docs/systems/security/cs161)**：同样是本科安全入门，内存安全和 Web 安全讲得更多，有免费的在线教材。
