## 课程简介

CSE 466 Computer Systems Security 是亚利桑那州立大学的系统安全课，2026 年秋季由 **Michael Tompkins** 和 **Ozgur Ozmen** 讲授，整门课都在 **pwn.college** 上。

官方的课程描述是：这门课探讨计算机系统的安全**会以哪些方式失效**。安全只和最弱的一环一样强，一个小失误就能让原本非常安全的软件崩塌。
基于“要构建将来的安全系统，必须先懂安全怎么被打破”的想法，课程覆盖应用安全和操作系统安全里的多种失效方式。
每讲介绍一个新主题、讲真实世界里相关的安全事故，再配一个作业让你亲手探索。

## 先修要求

官方的话很直接：**这门课会极其有挑战性**，很多技术要你自己课外去学。你需要：

- 很好地理解底层计算机体系结构（比如看得懂 x86 汇编）和底层语言 C；
- 熟练掌握一门高级语言（Python）；
- 非常好的操作系统背景，尤其是 Linux/UNIX。

官方给的参照是：题目难度大致相当于 Vortex 攻防游戏的前六关。课程还建议先复习 [CSE365](/docs/systems/security/asu-cse365) 的内容，以及 pwn.college 橙带的逆向工程和二进制利用模块。

## 课程结构

2026 年秋季共十个模块：

| 模块 | 内容 |
|---|---|
| 1 | 汇编与调试复习 |
| 2 | 程序安全 |
| 3 | 高级逆向工程 |
| 4 | 返回导向编程（ROP） |
| 5 | 动态分配器滥用（堆利用） |
| 6 | 程序利用 |
| 7 | 竞态条件 |
| 8 | 沙箱逃逸 |
| 9 | 内核安全 |
| 10 | 系统利用 |

评分：作业 70%、期中 15%、期末 15%，另有最多 5% 的加分（在社区里帮助别人收到感谢）。

## 官方作业

每个模块是一个作业，包含大量相关的挑战，开放一到两周，解出一题拿一个 flag。作业分数的前 20% 靠在检查点前解出一半题目，其余 80% 按解题比例算；
截止后再解的题按 75% 计分。挑战可能需要用到甚至自己实现相当复杂的攻击工具。

官方说得很清楚：**pwn.college 平台和全部内容都对全世界公开**，校外注册账号就能做全部题目；每周的讲课录像（YouTube）和幻灯片也都链在课程页上。

## 学习建议

- **先把 CSE365 的内容打扎实。** 尤其是汇编、逆向和基础的二进制利用，否则一上来就会卡住。
- **gdb 要用到出神入化。** 这门课几乎每一题都要在调试器里看内存、看寄存器。
- **ROP、堆利用、内核三块最难。** 每块都值得配合讲课视频反复看，再回去做题。
- **在社区里交流思路。** pwn.college 的 Discord 很活跃，帮助别人还能得到感谢（选课学生还能拿加分）。
