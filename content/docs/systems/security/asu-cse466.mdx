## 课程简介

CSE466 是 CSE365 的进阶版，同样托管在 pwn.college 上，
主题集中在系统安全，尤其是二进制利用。

模块包括：程序内存布局、栈溢出与返回导向编程（ROP）、
shellcode 编写、格式化字符串漏洞、堆利用（各种 glibc 堆风水）、
竞态条件、内核态利用、沙箱逃逸等。

题目质量很高，但难度也确实大——涉及内核的那几个模块
经常一天写不出一道题。这是正常的；
官方同样提供 Discord 讨论区供求助。

做完这门课，你对“一个程序为什么会被攻破”的理解会非常具体。

## 先修要求

- 没有硬性先修要求，但强烈建议先完成 CSE365。
- 需要 C、Python 与 x86 汇编的阅读能力。
