## 课程简介

CS161 Computer Security 是伯克利的计算机安全课，2026 年秋季由 **David Wagner** 和 **Peyrin Kao** 讲授（2026 年春季是 Henry Corrigan-Gibbs 和 Raluca Ada Popa）。

课程按四大块展开，都配有一本**免费的在线教材**（由课程组编写）：

- **安全原则**：威胁模型、纵深防御、最小权限等设计安全系统的基本原则；
- **内存安全**：缓冲区溢出等内存漏洞怎么被利用，又怎么防御；
- **密码学**：对称加密、哈希、消息认证码、非对称加密与数字签名、密钥交换，以及怎样正确地组合它们；
- **Web 与网络安全**：同源策略、跨站脚本、跨站请求伪造、SQL 注入，TLS、DNS 安全、拒绝服务、防火墙与入侵检测。

三个项目分别对应内存安全、密码学系统设计和 Web 安全，讲、练结合得很好。

## 先修要求

官方先修：**CS61B、CS70 和 CS61C**（不强制检查，但官方不建议跳过）：

- **CS61C** 最重要：第一单元内存安全直接用到 C 和汇编（官方要求你懂 CS61C 前 13 讲的 C 与汇编部分）；
- **CS61B**：会从零实现链表、会测试自己的代码、能在 500～1000 行的代码库里工作，这和项目二有关；
- **CS70**：模运算、集合记号、能看懂数学证明，这和密码学单元有关。

另外默认你会 C、Python 和 Git；项目二用 **Go**，课上不讲 Go 语法，要自己学。

对应到本站：[CS61B](/docs/data-structures-algorithms/cs61b)、[CS61C](/docs/systems/computer-architecture/cs61c)、[CS70](/docs/advanced-mathematics/cs70)。

## 课程结构

按在线教材的章节：

| 部分 | 讲什么 |
|---|---|
| 安全原则 | 安全原则（第 1 章） |
| 内存安全 | x86 汇编与调用栈；内存安全漏洞；缓解内存安全漏洞（第 2～4 章） |
| 密码学 | 密码学导论；对称密码；密码学哈希；消息认证码；伪随机数生成器；Diffie-Hellman 密钥交换；公钥加密；数字签名；证书；口令；案例；比特币（第 5～16 章） |
| Web 安全 | SQL 注入；Web 导论；同源策略；Cookie 与会话管理；CSRF；XSS；UI 攻击；验证码（第 17～24 章） |
| 网络安全 | 网络导论；ARP；DHCP；WPA；BGP；TCP 与 UDP；TLS；DNS 与 DNSSEC；拒绝服务；防火墙；入侵检测及其规避；恶意软件；匿名与 Tor（第 25～39 章） |

评分（2026 年春季）：作业 10%、项目一 10%、项目二 20%、项目三 10%、期中 20%、期末 30%。

## 官方作业

**三个项目**（可以 1～2 人一组）：

| 项目 | 内容 |
|---|---|
| Project 1：利用内存安全漏洞 | 在虚拟机里依次攻破一系列有漏洞的程序（栈溢出、绕过各种防御等），2026 秋季共七题 |
| Project 2：安全的文件共享系统 | 用 Go 设计并实现一个端到端加密的文件共享系统：用户认证、文件操作、共享与撤销；要先交设计文档，再写代码和测试 |
| Project 3：攻破一个有漏洞的网站 | 用 Web 攻击技巧拿到网站里的一个个 flag |

2026 年秋季还有 **DUE**（Demo、Understand、Experiment）：项目做完后和助教进行几段简短的面谈，演示并讲清楚自己的代码。项目说明全部公开在课程网站上。

**作业与讨论课**：每周有作业，讨论课的题目和答案也都在网站上。

**AI 政策**：官方认为不用生成式 AI 学得最好，但对坚持要用的同学，按“学生、系统设计者、工程师”三种角色分别给出了可接受的用法指南。

## 学习建议

- **以在线教材为主线。** 教材按单元写得很完整，免费，比幻灯片更适合自学。
- **项目一先把栈吃透。** 画出每个函数的栈帧、返回地址在哪里，是写利用代码的前提；[CSAPP](/docs/systems/systems-fundamentals/cmu-15-213-csapp) 的 Attack Lab 是很好的热身。
- **项目二先设计再写代码。** 它最考验的是设计：怎样在服务器不可信的前提下保证机密性和完整性，还要支持共享和撤销。官方要求先交设计文档，这一步别省。
- **看 YouTube 录像。** 课程主页链着讲课录像的播放列表。
