## 课程简介

CS161 是伯克利的计算机安全导论，内容分五大块：
内存安全（缓冲区溢出及其防御）、密码学（对称与非对称加密、
哈希、签名、密钥交换）、Web 安全（XSS、CSRF、SQL 注入、同源策略）、
网络安全（TCP/DNS 攻击、防火墙、入侵检测），以及一些专题。

课程最有分量的是 Project 2：用 Go 设计并实现一个安全的文件分享系统。
你要自己决定用什么密码学原语、怎么组织密钥、
怎么保证在服务器不可信的前提下数据仍然保密和完整。
这是一次真正的安全系统设计训练，而不是做几道题。

2020 夏季学期的版本公开了课程录像，讲义和往年试题也都开放。

## 先修要求

- 指南列出的学前准备是 CS61A、CS61B、CS61C。
- 需要 C 语言能力（内存安全部分）与基本的 Go（项目部分）。
