## 课程简介

CSE365 是亚利桑那州立大学的网络安全导论，
托管在 pwn.college 平台上。课程完全以动手题目为主、讲座和阅读为辅。

内容按模块组织：Linux 命令行与权限、shell 脚本、程序与进程、
汇编基础、二进制文件格式、基础的内存破坏、
Web 安全基础、密码学基础、取证等。
每个模块有几十道题，难度依次递增，
全部以 CTF 的形式呈现——找到 flag 才算通过。

平台提供在线的实验环境，点开就能用，不需要自己配虚拟机。
对基础薄弱的人，卡关是正常现象；官方在首页提供了 Discord 讨论区。
