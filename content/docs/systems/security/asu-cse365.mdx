## 课程简介

CSE 365 Introduction to Cybersecurity 是亚利桑那州立大学（ASU）的网络安全入门课，2026 年秋季由 **Connor Nelson** 和 **Jaron Mink** 讲授。
整门课都搭在 **pwn.college** 上——这是 ASU 团队做的一个在线安全练习平台，**所有内容对全世界免费开放**。

官方的课程描述是：这门课介绍网络安全的基础。安全只和最弱的一环一样强，一个小失误就能让原本非常安全的软件崩塌。
课程从 **Web 的视角**看安全，沿着整个技术栈走一遍：从 CPU、内核、用户态、网络、密码学，一直到浏览器、HTTP 服务器和 Web 应用。

它的教学理念很鲜明：**真正的学习来自动手——频繁地、不停地动手**。讲课视频只提供背景，你会时常觉得“没准备好就上了”，这是有意为之。
课程的大部分时间都花在解题上：每个模块有 10～100 道挑战，解出来会拿到一个 flag，就知道自己做对了。

## 先修要求

官方没有要求安全基础。你需要会编程、愿意在 Linux 命令行里摸索。

官方很坦白：这门课 3 学分，按规定每周至少要花 9 小时，**很多人会觉得这是自己上过最难的课**，要做好投入大量时间的准备。

## 课程结构

2026 年秋季共八个模块：

| 模块 | 内容 |
|---|---|
| 1 | 入门、Linux 基础（Linux Luminarium）与访问控制 |
| 2 | 处理数据、与 Web 对话（HTTP）、SQL 练习场 |
| 3 | Web 安全 |
| 4 | 计算机基础（Computing 101：汇编等） |
| 5 | 逆向工程 |
| 6 | 二进制利用 |
| 7 | 拦截通信 |
| 8 | 密码学 |

评分：每个模块满分 105 分（以 100 为基准），包括累计解题 35 分、考核 55 分（现场演示解题 30 分 + 知识测验 25 分）和参与 15 分（看讲课、检查点、反思）。

## 官方作业

题目就是作业：每个模块几十到上百道挑战，都在 pwn.college 上，浏览器里就能开一个配好环境的工作区，也可以用 SSH 连进去。
解出一题会得到一个 flag，平台上实时记分。**校外任何人注册账号就能做全部题目**，只是成绩和考核只对选课学生有效。

pwn.college 上还有不跟学期的公开“道场”（dojo），配有从白带到黑带的“腰带”体系，可以按自己的节奏做。

## 学习建议

- **先做 Getting Started 和 Linux Luminarium。** 熟悉平台和命令行之后，后面的题会顺很多。
- **卡住是正常的。** 官方明说你会经常觉得“知识不够”，这正是学习的时候：去查资料、去试、去失败再重来。
- **用好 Discord。** 平台有很活跃的官方 Discord 社区，卡太久可以去问思路（别直接要答案）。
- **跟着讲课视频看背景。** 每个模块开头都有讲解视频，也发在 pwn.college 的 YouTube 频道上。
