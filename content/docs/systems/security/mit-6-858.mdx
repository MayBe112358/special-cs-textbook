## 课程简介

6.858 Computer Systems Security 是 MIT 的系统安全课，现在课号改成了 **6.566**，每年春季开，课程网站保留着 2009 年以来每一年的版本。

官方的课程描述是：**安全计算机系统的设计与实现**。讲课既讲破坏安全的攻击，也讲实现安全的技术，内容基于近年的研究论文——
操作系统安全、权限分离、能力（capability）、基于语言的安全、加密网络协议、可信硬件，以及 Web 应用和手机上的安全。
实验要实现并攻破一个能把任意代码关进沙箱的 Web 应用，支持 TLS 证书，再加上双因素认证。

课程主要面向高年级本科生、硕士和博士生，适合想深入学习“怎样构建安全的计算机系统”的人。

## 先修要求

官方先修：**6.102（软件构造）和 6.1800（计算机系统工程）**。

对应到本站：[MIT 6.102](/docs/software-engineering/mit-6-031) 和一门系统课（[CSAPP](/docs/systems/systems-fundamentals/cmu-15-213-csapp) 或 [MIT 6.S081](/docs/systems/operating-systems/mit-6-s081)）。
实验会用到 C、x86 汇编（缓冲区溢出那个实验）和 Python，要熟悉 Linux 和基本的网络知识。

## 课程结构

2026 年春季的讲次（几乎每讲都有一篇课前阅读的论文）：

| 部分 | 讲什么 |
|---|---|
| 隔离 | 导论与威胁模型；操作系统与虚拟机隔离；软件故障隔离；可信硬件；权限分离 |
| 平台 | 数据中心基础设施；手机安全；Web 安全模型 |
| 有缺陷的代码 | 缓冲区溢出防御；符号执行 |
| 网络与分布式 | 网络安全；安全信道；证书；用户认证；消息安全；匿名通信 |

评分：两次小考共 35%、五个实验 55%、课堂参与与课前问题 10%。

## 官方作业

**五个实验**（个人完成，大多围绕同一个 Python Web 应用 **zoobar**——用户之间互相转账“zoobar”——在官方提供的虚拟机里运行）：

| 实验 | 内容 |
|---|---|
| Lab 1 | 缓冲区溢出：找出 Web 服务器的漏洞并写利用代码，再修补 |
| Lab 2 | 权限分离：把 Web 应用拆成互相隔离的部分 |
| Lab 3 | 符号执行：自己搭一个符号执行系统，用它自动找 Web 应用里的 bug |
| Lab 4 | 浏览器安全：跨站脚本攻击、侧信道与钓鱼攻击、写一个在个人资料里传播的蠕虫 |
| Lab 5 | HTTPS 与 WebAuthn：支持 TLS 证书，加上双因素认证 |

实验说明和代码公开，评分用课程提供的 Makefile 和测试脚本，本地就能跑。官方要求不要把自己的答案公开。

**往年小考**：网站上有历年的小考题和答案。

**AI 政策**：官方说，想用 AI 助手替你写代码时，想一想你会从实验里少学到多少；你要理解交上去的所有代码，并能在考试里推理实验相关的问题。

## 学习建议

- **Lab 1 先补汇编和栈。** 缓冲区溢出要你亲手构造攻击载荷，栈帧布局和调用约定必须清楚，[CSAPP](/docs/systems/systems-fundamentals/cmu-15-213-csapp) 的 Attack Lab 是很好的热身。
- **每讲的论文要读。** 课程内容主要来自研究论文，课前问题就是为了逼你读完。
- **按官方虚拟机的环境做。** 实验对环境很敏感（编译选项、地址布局），用官方的虚拟机能省很多麻烦。
- **看 OCW 的录像。** 2026 年的录像在 MIT 的 Panopto 上需要登录；MIT OpenCourseWare 上有 2014 年秋季版的完整讲课录像，主题大部分相同。
