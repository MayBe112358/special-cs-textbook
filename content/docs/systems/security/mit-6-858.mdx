## 课程简介

6.858 是 MIT 的计算机系统安全课，形式上偏研究导向：
每节课围绕一篇论文或一个真实漏洞展开，
讨论攻击是怎么构造的、防御为什么有效或无效。

实验环境是一个叫 Zoobar 的 Web 应用靶场。
Lab 1 做缓冲区溢出攻击；Lab 2 用沙箱和权限隔离加固它；
Lab 3 用混合符号执行遍历程序的所有分支来找漏洞——
理解了符号执行的思路之后这个实验并不难，
但它非常直观地展示了这项技术能做什么；
Lab 4 是 Web 安全；最后的 Final Project 可以选择实现 SecFS，
一个基于加密的安全文件系统。

课程材料、讲座笔记和实验框架全部公开。

## 先修要求

- 需要计算机体系结构与操作系统的初步了解。
- 需要 C 与 Python 能力。
