## 课程简介

CS61C 是伯克利 CS61 系列的最后一门，把前两门课建立的“程序”概念一路拆到硬件。

课程主线是：数字的机器表示 → C 语言与内存布局 → RISC-V 汇编 →
编译、汇编、链接、加载的全过程 → 数字逻辑与 CPU 数据通路 →
流水线与冒险 → Cache 与存储层次 → 虚拟内存 → 并行（SIMD、多线程、MapReduce）。
学完你会知道一行 C 语句如何变成指令，指令又如何在流水线里执行。

课程项目很有特点：有一次是用 C 写一个小程序（做过《生命游戏》），
有一次是用 RISC-V 汇编实现神经网络的矩阵运算，
还有 Cache 与并行优化的性能竞赛。

它和 CSAPP 覆盖面接近，区别是 CS61C 更偏硬件一侧，
会真的让你画数据通路、算流水线周期。

## 先修要求
