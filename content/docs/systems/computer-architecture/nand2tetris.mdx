## 课程简介

Nand to Tetris（From Nand to Tetris: Building a Modern Computer From First Principles）由以色列的 **Noam Nisan** 和 **Shimon Schocken** 设计，
配套书是《The Elements of Computing Systems》（MIT 出版社，有中文版，中译名《计算机系统要素》）。

课程的设定是：**只给你一个与非门（Nand），一步步造出一台通用计算机，再在上面搭起一整套现代软件栈**——汇编器、虚拟机、高级语言编译器、操作系统，
最后在自己造的机器上跑小游戏。

它最独特的价值是“全栈可见”：通常分散在数字电路、计算机组成、编译原理、操作系统等十几门课里的东西，在这里被压成一条你亲手走完的链条。
官网说全世界有四百多所大学、高中和训练营在教这门课，学生从高中生到博士生、资深工程师都有。

**全部材料免费开源**（非营利用途）：讲义、项目说明、软件工具都在官网上。也可以在 Coursera 上学它的两部分课程，拿证书要付费。

## 先修要求

- 硬件部分（项目 1～5）：**不需要任何先修**，连电路基础都不用。
- 软件部分：项目 6 的汇编器起，要用一门你熟悉的编程语言（Python、Java 等都行）写程序，要能写中等规模的程序。

## 课程结构

十二个项目，分硬件和软件两部分：

| 部分 | 项目 | 做什么 |
|---|---|---|
| 硬件 | 1 布尔逻辑 | 用与非门搭出与、或、非、异或、多路选择器等基本门 |
| | 2 布尔算术 | 半加器、全加器、加法器，再组成 ALU |
| | 3 存储 | 触发器、寄存器、RAM、程序计数器 |
| | 4 机器语言 | 用 Hack 汇编写几个小程序，熟悉这台机器的指令 |
| | 5 计算机体系结构 | 把 CPU、内存装成一台完整的 Hack 计算机 |
| | 6 汇编器 | 写一个把 Hack 汇编翻译成机器码的汇编器 |
| 软件 | 7～8 虚拟机 | 实现一个栈式虚拟机的翻译器：先是算术与内存访问，再是程序控制和函数调用 |
| | 9 高级语言 | 用课程自定义的面向对象语言 Jack 写一个程序（比如小游戏） |
| | 10～11 编译器 | Jack 编译器：先做词法和语法分析，再做代码生成 |
| | 12 操作系统 | 用 Jack 写一个简单的操作系统库（数学、内存管理、屏幕、键盘、字符串等） |

每个项目都配有讲义幻灯片和项目说明，部分项目链着书的章节（主要是第一版的）。

## 官方作业

十二个项目就是全部作业。硬件部分用书里定义的简化**硬件描述语言（HDL）**写芯片，软件部分用你自己选的语言写。

**工具**：官方推荐新的**网页版 IDE**，不用安装任何东西，打开浏览器就能写 HDL、跑模拟器，文件存在浏览器里、也可以下载；
老的 Java 桌面版工具也还能下载。工具包括硬件模拟器、CPU 模拟器、汇编器、虚拟机模拟器等。

**测试**：每个项目都有官方的测试脚本和期望输出，在模拟器里一跑就知道对不对，非常适合自学。
卡住了可以去官网的问答论坛提问。

## 学习建议

- **先做项目，再看讲义。** 每个项目的说明本身就写得很完整，卡住了再回去看讲义和书。
- **用网页版 IDE。** 省掉装 Java 的麻烦，写完就能在浏览器里测试。
- **硬件部分最好一口气做完。** 前五个项目环环相扣，隔太久再回来容易忘了前面芯片的接口。
- **软件部分用你最熟的语言。** 汇编器、虚拟机翻译器、编译器的代码量逐渐变大，用顺手的语言能把精力留给设计本身。

## 同类课怎么选

- **[UC Berkeley CS61C](/docs/systems/computer-architecture/cs61c)**：真实的 RISC-V 指令集和 C 语言，缓存、流水线、并行讲得更深。
- **[ETH DDCA](/docs/systems/computer-architecture/eth-ddca)**：用真正的 Verilog 和 FPGA 开发板，一直讲到乱序执行和 GPU。
- **[CMU 15-213 CSAPP](/docs/systems/systems-fundamentals/cmu-15-213-csapp)**：从程序员视角看真实的 x86-64 系统，适合做完 Nand2Tetris 之后接着学。
- 想把编译器那部分学深，接 [Stanford CS143](/docs/systems/compilers/cs143)。
