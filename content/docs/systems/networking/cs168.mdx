## 课程简介

CS168 Introduction to the Internet: Architecture and Protocols 是伯克利的计算机网络课。2026 年秋季由 **Ion Stoica 和 Sylvia Ratnasamy** 讲，
2026 年春季由 Rishabh Iyer 讲。

官方的课程描述是：这门课介绍互联网的体系结构，**重点是那些让互联网取得成功的概念和基本设计原则**。
它不按“自顶向下”或“自底向上”地罗列协议，而是反复追问：互联网为什么要分层？路由为什么这样设计？TCP 为什么需要拥塞控制？
这些设计背后的原则（比如端到端原则）是什么？

课程有一本专门编写的**免费在线教材**（Peyrin Kao 根据 Sylvia Ratnasamy 等人的讲课整理），和讲课一一对应，是自学这门课最好的材料。

## 课程结构

按在线教材的章节（也是讲课的顺序）：

| 部分 | 讲什么 |
|---|---|
| 导论 | 互联网导论；分层；报文头；网络体系结构与设计原则；资源共享的设计；链路 |
| 路由 | 路由导论与模型；距离向量协议；链路状态协议；编址；路由器硬件；域间路由与 BGP；IP 报文头 |
| 传输 | 传输层原则；TCP 的设计与实现；拥塞控制的原则、设计与实现；TCP 吞吐量模型；路由器辅助的拥塞控制 |
| 应用 | DNS；HTTP 与 CDN |
| 端到端 | 以太网；二层路由（生成树 STP）；ARP；DHCP；NAT；TLS；端到端连通 |
| 数据中心 | 拓扑；拥塞控制；路由；编址；虚拟化；软件定义网络（SDN）；主机网络 |
| 超越客户端—服务器 | IP 组播与 DVMRP、核心树；覆盖网组播；集合通信（collective）操作及其实现 |
| 无线 | 无线链路；蜂窝网络 |

评分（2026 年春季）：三个项目共 50%、期中 25%、期末 25%，按系里的高年级课程标准调曲线；来上课还有少量加分。

## 官方作业

**三个项目**（Python，起始代码是课程网站上的 zip 包，校外可以直接下载）：

| 项目 | 内容 |
|---|---|
| Project 1：Traceroute | 自己实现 traceroute，分两部分：基本功能，再加上各种出错情况的处理 |
| Project 2：Routing | 写一个距离向量路由协议，课程提供模拟器，可以可视化地看你的协议怎样收敛 |
| Project 3：Transport | 实现 TCP 的一个子集，提供可靠传输（不含拥塞控制） |

2026 年秋季的第三个项目还没公布。自动评分只对选课学生开放，校外做完可以用项目自带的测试和模拟器自查。

**讨论课**：每周的讨论课题目、答案、讲解视频和幻灯片都放在课程网站上，是很好的练习题。

## 学习建议

- **以在线教材为主线。** 教材的章节和讲课一一对应，写得比幻灯片完整，而且免费。
- **看录像。** 2026 年春季的讲课录像放在 YouTube 播放列表里，讨论课的讲解视频也公开。
- **Project 2 多用模拟器。** 距离向量协议的毛病（如计数到无穷）光看代码很难发现，在模拟器里看路由表怎么变化最直观。
- **Project 3 在 Linux 或 WSL 的 Linux 文件系统里做。** 官方提醒：用 WSL 的话，别在 `/mnt/c` 下的 Windows 文件上跑 Linux 命令，会非常慢。
