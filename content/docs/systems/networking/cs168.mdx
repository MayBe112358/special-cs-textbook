## 课程简介

CS168 关心的是设计而不是配置：为什么互联网要分层？
为什么地址要这样编排？为什么路由要分成域内和域间两套机制？

课程从分层结构与包头讲起，接着是资源共享的设计（为什么是分组交换）、
链路层，然后花大篇幅讲路由——域内路由的模型、距离向量与链路状态算法、
域间路由与 BGP，之后是传输层（可靠传输、拥塞控制）、
DNS 与应用层，最后是安全与现代数据中心网络。

课程自编的在线教材写得很清楚，完全公开。作业用 Python 完成，
你会实现路由算法并在模拟网络里验证它们的行为。
