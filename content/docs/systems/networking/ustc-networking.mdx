## 课程简介

这是中国科学技术大学自动化系 **郑烇** 老师的《计算机网络》（和杨坚老师一起讲），郑老师从 1996 年起就在科大讲这门课。
课程用 Kurose 和 Ross 的《计算机网络：自顶向下方法》作教材，**B 站上的录像是 2020 年秋季科大本科课程的录制版**，是中文互联网上流传最广的网络课之一。

按课程简介的说法：在介绍计算机网络体系结构的基础上，**自上而下、以互联网为例**，系统地讲网络体系结构各层的主要服务、工作原理、常用技术和协议——
应用层、传输层、网络层、数据链路层和物理层，最后是网络安全的原理和协议。


## 先修要求

- 课程是网络的入门课，没有硬性先修。
- 有操作系统（进程、套接字）和计算机组成的基础，会更容易理解传输层和网络层的内容。
- 建议手边备一本《自顶向下方法》，课程的章节编号和教材一致。

## 课程结构

B 站录像共 69 集：

| 部分 | 讲什么 |
|---|---|
| 1 概述 | 什么是 Internet；网络边缘；网络核心；接入网和物理媒体；Internet 结构和 ISP；分组时延、丢失和吞吐量；协议层次和服务模型；历史 |
| 2 应用层 | 应用层原理；Web 和 HTTP；FTP；电子邮件；DNS；P2P 应用；CDN；TCP 和 UDP 套接字编程 |
| 3 传输层 | 传输层服务；多路复用和解复用；UDP；可靠数据传输的原理；TCP；拥塞控制原理；TCP 拥塞控制 |
| 4 网络层：数据平面 | 导论；路由器组成；IP 协议；通用转发和 SDN |
| 5 网络层：控制平面 | 路由选择算法；自治系统内部的路由选择；ISP 之间的路由选择 BGP；SDN 控制平面 |
| 6 链路层 | 服务；差错检测和纠正；多点访问协议；局域网；链路虚拟化；数据中心网络；一次 Web 请求的全过程 |
| 8 网络安全 | 什么是网络安全；加密原理；认证；报文完整性；密钥分发和证书；各个层次的安全性；防火墙；攻击和对策 |
| 9 前沿专题 | 软件定义网络；命名数据网络（两集）；移动优先网络和网络试验设施 |
| 复习与习题 | 课程复习；陈双武副教授讲第 1～6、8 章的典型习题 |

教材第 7 章（无线和移动网络）没有录像。

## 官方作业

课程没有配套的编程作业或在线评测，练习以教材为准：

- **典型习题讲解**：录像最后几集由陈双武副教授按章讲典型习题，适合学完一章后跟着做一遍。
- **教材章末习题**：教材作者网站上有[交互式章末习题](https://gaia.cs.umass.edu/kurose_ross/interactive/)，可以不断生成新题、做完看答案。
- **Wireshark 实验**：教材作者提供的[抓包实验](https://gaia.cs.umass.edu/kurose_ross/wireshark.php)，用真实数据包验证协议行为。

**课件**：郑老师在 B 站视频简介里用网盘链接免费分享了上课用的 PDF 课件（2020 年版和 2025 年版），个人主页上也有一份课程资源压缩包。
视频简介里说明，老师只在评论区抽空回答原理性问题，不解答习题。

## 学习建议

- **一章视频配一章教材。** 视频的节次编号和教材一致，看完一节就去读教材对应的部分，细节在书里。
- **习题别跳过。** 时延计算、TCP 序号与确认、拥塞窗口变化、路由算法这些题，不动手算一遍很难真正掌握；典型习题那几集正好讲这些。
- **抓包验证。** 讲到 HTTP、DNS、TCP 时，打开 Wireshark 抓一下自己电脑上的真实报文，对照课上讲的格式看。
- **想动手写协议，接 CS144。** 这门课偏原理，没有编程实验。
