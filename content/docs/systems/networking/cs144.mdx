## 课程简介

CS144 的讲授者之一是网络领域的 Nick McKeown。
课程按自顶向下的顺序讲：应用层、传输层、网络层、链路层，
每一层都先讲设计目标，再讲具体协议。

真正让这门课与众不同的是它的项目：你要用现代 C++ 循序渐进地实现一个完整的 TCP 协议栈——
先写字节流抽象，再写重组器处理乱序到达的分片，然后是接收方、发送方、
重传逻辑，最后把它接到真实网络上，用你自己写的协议栈和外部服务器通信。

做完之后，TCP 对你来说不再是 RFC 里的名词，而是你调试过的代码。
很多人说这门课同时也是一门很好的现代 C++ 实践课。

## 先修要求

- 需要一定的计算机系统基础与 C++ 能力（指南建议先修 CS106L）。
- 需要会用 Linux 命令行与调试工具。
