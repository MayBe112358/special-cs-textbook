## 课程简介

6.5840 Distributed Systems（2022 年及以前叫 6.824）是 MIT PDOS 研究组的研究生核心课，2026 年春季由 **Frans Kaashoek 和 Robert Morris** 讲授，
官网保留着 2000 年以来每一年的课程网站。

课程讲**构建分布式系统的抽象和实现技术**，核心话题是**容错、复制和一致性**。大部分时间用来研读和讨论真实的分布式系统案例：
几乎每节课读一篇经典论文，课前要交一道关于论文的小问题。

它真正出名的是**实验**：用 Go 一步步写出 MapReduce、Raft 共识算法、基于 Raft 的容错键值存储，最后是分片存储。
测试非常严格，会反复模拟网络分区、节点崩溃、消息丢失和乱序——能把 Raft 的全部测试跑绿，是很多人学分布式系统的一个里程碑。

## 先修要求

官方写的先修：**6.1910（计算机组成）加上 6.1800（计算机系统工程）或 6.1810（操作系统）之一，或同等课程**；
大量的编程经验会对实验很有帮助。

对应到本站：[CS61C](/docs/systems/computer-architecture/cs61c) 或 [CSAPP](/docs/systems/systems-fundamentals/cmu-15-213-csapp)，
再加上 [MIT 6.S081](/docs/systems/operating-systems/mit-6-s081)。Go 语言不要求事先会，第二讲就用 Go 讲 RPC 和线程，官方还指定了在线 Go 教程。

## 课程结构

2026 年春季 22 讲（括号里是要读的论文）：

| 部分 | 讲什么 |
|---|---|
| 入门 | 导论（MapReduce）；RPC 与线程（Go 示例）；GFS；Go 的并发模式（Go 团队的 Russ Cox 客座） |
| 共识与复制 | Paxos；Raft（两讲）；一致性与线性一致性；ZooKeeper |
| 事务 | 分布式事务（两阶段提交等）；Spanner；链式复制；乐观并发控制（FaRM） |
| 真实系统 | 分布式系统的形式化验证（IronFleet）；Facebook 的 Memcached；AWS Lambda（客座）；Ray |
| 去信任 | 分叉一致性（SUNDR）；比特币；拜占庭容错（PBFT） |
| 收尾 | 课程项目展示 |

中间有两个“黑客日”不上课，专门写实验。

评分：实验 40%（含选做的课程项目）、实验当面检查 15%、期中 20%、期末 20%、论文小问题 5%。

## 官方作业

**五个 Go 实验**（个人完成）：

| 实验 | 内容 |
|---|---|
| Lab 1：MapReduce | 实现一个 MapReduce 系统（协调者和工作者） |
| Lab 2：Key/Value Server | 单机键值服务器，保证在网络故障下每个 Put 最多执行一次、所有操作线性一致，再用它实现一把锁 |
| Lab 3：Raft | 分四部分：领导者选举、日志复制、持久化、日志压缩（快照） |
| Lab 4：KV Raft | 用自己的 Raft 库搭一个容错的键值存储，只要多数服务器活着就能继续服务 |
| Lab 5：Sharded KV | 把键分片到多个 Raft 复制组上，支持分片迁移；也可以换成自己设计的课程项目 |

实验代码公开：`git clone git://g.csail.mit.edu/6.5840-golabs-2026 6.5840`。官方提供了打分时用的全部测试，本地用 `make`（底层是 `go test -race`）就能跑。

**历年试题**：官网有 2018～2025 年的期中期末卷，大多附答案。

**AI 政策**：官方的原话是，想让 AI 助手替你写代码的时候，想一想你从实验里学到的也会相应变少；无论如何，你都要能解释交上去的每一行代码，并能在考试里推理实验相关的问题。
另外官方明确要求不要把实验代码公开到 GitHub 上。

## 学习建议

- **先把 Lab 1 当 Go 练习。** MapReduce 实验不难，正好用来熟悉 Go 的 goroutine、channel 和 RPC。
- **Raft 前先把论文读透。** 论文里的图 2 几乎就是实现规格，实验说明里多次提到要对照它来写。
- **测试要反复跑。** 分布式的 bug 常常几百次才出现一次，一次跑过不代表对了。
- **加日志、看时序。** Raft 出问题时，打印每个节点的任期、角色和日志变化，比单步调试有用得多。
- **看 2020 年的录像。** 2020 年春季的课程网站上大多数讲都有录像，论文和现在大部分重合。
