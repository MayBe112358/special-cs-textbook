## 课程简介

6.S081（现已改号为 **6.1810** Operating System Engineering）是 MIT 的操作系统课，2026 年秋季由 Robert Morris、Frans Kaashoek 和 Nickolai Zeldovich 轮流讲。

它不讲抽象的操作系统概念史，而是给你一个能真正启动起来的小型类 Unix 内核 **xv6**，让你一个实验一个实验地改造它：
加系统调用、实现页表、处理陷阱、写写时复制、写网卡驱动、写锁、写文件系统、写 mmap。课程的说法是 learning by doing——
你对操作系统的理解来自亲手让内核跑起来，或者亲手让它崩溃。

xv6 是 MIT 照 Unix 第六版重写的教学内核，运行在 RISC-V 上，代码规模远小于 Linux，但结构相似。读完之后再去看 Linux 内核，会发现许多东西是眼熟的。
后半学期的讲课还会借 xv6 讨论真实系统里的问题：透明大页、尾延迟、崩溃恢复、形式化验证、多核可扩展性与 RCU、容器与虚拟机、BPF、Meltdown。

## 先修要求

- 官方说这门课面向“**上过并且喜欢 6.1910（原 6.004）**”的本科生。6.1910 是 MIT 的计算机组成课，对应到本站可以看 [CS61C](/docs/systems/computer-architecture/cs61c) 或 [CSAPP](/docs/systems/systems-fundamentals/cmu-15-213-csapp)。
- 编程语言：实验全部用 C 写，需要能读写指针、结构体和手工内存管理。官方指定的教材之一就是 K&R《C 程序设计语言》。
- 工具：实验在 Unix 环境里用 make、gdb 和 QEMU 完成，需要基本的命令行能力。

## 课程结构

2026 年秋季共 23 讲，每讲前都要读 xv6 讲义的对应章节或一篇论文，并交一道小作业题：

| 部分 | 讲什么 |
|---|---|
| 入门 | 导论与示例；xv6 里的 C；操作系统设计 |
| 虚拟内存 | 页表；缺页异常；透明大页；给应用程序用的虚拟内存 |
| 陷阱与系统调用 | 系统调用的进入与返回；系统调用拦截 |
| 并发 | 锁；线程切换；协调（睡眠与唤醒） |
| 设备与组织 | 设备驱动；操作系统的组织方式（宏内核与微内核）；网络 |
| 存储 | 文件系统；崩溃恢复（日志） |
| 真实系统专题 | 尾延迟；形式化验证；多核可扩展性与 RCU；容器与虚拟机；内核可扩展性（BPF）；Meltdown |

教材是课程自编的《xv6: a simple, Unix-like teaching operating system》（Cox、Kaashoek、Morris），外加 K&R。

评分：实验 65%（`make grade` 的得分加上和助教的当面检查）、两次考试 30%、课前小作业 5%。**所有实验都必须交才能及格。**

## 官方作业

九个实验，全部在 xv6 上做（2026 年秋季）：

| 实验 | 内容 |
|---|---|
| Utilities | 启动 xv6，写 sleep、find 等用户程序，熟悉系统调用 |
| System calls | 用 gdb 调试内核；给命令加沙箱（限制它能用的系统调用和路径）；再试着攻击 xv6 |
| Page tables | 查看和打印两级页表；检测哪些页被访问过；用页表加速系统调用；支持超级页 |
| Traps | 读 RISC-V 汇编；打印调用栈（backtrace）；实现用户态定时回调（alarm） |
| Copy-on-write | 实现写时复制的 fork |
| Network driver | 给 E1000 网卡写驱动，再实现 UDP 接收 |
| Lock | 改造内存分配器减少锁争用；实现读写锁 |
| File system | 支持大文件和符号链接 |
| mmap | 实现 `mmap` 和 `munmap` |

每个实验都带 `make grade` 评分脚本，本地就能自测——这也是官方给实验打分的依据（Gradescope 上跑的就是它）。
实验代码通过 git 公开发布，校外可以完整地做一遍。

**往年考试**：课程的 quiz 页上有历年的期中期末试题，官方提醒其中关于旧教学系统 JOS 的题已经不适用，xv6 的题仍是很好的练习。

**AI 政策**：可以用 AI 帮你理解操作系统概念、阅读材料和 xv6 代码，但**不要用它写实验代码，也不要用它帮你调试实验代码**。
官方还要求不要把自己的实验答案公开到 GitHub 等网站上。

## 学习建议

- **先读实验指引。** 官方的 Guidance 页讲了怎样调试内核、怎样用 gdb 连 QEMU，第一次做之前一定要读。
- **读 xv6 讲义和源码。** 每个实验都对应讲义的一两章，先把对应的 xv6 代码读懂再动手，比直接改要快得多。
- **看 2020 年的讲课录像。** 2020 年秋季的课程日程上大多数讲都链着 YouTube 录像，前半学期的内容和现在基本一致。
- **用好 gdb。** 内核崩溃时 `make qemu-gdb` 加 gdb 单步跟踪，是定位问题最快的办法。
- **注意工具链。** 按 Tools 页装 RISC-V 工具链和 QEMU；Windows 上建议用 WSL。

## 同类课怎么选

- **[UC Berkeley CS162](/docs/systems/operating-systems/cs162)**：理论覆盖更全（调度、分布式等都讲），项目在 Pintos 上做，是另一条主流路线。
- **[南京大学 操作系统](/docs/systems/operating-systems/nju-os)**：蒋炎岩的中文课，大量现场代码演示，实验同样要写一个小内核。
- **[哈工大 操作系统](/docs/systems/operating-systems/hit-os)**：中文课，围绕 Linux 0.11 讲，适合想先看一个真实的早期内核的人。
- 做完可以接 [MIT 6.5840 分布式系统](/docs/systems/parallel-and-distributed/mit-6-5840)，同一个研究组开的课。
