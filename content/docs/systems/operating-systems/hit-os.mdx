## 课程简介

这门课的主线是一个很实在的问题：给一台只有单核 CPU、内存、磁盘、
键盘和显示器的基本计算机，怎么配上一个能实际运转的操作系统？

围绕这个问题，课程讲六个基本模块——CPU 管理、内存管理、外设管理、
磁盘管理与文件系统、用户接口、启动模块——以及它们之间的联系。
每个模块都从原理讲到算法和数据结构，再落到 Linux 0.11 的真实代码上。

它的讲法很善于从学生的困惑出发：从“弱弱地问，什么是操作系统”开始，
从 CPU 的直观管理引出进程概念，从“那就先让程序进内存”引出内存管理。
配套有十二个实验，覆盖进程、虚存、驱动的设计与实现。

## 先修要求

- 需要 C 语言基础。
- 了解一点汇编会更容易读懂 Linux 0.11 的启动代码。
