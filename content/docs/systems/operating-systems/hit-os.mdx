## 课程简介

这是哈尔滨工业大学 **李治军** 老师的《操作系统》（和张丽杰老师一起开在中国大学 MOOC 上）。

课程的主线是一个很实在的问题：**给一台只有单核 CPU、内存、磁盘、键盘和显示器的基本计算机，怎样配上一个能实际运转的操作系统？**
围绕它，课程讲一个基本操作系统的六个模块——**CPU 管理、内存管理、外设管理、磁盘管理与文件系统、用户接口、启动模块**——以及它们之间的联系。
每个模块都从原理讲到算法和数据结构，再借开源的 Linux（0.11 版）讲清楚完整的代码实现。

它的讲法很善于从学生的困惑出发：第二讲叫“开始揭开钢琴的盖子”，从 CPU 最直观的管理办法引出多进程，从“那就先让程序进内存”引出分段和分页。
官方的目标是让你体会一个完整的操作系统怎样运转，培养设计和实现一个完整操作系统的能力。

## 先修要求

- C 语言：实验全部在 Linux 0.11 的 C 源码上改。
- 汇编：启动那几讲和第一个实验会读 x86 汇编，了解一点会轻松很多。
- 计算机组成的基本概念（寄存器、中断、内存寻址），[CSAPP](/docs/systems/systems-fundamentals/cmu-15-213-csapp) 或 [CS61C](/docs/systems/computer-architecture/cs61c) 的前半部分就够了。

## 课程结构

中国大学 MOOC 上共 32 讲，分四章：

| 章 | 讲什么 |
|---|---|
| 操作系统基础 | 什么是操作系统；揭开钢琴的盖子；操作系统启动；操作系统接口；系统调用的实现；操作系统历史 |
| 进程与线程 | CPU 管理的直观想法；多进程图像；用户级线程；内核级线程及其实现；进程“树”；CPU 调度策略；一个实际的 schedule 函数；进程同步与信号量；临界区保护；信号量的代码实现；死锁处理 |
| 内存管理 | 内存使用与分段；分区与分页；多级页表与快表；段页结合的实际内存管理；请求调页；内存换出 |
| 设备驱动与文件系统 | I/O 与显示器；键盘；生磁盘的使用；从生磁盘到文件；文件使用磁盘的实现；目录与文件系统；目录解析的代码实现 |

每章有章节测试，MOOC 上建议每周投入 3～5 小时。

## 官方作业

MOOC 上穿插了五个实验项目（控制系统启动、添加系统调用、进程运行轨迹的跟踪与统计、地址映射与共享、终端设备的控制），
完整的实验在**蓝桥云课的《操作系统原理与实践》**里，免费，浏览器里直接开一个装好 Linux 0.11 和 Bochs 模拟器的在线环境：

| 实验 | 内容 |
|---|---|
| 熟悉实验环境 | 编译 Linux 0.11、在模拟器里启动它 |
| 操作系统的引导 | 改写启动阶段的汇编代码，完成系统引导 |
| 系统调用 | 给 Linux 0.11 添加两个系统调用并写测试程序 |
| 进程运行轨迹的跟踪与统计 | 在内核里记录每个进程的状态变化，再做统计分析 |
| 基于内核栈切换的进程切换 | 把 Linux 0.11 基于 TSS 的切换改成基于内核栈的切换 |
| 信号量的实现和应用 | 在内核里实现信号量，再写程序用它做进程同步 |
| 地址映射与共享 | 跟踪 Linux 0.11 的地址映射过程，并实现进程间的内存共享 |
| 终端设备的控制 | 修改键盘和显示的处理，控制字符的输入与显示 |
| proc 文件系统的实现 | 在 Linux 0.11 上实现 proc 文件系统里的 psinfo 结点 |

MOOC 官方说全套有 12 个配套实验，蓝桥云课上目前是以上 8 个加一个环境熟悉。实验没有自动评分，做完自己在模拟器里验证效果。

## 学习建议

- **先看录像，再做实验。** 蓝桥云课的实验说明也推荐先学完对应的理论课，实验要改的代码都在课上讲过。
- **对照 Linux 0.11 源码听课。** 课上讲 schedule 函数、信号量实现、目录解析这些都会逐行讲代码，手边开着源码跟着看效果最好。
  赵炯的《Linux 内核完全注释》逐行注释了 Linux 0.11 的源码，可以当参考书。
- **进程切换那个实验最有价值。** 把 TSS 切换改成内核栈切换，会逼你把进程、栈、中断返回这些概念彻底弄明白。
- **用 gdb 连 Bochs 调试。** 内核崩了什么都看不到的时候，单步跟踪是唯一的办法。
