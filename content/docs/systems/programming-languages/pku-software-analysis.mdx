## 课程简介

《软件分析技术》是北京大学 **熊英飞** 老师的课，从 2014 年起每年秋季开，课件都放在他的主页上。这里以最近一个完整学期（2025 秋季）为主，2026 秋季正在进行。

官方的课程简介说：对软件代码进行分析是各种软件工程工具的基本手段——编译器、代码编辑器、测试与调试工具都离不开它；
工业界大公司的基础平台部门大量需要这类人才，学术界它是程序设计语言和软件工程研究的必备基础。
但这方面的文献**内容广、流派多、数学要求高**，学起来一直很难。这门课想通过通俗易懂的讲解，帮你建立较完整的软件分析知识体系，
学术上为进一步研究打基础，实践上培养开发大型软件工程工具的能力。

课程内容分三块：

1. **基于抽象解释的程序分析**：数据流分析、过程间分析、指针分析、抽象解释及其自动化；
2. **基于约束求解的程序分析**：SAT、SMT、符号执行；
3. **前沿与应用**：资源消耗（量化）分析、程序合成、缺陷定位与修复；2026 秋季还有量化分析和贝叶斯程序分析的客座讲座。

## 先修要求

官方写的预备知识只有一条：**熟悉常见的数学符号**。

实际上还需要数据结构与算法；课程项目一用 Java（在静态分析框架上实现），项目二用 Python。
学过一门静态分析入门课（比如南大的[软件分析](/docs/systems/programming-languages/nju-software-analysis)）会轻松很多。

## 课程结构

2025 年秋季 18 讲左右：

| 部分 | 讲什么 |
|---|---|
| 基础 | 课程介绍；程序设计语言基础知识 |
| 数据流分析 | 示例；框架和扩展；加宽、变窄与抽象解释；多角度理解程序分析 |
| 过程间分析 | 过程间分析；过程间分析的加速技术 |
| 指针分析 | 过程内指针分析；其他过程内指针分析与过程间指针分析 |
| 稀疏与抽象域 | 静态单赋值与稀疏分析；关系型抽象域 |
| 约束求解 | 布尔可满足性（SAT）；可满足性模理论（SMT）；符号执行；符号抽象 |
| 应用 | 程序的资源消耗分析；程序合成（枚举法与其他方法） |

还有一份配套的课程讲义（PDF），和前几讲对应。

评分（2026 秋季）：课程作业 20 分、课程项目 40 分（命题项目和自选项目各 20 分）、期末考试 40 分（半开卷，可带小抄）。

## 官方作业

- **每讲的练习**：几乎每讲的幻灯片里都有练习题，是每周的书面作业，题目随幻灯片公开，可以自己做。
- **课程项目一：Java 指针分析**（3 人一组）：实现一个 Java 程序的指针分析系统，给测试点里的变量算出可能指向的分配点。
  可以用太阿、Soot、WALA 等平台，但不能直接调用平台自带的指针分析；按结果是否健壮（sound）和精度打分，还要提交一个自己写的测试用例。
  项目要求、太阿框架介绍和项目包都公开可下载。
- **课程项目二：符号执行**（个人）：以 MIT 6.566（原 6.858）的 lab3 为基础，用 Python 做符号执行，通过 GitHub Classroom 分发和自动测评；说明文档公开。

## 学习建议

- **先学一门入门课再来。** 这门课理论覆盖更全、节奏更快，先学过南大的软件分析，再来看抽象解释和约束求解会顺很多。
- **抽象解释要反复看。** 抽象域、加宽和变窄这些概念是整门课的骨架，第一次看不懂很正常。
- **做项目一练指针分析。** 自己实现一个指针分析、在健壮性和精度之间权衡，是理解这部分内容最好的方式。
- **看历年课件对照。** 主页上保留了 2014 年以来每一年的课件，某一讲看不懂，可以翻翻其他年份的版本。

## 同类课怎么选

- **[南京大学 软件分析](/docs/systems/programming-languages/nju-software-analysis)**：入门首选，录像完整，Tai-e 作业有在线评测；这门课的项目一也推荐用 Tai-e。
- **[剑桥 程序设计语言语义学](/docs/systems/programming-languages/cambridge-semantics)**：形式语义的基础，理解抽象解释之前的好铺垫。
- **[MIT 6.858 计算机系统安全](/docs/systems/security/mit-6-858)**：项目二用的就是它的符号执行实验。
