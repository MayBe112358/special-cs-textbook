## 课程简介

这门课比同类课程的覆盖面更宽，分三大块：

第一块是基于抽象解释的程序分析：数据流分析、过程间分析、
指针分析，以及抽象解释这个统一的理论框架。
第二块是基于约束求解的程序分析：SAT、SMT 求解器、符号执行——
这条路线和数据流分析是两种不同的思路，前者把程序性质编码成约束交给求解器。
第三块是软件分析的应用：程序合成（让机器写代码）、
缺陷定位与缺陷自动修复。

和南大那门课相比，这门课理论覆盖更全面，难度也更大，
尤其是抽象解释和约束求解那两部分。
如果你已经学过一门静态分析课，这门课能把视野拓宽不少。

## 先修要求

- 需要数据结构与算法基础。
- 需要至少熟悉一门编程语言；理解形式化定义的能力更重要。
