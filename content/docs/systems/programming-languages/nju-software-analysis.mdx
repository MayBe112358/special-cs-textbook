## 课程简介

《软件分析》（Static Program Analysis）是南京大学 **李樾** 和 **谭添** 两位老师在 2020 年春季开设的课，讲**静态程序分析**——
一种在不运行程序的情况下推断它行为的技术，用来提升软件的可靠性、安全性和性能，在工业界的影响越来越大。

课程分理论和实践两部分：

- **理论**：从经典的数据流分析和指针分析的基础，讲到安全分析、Soundiness 等进阶话题；
- **实践**：两位老师专门设计了一个全新的静态分析框架 **Tai-e（太阿）**，所有作业都在它上面实现——活跃变量分析、常量传播、死代码检测、
  基于类层次结构的调用图构建、非上下文敏感和上下文敏感的指针分析、污点分析。

课程面向高年级本科生和各阶段的研究生，每讲都有中文录像放在 B 站上。

## 先修要求

官方写的先修：

- 数据结构与算法；
- 熟悉一门编程语言，**最好是 Java**（作业都用 Java 实现）；
- 编译原理**不是**先修，但了解它会更好。

## 官方作业

八个编程作业，全部在 **Tai-e 教学版**上用 Java 实现：

| 作业 | 内容 |

作业的参考答案和完整测试用例只提供给授课老师（发邮件申请）。

## 学习建议

- **视频配幻灯片。** 每讲都有 PDF 幻灯片和 B 站录像，讲得非常细，适合反复看。
- **数据流分析的理论基础要吃透。** 格、单调框架、不动点这几讲是后面所有分析的数学基础。
- **作业按顺序做。** 八个作业一环套一环：数据流分析、过程间分析、指针分析，再到用指针分析做污点分析。
- **自己写测试用例。** 官方的教程教你用 Tai-e 分析自制的 Java 程序，比只跑给定用例更能发现问题。
- **想继续深入，看科研版 Tai-e。** 它是一个用于研究的完整静态分析框架，有独立的文档。

## 同类课怎么选

- **[北京大学 软件分析技术](/docs/systems/programming-languages/pku-software-analysis)**：同样讲程序分析，更侧重抽象解释、约束求解，以及程序合成与缺陷修复等应用。
- **[剑桥 程序设计语言语义学](/docs/systems/programming-languages/cambridge-semantics)**：从形式语义的角度理解程序，为程序分析打理论基础。
- **[Stanford CS143](/docs/systems/compilers/cs143)**：编译器课的优化部分（数据流分析）和这门课的前半段相通。
