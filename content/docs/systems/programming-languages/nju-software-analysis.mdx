## 课程简介

软件分析在这门课里特指静态分析——不运行程序，
只通过分析源代码和各种中间表示，得到关于程序性质的**近似**结论。
“近似”这个词是关键：静态分析的全部艺术都在于如何在精度和代价之间取舍。

课程从基础讲起：抽象语法树、控制流图与中间表示，
然后是数据流分析的理论框架（格、单调函数、不动点）、
过程间分析与调用图构造，接着是指针分析——
这是全课最核心也最难的部分，从上下文不敏感一路讲到上下文敏感。
最后是 IFDS 等高级主题。

配套实验框架 Tai-e 由课程团队自己开发，八个作业覆盖编译优化
（活跃变量、常量传播）、指针分析与安全应用（污点分析）。
每个作业都有测试，是国内少有的高质量静态分析实践材料。

## 先修要求
