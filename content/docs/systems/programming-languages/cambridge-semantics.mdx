## 课程简介

这门课回答一个容易被忽略的问题：当我们说一段程序“做了什么”，
这句话本身有没有精确的含义？

课程从一门用 BNF 定义的简单命令式语言开始，
先给它一套操作语义（operational semantics）——
用形式规则描述程序如何一步步求值；接着引入类型系统，
证明类型安全性（well-typed programs don't go wrong）；
然后扩展语言，加入函数、递归、引用与子类型；
最后进入指称语义（denotational semantics），
把程序解释成数学对象。

它是为数不多提供公开视频的编程语言理论课，讲得严谨但对初学者友好。
如果你想理解类型系统和语言规范背后的数学，这是一个很好的起点。

## 先修要求

- 需要基础的离散数学，尤其是归纳法与形式化证明。
- 接触过函数式语言（OCaml/ML/Haskell）会更容易理解例子。
