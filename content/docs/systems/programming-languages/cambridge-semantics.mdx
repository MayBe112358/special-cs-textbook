## 课程简介

Semantics of Programming Languages 是剑桥大学计算机系本科二年级（Part IB）的课，由 **Peter Sewell** 讲授，12 讲。

官方的目标是：**介绍程序设计语言语义的结构化、操作式方法**——怎样精确地规定典型语言构造的含义（放在语言设计的背景下），
以及怎样**形式化地推理程序的语义性质**。

它不是“学一门新语言”的课，而是回答“一门语言到底是什么意思”：用一组推导规则写出程序怎样一步步执行（操作语义）、哪些程序是合法的（类型系统），
再用归纳法**证明**这些定义的性质，比如“类型正确的程序不会卡住”（类型安全）。课程围绕几门逐步变大的小语言（L1、L2、L3）展开。

在剑桥，它是 Hoare 逻辑与模型检验、类型论等高年级课的先修课。

## 先修要求

官网没有列硬性先修。实际上你需要：

- 离散数学：集合、关系、数学归纳法；
- 能读写数学证明——整门课的核心就是归纳证明；
- 看懂讲义附带的实现需要一点函数式编程（OCaml 或 Standard ML）。

## 课程结构

2025–26 学年的大纲：

| 主题 | 讲什么 | 讲次 |
|---|---|---|
| 导论 | 迁移系统；结构化操作语义的思想；一门简单命令式语言的迁移语义；语言设计的取舍 | 2 |
| 类型 | 形式类型系统入门；简单命令式语言的类型；想要的性质怎么表述 | 2 |
| 归纳 | 数学归纳；抽象语法树与结构归纳；基于规则的归纳定义与证明；类型安全性的证明 | 2 |
| 函数 | 传名调用与传值调用的语义和类型；局部递归定义 | 2 |
| 数据 | 积、和、记录、引用的语义与类型 | 1 |
| 子类型 | 记录子类型与简单的对象编码 | 1 |
| 语义等价 | 程序片段的语义等价与同余性；等价与不等价的例子 | 1 |
| 并发 | 共享变量的交错执行；简单互斥锁的语义；可串行化性质 | 1 |

学完你应该：熟悉用规则描述简单的命令式、函数式、交互式构造的操作语义和类型系统；能用数学、结构、规则三种归纳法证明操作语义的性质；
熟悉几种基于操作语义的程序等价概念。

推荐阅读：Pierce《类型和程序设计语言》（TAPL，前 15 章与本课相关）、Harper《Practical Foundations for Programming Languages》（作者主页免费）、
Hennessy《The Semantics of Programming Languages》（绝版，网上可下）、Winskel《程序设计语言的形式语义》。

## 官方作业

- **讲义习题**：讲义（136 页）每章后都有习题，按难度分三级——一颗星是检验是否理解的基础题（建议全做），两颗星需要多想一点（包括证明和实现题，建议大部分都做），
  三颗星可能超出讲义或很花时间。讲义里还给了一份建议的辅导课（supervision）习题清单。
- **语言实现**：课程网站提供 L1 的 OCaml、Standard ML、Java 实现和 L2 的 Standard ML 实现，可以边读规则边跑解释器，部分习题要求修改它们。
- **历年考题**：剑桥计算机系公开了这门课的历年考题。

没有编程作业和自动评分；剑桥的考核是期末笔试。

## 学习建议

- **每条规则都手推一个例子。** 看到一条推导规则，就拿一段小程序按规则一步步走一遍，比盯着符号看有效得多。
- **归纳证明要亲手写。** 类型安全（进展 + 保持）的证明是整门课的高潮，第一次写很难，但写通一次，后面的证明都是同一个套路。
- **配合 TAPL 读。** Pierce 的书把同样的内容讲得更详细，还有大量习题和 OCaml 实现。
- **用解释器做实验。** 改一条规则、看解释器行为怎么变，是理解“规则决定语义”最直观的方式。
