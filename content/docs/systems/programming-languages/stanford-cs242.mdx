## 课程简介

CS242 讲编程语言，但不是纯理论导向。官方的课程说明写得很清楚：
这门课研究计算的模型，既有老的——1930 年代的 Lambda 演算与函数式编程，
也有新的——2010 年代 Rust 那样的内存安全系统编程。

课程的主张是：编程语言的研究一半是理论一半是系统，
对语法、结构和语义的严格理解，能让你对真实系统的行为做形式化的推理。
所以课程会先讲 Lambda 演算、类型系统、类型推导，
再用 Rust 这样的真实语言展示这些理论如何在实践中防住错误。

在今天这个新语言层出不穷的环境里，这门课还想给你一套框架，
用来比较不同语言、不同范式之间的取舍，
而不是凭印象说某个语言好。

## 先修要求

- 需要对计算机系统和编程语言理论有初步了解。
- 作业使用 OCaml 与 Rust，不要求预先精通。
