## 课程简介

CS242 Programming Languages 是斯坦福的程序设计语言课，2026 年秋季由 **Alex Aiken** 讲授。

官方的描述是：课程讲**程序设计语言理论的基础**、这些理论**在今天广泛使用的语言里的应用**，以及可能塑造**明天的程序设计语言**的趋势。
课上学到的技术也是一套思考工具，帮你理解陌生的语言、提升设计和编写软件的能力；课程还会用这些思想来考察一些现代语言和环境。

路线大致是：先用组合子演算、λ 演算和类型系统打好理论基础，再用这些概念去看状态、续延、单子、对象这些语言特性，
最后巡览 Rust、Prolog、Haskell、Agda 等风格迥异的语言，以及渐进类型、数组编程和基于类型论的程序验证。

## 先修要求

官网没有列硬性先修。实际上你需要：

- 扎实的编程能力：七个作业每周约 10 小时，要能快速上手没用过的语言；
- 离散数学和证明能力：λ 演算、类型系统部分有推导和证明；
- 计算机系统的基础（讲 Rust、状态时会用到）。

## 课程结构

2026 年秋季（暂定）的讲次和配套阅读：

| 部分 | 讲什么 |
|---|---|
| 计算模型 | 课程概述；组合子演算（两讲，读 Backus《程序设计能从冯·诺依曼风格中解放出来吗？》和 MapReduce 论文）；λ 演算 |
| 类型 | 类型化 λ 演算；多态类型（读 Milner 的类型多态论文） |
| 语言特性 | 状态；续延；单子；对象 |
| 语言巡览 | Rust；Prolog；Haskell；Agda |
| 进阶 | 用类型论做程序验证（读 CompCert、seL4 论文）；渐进类型；数组编程 |

评分：七个编程作业共 35%（每个 5%）、期中 25%、期末 40%（全面覆盖，侧重期中之后）。讲课录像只放在校内 Canvas 上。

## 官方作业

- **2026 年秋季**：七个编程作业，大约每周一个，第二周开始，学期中陆续发布。
- **往年试卷**：官网有 2021～2024 年秋季的期中、期末卷，**都附答案**，是自学时最好的练习。
- **2019 年秋季版（Will Crichton 讲）**：八个作业和实验全部公开，可以完整做一遍：

| 作业 | 内容 |
|---|---|
| 1 JSafe | 定义 JSON 模式的文法并写校验器；给 JSON 访问器写操作语义，证明访问的安全性 |
| 2 Lambda Theory | λ 演算的理论题 |
| 3 106 Redux | 用 OCaml 写 n-gram 文本生成和一个 Karel 虚拟机，熟悉函数式编程 |
| 4 Interpreter | 用 OCaml 写一个解释器 |
| 5 WebAssembly | 把 x86 代码翻译成 WebAssembly；给 WASM 加 if、for、try/except；控制流完整性 |
| 6 Linear Types | 用 Rust 体会线性类型 |
| 7 Futures | Rust 的 Future 与异步 |
| 8 Typestate | 用 Rust 的类型编码状态机：购物车 API，以及用会话类型实现经过验证的 TCP |

## 学习建议

- **理论部分跟着推。** λ 演算的归约、类型推导规则，要拿纸笔一步步推，光看不练很快就会迷失。
- **每门“巡览”语言都写点代码。** Prolog、Haskell、Agda 的思维方式差别很大，各写一个小程序才能真正体会课上讲的概念。
- **用往年试卷检验。** 四年的期中期末都附答案，题目风格很稳定。
- **想要完整的作业，做 2019 版。** 那一版的作业把理论（λ 演算、类型）和实践（OCaml、Rust、WebAssembly）结合得很好。
