## 课程简介

15-213 Introduction to Computer Systems（ICS）是卡内基梅隆大学的系统入门课，2026 年秋季由 Phillip Gibbons 和 Seth Goldstein 讲授。
配套教材《Computer Systems: A Programmer's Perspective》（简称 CSAPP，中译《深入理解计算机系统》，第 3 版）
由 CMU 的 Randal Bryant 和 David O'Hallaron 编写，被很多学校当作系统课的教材。

官方的定位是：**从程序员的视角看计算机系统怎样执行程序、存储信息、相互通信**。
学完你会写出更好的程序——尤其是在性能、可移植性和健壮性上；它也是编译器、网络、操作系统、体系结构这些后续课的基础。

这门课最出名的是它的**实验**。官方原话：“实验是这门课的核心，你在这门课里学到的大部分东西都来自完成这些实验。”

## 先修要求

- 官方先修：CMU 15-122（C 语言的命令式编程与数据结构）。对应到本站，[CS61A](/docs/programming-intro/cs61a) 和 [CS61B](/docs/data-structures-algorithms/cs61b) 再加上一点 C 语言的练习。
- 课上会用到 Linux 命令行、Git、gdb、gcc 和 make。CMU 会开几次“训练营”（bootcamp）专门教这些，自学的话事先熟悉一下。

## 课程结构

2026 年秋季的讲次（括号里是 CSAPP 对应章节）：

| 部分 | 讲什么 |
|---|---|
| 数据 | 位、字节与整数（2.1～2.3） |
| 机器级程序 | x86-64 机器级编程（四讲，第 3 章） |
| 链接与调试 | 链接（第 7 章）；设计与调试 |
| 存储器 | 存储器层次；缓存（第 6 章）；虚拟内存的概念与细节（9.1～9.8）；动态内存分配基础与进阶（9.9～9.12） |
| 性能 | 代码优化（第 5 章） |
| 进程与异常 | 进程与多任务；异常控制流（第 8 章） |
| I/O 与网络 | 系统级 I/O 与文件系统；网络编程（两讲，第 11 章） |
| 并发 | 并发编程；同步基础与进阶；线程级并行（第 12 章） |
| 收尾 | 计算的前沿 |

评分：实验共 50%；十次书面作业 6%（同学互评）；十次课堂小测共 4%；期中 15%；期末（三小时闭卷，可带两张小抄）占其余部分。

## 官方作业

**实验**（2026 年秋季，括号里是占总成绩的比例）：

| 实验 | 内容 |
|---|---|
| L0 C 编程（2%） | C 语言热身 |
| L1 Data Lab（7%） | 只用受限的位运算和直线代码实现整数和浮点函数，比如不用分支求绝对值 |
| L2 Bomb Lab（6%） | 一个只给二进制的“炸弹”，要读反汇编、用 gdb 找出 6 个口令拆掉它 |
| L3 Attack Lab（4%） | 对有缓冲区溢出漏洞的程序做代码注入和面向返回编程（ROP）攻击 |
| L4 Cache Lab（5%） | 写一个缓存模拟器，再优化矩阵转置让缓存不命中最少 |
| L5 Malloc Lab（4% + 7%） | 自己实现 `malloc`/`free`/`realloc`，分检查点和最终版两次交 |
| L6 Shell Lab（7%） | 写一个带作业控制的小 shell，处理进程和信号 |
| L7 Proxy Lab（4%） | 写一个多线程、带缓存的 HTTP 代理 |
| L8 SFS Lab（4%） | 排在文件系统那几讲之后（日程上叫 sfslab），教材官网没有这个实验，校外拿不到材料 |

CMU 的学生还要做代码审查：和助教讨论代码风格，并做一个 10 分钟的小测证明自己理解实验内容。

**自学怎么做**：教材官网给自学者提供了各实验的“自学版”（Self-Study Handout），不用注册就能下载，但**不含答案**，答案只给授课老师。
包括 Data、Bomb、Attack、Architecture（Y86-64 处理器）、Cache、Performance、Shell、Malloc、Proxy 等实验。
Bomb Lab 的自学版关掉了向评分服务器报告的功能，炸了也不扣分。多数实验的自学版带本地测试脚本。

**往年考试**：考试页上有从 2001 年起的历年期末卷和参考答案，还有一份最新的模拟卷。注意早年的卷子有些是 32 位 x86 汇编，现在只考 64 位。

## 学习建议

- **实验比讲课重要。** 每章读完就做对应的实验，Data Lab 和 Bomb Lab 适合在学完第 2、3 章后马上做。
- **Bomb Lab 练熟 gdb。** 断点、单步、看寄存器和内存，这门课后面所有实验都会用到这些调试技巧。
- **Malloc Lab 最花时间，提前开始。** CMU 给它排了将近一个月，还拆成检查点和最终版两次交。
- **书上的练习题要做。** 官方复习建议里专门提到做书里的练习题（书后有答案）和往年考题。
- **在 Linux 上做。** 实验针对 x86-64 Linux，Windows 用 WSL 或虚拟机，Apple Silicon 的 Mac 要找一台 x86-64 的机器或用模拟环境。

## 同类课怎么选

- **[Stanford CS110](/docs/systems/systems-fundamentals/stanford-cs110)**：接在 C 语言课之后，更侧重用系统调用组织多进程、多线程和网络程序。
- **[UC Berkeley CS61C](/docs/systems/computer-architecture/cs61c)**：从更靠近硬件的角度讲，涵盖 RISC-V、数字电路和并行，和 CSAPP 互补。
- **[Nand2Tetris](/docs/systems/computer-architecture/nand2tetris)**：从与非门一路搭到操作系统，适合想先建立整体图景的人。
- 学完可以接 [MIT 6.S081](/docs/systems/operating-systems/mit-6-s081)（操作系统）、[CS144](/docs/systems/networking/cs144)（网络）或 [CS143](/docs/systems/compilers/cs143)（编译器）。
