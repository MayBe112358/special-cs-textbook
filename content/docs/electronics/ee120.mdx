## 课程简介

EE120（Signals and Systems）讲信号与系统的基本理论：怎么描述一个信号，怎么描述一个系统对信号做了什么，
以及怎么在时域和频域之间来回切换。2026 年秋季由 Babak Ayazifar 讲授。

系里的课程说明：连续与离散时间的变换分析方法及应用；线性时不变系统、传递函数；傅里叶级数、傅里叶变换、
拉普拉斯变换和 Z 变换；采样与重建；用变换解微分方程和差分方程；频率响应、波特图、稳定性分析；
用通信系统和反馈控制系统作为例子。

这门课的讲法有个特点：**先讲离散时间，再讲连续时间**，而且强调“向量空间”的视角——
傅里叶变换就是把信号投影到一组复指数基上，和线性代数里的基变换是一回事。
这些工具的应用面比名字听起来广得多：音频、图像、通信、控制，乃至卷积神经网络，数学根基都在这门课里。

## 先修要求

- 系里目录列的先修是 **EE64 和 EE66**，也就是改版后的电路课和信号与系统入门课（原来的 EECS16B 和 16A），
  见 [EE16A / EE16B](/docs/electronics/ee16a-ee16b)。
- 实际需要的是：线性代数（向量空间、内积、特征值）、复数和欧拉公式、会解简单的微分方程，以及能写 Python（实验用）。

## 课程结构

2026 年秋季的课程政策列出了计划讲的主题（按这个顺序）：

| 部分 | 讲什么 |
|---|---|
| 离散时间信号与系统 | 冲激和阶跃、线性与时不变、卷积、常系数差分方程与方框图（延迟-加法-增益） |
| 频率响应 | 复指数是 LTI 系统的特征函数、频率响应、幅度与相位图 |
| 稳定性与状态空间 | BIBO 稳定性、因果性、状态空间表示 |
| 连续时间信号与系统 | 狄拉克函数、连续时间 LTI 系统、微分方程与方框图（积分-加法-增益）、反馈系统 |
| 向量空间视角 | 函数构成的希尔伯特空间入门 |
| 傅里叶分析 | 离散和连续时间、周期（傅里叶级数）和非周期（傅里叶变换）信号，FFT，时频不确定性原理 |
| 采样 | 采样定理、重建与插值、过采样与欠采样、多速率系统入门 |
| 变换 | Z 变换、拉普拉斯变换 |

每周两讲（每讲 2 小时），周五讨论课。日程里每讲都标了 Oppenheim《Signals and Systems》和 Hsu《Signals and Systems》（Schaum 系列）的对应章节。
写这页时学期刚过第四周，日程只排出了前几讲的主题。

## 学习建议

- **离散时间学扎实再往后走。** 课程先把离散时间的卷积、频率响应讲透，连续时间只是把求和换成积分。前面没懂，后面会一直吃力。
- **每讲读 Oppenheim 对应小节。** 日程里标得很细，比如第二讲对应 1.6.5–1.6.6、2.1、2.3.1 节。
  Hsu 的 Schaum 版习题多、有详细解答，适合练手。
- **自己动手画频率响应。** 用 NumPy 算一个简单滤波器（比如两点平均 `y[n] = (x[n] + x[n-1]) / 2`）的幅度响应，
  看它为什么是低通。一张图胜过一页推导。
- **习题做完再看解答。** 解答是公开的，很容易忍不住先看，但这门课的题目主要练的是“换个域想问题”的直觉，
  得自己卡过一次才练得出来。
