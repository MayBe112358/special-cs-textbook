# 一本特殊的 CS 教材

在线地址：<https://maybe112358.github.io/special-cs-textbook/>

这个网站有两层内容，互相指着对方：

- **课程是目录**。按知识领域组织的计算机科学课程树，每门课只写简介、先修要求和官方链接，
  练习一律指向课程团队自己发布的作业，站内不自编习题。
- **代码是正文**。这个网站自己的源码就是教材正文，讲解写在每个核心文件顶部的结构化注释里，
  由构建脚本抽取成 `internals` 分支下的讲解页。

两层之间的跳转是自动的：课程页底部列出“学完这门课可以读哪些代码”，讲解页顶部列出“读懂这里
需要先学哪些课”。这些链接由源码注释里的 `@courses` 字段生成，改注释就会改链接。

网站是纯静态的，同一棵树有两个入口：左边的侧边栏，和底部的终端。

## 终端

页面底部可以展开一个终端，命令语义对齐真实 Unix：

| 命令 | 作用 |
|---|---|
| `ls` | 列出当前位置下有什么，每一项可以点 |
| `cd` | 切换位置，支持 `..`、`~`、`-` |
| `cat` | 在终端里读一门课的简介或一个模块的讲解 |
| `open` | 在正文区打开对应页面 |
| `refs` | 课程 ↔ 代码互相反查 |
| `help` | 列出全部命令 |

终端不自己保存“当前目录”——位置完全由网址推导，因此鼠标点侧边栏和终端里 `cd` 始终同步，
浏览器的前进后退和分享网址也都正常。

## 本地运行

```powershell
npm install
npm run dev
```

浏览器打开 <http://localhost:3000>。

其他命令：

```powershell
npm run index   # 重新扫描内容与源码注释，生成知识索引
npm test        # 跑命令引擎、虚拟文件系统与心得备份的测试
npm run build   # 静态导出到 out/
```

`npm run dev` 和 `npm run build` 都会先自动跑一次 `npm run index`。

## 目录

| 位置 | 放什么 |
|---|---|
| `content/docs/` | 课程页（MDX），目录名用英文，中文标题写在文件里 |
| `core/` | 与界面无关的纯逻辑：命令引擎、虚拟文件系统、知识索引、心得数据 |
| `components/` | 界面：终端、心得、评论、讲解页 |
| `app/`、`lib/` | Next.js 与 Fumadocs 的接线 |
| `scripts/` | 构建期脚本：生成知识索引、修补静态预取 |
| `开发指导文档/` | 项目定位、协作约束与分阶段规划 |

## 心得与评论

- **私人心得**存在你自己的浏览器里，换一台设备看不到，可以整体导出成 JSON 备份再导入。
- **作者心得**写在内容文件里，跟项目走，任何人都能看到。
- **公开评论**用 GitHub Discussions（Giscus），需要 GitHub 账号，网站本身依然没有服务端。
